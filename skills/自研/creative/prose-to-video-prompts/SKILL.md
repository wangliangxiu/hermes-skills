# 文字 → AI视频分镜提示词包

## 核心教训（用户2026-08纠正）
用户说"剧本/分镜/动画提示词"时，交付物是**可直接粘贴到AI视频工具的分镜提示词包**，不是文学剧本。原话："别按照剧本写了，按照能够生成动画的提示词写，写的越详细越好，对了，记得限定人物形象基本不变。"
- 只写文学剧本（旁白/对白/镜头散文）→ 会被打回
- 写生产级提示词（运镜术语+景别+人物一致性+时间轴+负向词）→ 正确

## 交付物结构（docx放桌面，原文不动）
1. 使用说明（先读）：资产先行 → 上传参考图 → 逐段粘贴 → 拼接
2. 全局风格前缀（每段都带）：如"写实电影纪实风格，35mm胶片颗粒，自然光，低饱和暖色调，16:9横屏"
3. 角色资产卡（锁人物形象的关键）
4. 场景资产卡
5. 道具资产卡
6. 分镜提示词：每段15秒时间轴格式，整段可粘贴

## 人物形象一致性（用户点名要求）
- **多年龄段角色卡 + 共享锚点**：同一角色按年龄段出多条卡（少年/青年/中年/老年），共享一组外貌锚点（脸型/眉/眼/鼻/肤色/体型），只变岁月痕迹（皱纹/白发/体型/服装）——全片看起来是"同一个人变老"
- 每条卡格式：全身站立正面、纯白背景、表情中性、空手、含鞋子；再补三视图（正面/侧面/背面+面部大特写）
- 分镜提示词里**每镜重复外貌锚点** + 【参考】@图片1 C0X 角色图 —— 稳定性=参考图+文字锚点，缺一不可

## 分镜提示词格式（时间轴）
```
[风格前缀]，15秒，16:9横屏，[整体氛围]
0-3秒：[建立] - [运镜术语]，[画面]
3-7秒：[发展] - …
7-11秒：[情绪/特写] - …
11-15秒：[收尾] - …
【声音】只写音效，不写音乐，不生成字幕
【参考】@图片1 C0X角色，@图片2 S0X场景
【负向】morphing, distortion, disappearing objects, static image, frozen background, watermark, text, jittery camera, aspect ratio change
- 中文负向词（用户偏好，国内平台如即梦/可灵可整段替换；效果不稳再切回英文）：
【负向】形变, 扭曲, 物体消失, 画面静止, 背景不动, 水印, 文字, 镜头抖动, 画幅突变
```
- 运镜用标准术语：Pan / Dolly In / Dolly Out / Truck / Tracking / Crane / 航拍 / 手持 / 慢动作 / Slow Zoom In（模型对术语理解远好于自然语言）
- 景别交替：远景→中景→特写→收尾，不连排3个同景别
- 文本类元素（站名牌/匾额/报纸文字）→ 写"字迹模糊不可辨"，防AI画乱码

## 自传/真人传记的提示词铁律
- 事实照原文：人名/地名/时间/番号/数字一个不编
- 不虚构台词；对白只用原文有据的原话（家训/口号/口头禅）
- 画面可艺术渲染（环境/光线/氛围/季节感），剧情不可新增

## 交付偏好
- docx（python-docx：黑体标题/宋体正文/楷体引用，两端对齐，行距1.5）
- 迭代时用户可能要求保留多版本：命名"初版/细化版"并排，别默默覆盖
- 风格可换（3D动画/水墨/手绘），替换每段开头风格前缀即可，结构不动
