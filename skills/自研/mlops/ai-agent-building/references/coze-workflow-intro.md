# Coze / 扣子 工作流平台（拖拽式 Agent，无代码路线）

字节跳动旗下 AI 应用开发平台（coze.cn，国内可访问，2026 实测 200）。与代码版 Agent（本技能主体）互补：**不写代码也能搭 AI 应用**，是使用者（非程序员背景）向 HR 证明"懂 workflow"的捷径。

## 核心概念

Workflow（工作流）= 在网页画布上拖拽节点连成流水线：
```
[开始节点] → [插件节点(搜索)] → [大模型节点(总结)] → [结束节点]
```
Agent = 代码版工作流（节点换成工具函数）——面试时能说出这句类比 = 理解到位。

## 入门路径（10 分钟第一个工作流）

1. 打开 https://www.coze.cn → 手机号/抖音登录
2. 左侧菜单【工作流】→【创建工作流】
3. 画布默认有开始/结束节点，从节点面板拖入：
   - ① 开始节点（已存在）
   - ② 插件节点 → 搜"新闻"或"网页搜索"
   - ③ 大模型节点 → 选豆包/DeepSeek，提示词写"把搜索结果总结成3条要点"
   - ④ 结束节点 ← 连大模型的输出
4. 连线：按住节点右侧小圆点拖到下一个节点输入口
5. 右上角【试运行】→ 输入话题 → 看输出
6. 【发布】→ 选扣子商店或 API → 得到链接任何人可访问

## 面试话术（做完后能说）

"我在扣子Coze上搭过工作流：把搜索+大模型串起来做新闻摘要，不用写代码，拖节点就行。我理解AI应用的本质是『输入→处理→输出』的自动化，Agent也是一样，只是节点换成了工具函数。"

## 彩蛋：扣子编程（code.coze.cn）

字节的 AI Coding 工具（"Vibe Coding 基础设施"）——自然语言让 AI 写代码，与用 Hermes/DeepSeek 写代码同原理。面试提"Vibe Coding"很加分。

## 常见坑

- 找不到节点：左上角【节点面板】按名字搜索（"大模型""搜索""插件"）
- 新手大模型节点选豆包（免费额度多），进阶可接 DeepSeek API
- 别一上来就做复杂流——先跑通最简单的，再慢慢加节点
