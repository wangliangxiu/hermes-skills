# 计划 / 打卡 / 配额类 Excel 工作簿

## 什么时候用

- 用户要“给我出个表”：减脂/训练计划、学习计划、进度打卡、单价配额、用量统计这类**要天天填、隔段时间回看**的表
- 已有工作簿要改参数、加表、改说明文字

## 生成与验证（本机）

- openpyxl 装在 `D:\python\python.EXE`（3.14）；Hermes 自己的 venv 里没有，`execute_code` 里直接 `import openpyxl` 会 ModuleNotFoundError。
- 可靠路子：`write_file` 把生成/修改脚本写到临时目录，再用 `execute_code` +
  `subprocess.run([r"D:\python\python.EXE", 脚本路径], capture_output=True, text=True, encoding="utf-8")` 执行；跑完把临时脚本删掉。这条路不依赖 terminal 的交互授权，中文路径也稳。
- 读回验证用 xlsx skill 的 `xlsx_read.py <f> --sheets` / `--formulas`，同样用 `D:\python\python.EXE` 跑；改完用 openpyxl 复核数据验证、条件格式、合并区还在不在。

## 公式必须触发重算

- openpyxl 只写公式、不算结果，缓存值全是 null。写完要设工作簿 `fullCalcOnLoad`（`xlsx_edit.py <f> --recalc`），否则用户打开可能看到空白或 0。
- 不要用 `data_only=True` 读回来再保存——那会把公式全部换成缓存值（此时为 None）。

## 结构惯例

- 第一张固定是「使用说明」：用「步骤｜做什么｜在哪张表」三列表写怎么用，再列几条硬性红线。
- 每张表一个用途，表名直白：每日配额 / 体重打卡 / 饮食打卡 / 食物换算 / 调整规则。
- 关键参数做成**输入格 + 公式**：改一个数字（当前体重、单价、系数），配额、热量、分餐、合计全部自动重算；不要把算出来的数值写死，否则用户过两周权重一变就得找你重做。
- 打卡列加数据验证下拉（√ / ×）；趋势列加条件格式（下降=绿 C6EFCE，上升=红 FFC7CE）；表体 `freeze_panes` 冻表头；日期列预填一串日期便于下拉填写。

## 扩展已有工作簿：把大章节拆成「知识点细化表」

用户说“这个大章节感觉挺大，后面再开一些 sheet 把里面的知识点拓展出来，让我知道该细化到哪些知识点”时，指的就是这套做法：**在原有主表之外，一个章节开一张表**，把该章拆到“能勾选、能自测”的粒度。用户要的是**全部科目都拆**，不会只要他举例的那一科。

- **先 dump 再动手**：读现有工作簿的全部 sheet 名、列头、所有单元格、样式（字体/填充/列宽/行高/合并区/数据验证），照它的体例扩。dump 输出**落盘成 txt 再 read_file**，不要直接打到终端——`head` 会把结果截断，看不出全貌。
- **动手前备份原件**：生成器是原地覆盖，先把原 xlsx 复制一份到临时目录留后路。
- **每章一张表的固定结构**（列：序号｜知识点｜考纲要求｜真题频率｜掌握标志（能做什么题）｜完成✓｜完成日期｜备注）：
  1. 第 1 行合并 A1:H1 的标题行（`<科目> · <编号> <章名>` + 本章分值/题位）；第 2 行列头；`freeze_panes='A3'`；
  2. 知识点逐行；“完成✓”列加数据验证下拉 `formula1='"✓,×"'`；“掌握标志”列左对齐 + wrap；
  3. 章末先一行「学习顺序：…」（浅蓝底），再一块「易错提醒（考前重点看这几条）」（深蓝标题行 + 黄底条目）；
  4. 表名带编号（如 `M8 无穷级数`）——**必须和总表里的编号对得上**，用户是靠编号找表的。
- **顺手加两张“导航”**：① 每科第一张表放「使用说明」（步骤｜做什么｜在哪张表）；② 总表加一列「细化表（点章名跳转）」，用 `cell.hyperlink = "01-数学一.xlsx#'M8 无穷级数'!A1"` 做成可点击跳转（超链接字体 0563C1 + 单下划线）。
- **生成器必须可重复运行**：写表前先 `if title in wb.sheetnames: del wb[title]` 再创建，否则每改一次就多出一批重名表。现成脚本：`scripts/generate_chapter_sheets.py`（配置文件 + JSON 数据 → 写工作表 → 总表加跳转列，含备份步骤）。
- **知识点内容的三条硬规矩**：
  1. 能对着现成大纲（公共课大纲全文、专业课考纲解析）写就对着写；“考纲要求”只用大纲原话四档（了解 / 理解 / 掌握 / 会），拿不准写“理解”，不要自编层级；
  2. “真题频率”按真题实际出现次数给高/中/低，**不许凭感觉**；
  3. 粒度要“一看就知道该练什么”：不写“中值定理”，要拆成“罗尔定理的条件与结论”“拉格朗日定理证不等式”“泰勒在哪点展开”；**不加大纲里没有的考点**。
- **内容量大就外包、渲染自己做**：几十章的知识点可以让子代理并行写，但**只让它产出固定 schema 的 JSON**（要求它自己 `json.load` 自检、只回报路径与各章条数、不贴全文），工作表的生成与核对留在自己手里。

## 版式（用户偏好）

- **扩展已有工作簿时以文件现有样式为准**：先 dump 出来照抄（实测已交付的备考计划表用 `1E3A5F` 做表头，不是下面这个 1F4E79）。从零新建时用这套：标题行深蓝底白字（1F4E79），列头浅蓝底深蓝字（D9E2F3），输入格黄底（FFF2CC），全表细边框（B4C6E7），正文微软雅黑 10.5pt。
- 数字列居中、说明/长文本列左对齐 + wrap_text；列宽逐列显式设置（说明列 45-58），不靠默认宽度。
- 换算/参考表把“常见份量”和数值写在同一行（如：1碗米饭≈180g≈45g碳水），用户是拿来估量的，不给克重秤。

## 交付

- 配一份同名 txt 说明（用户看 txt 不看 md）：先写方法依据和目标，再写每天怎么做、卡住怎么办、红线、时间预期。
- 文件放 `桌面\我的小项目\<项目名>\`；更新直接覆盖同名文件，不留 `_v1`/`最终版`。
- 用了别人的方法/教程当依据时，在说明里写清出处（谁讲的、哪来的一套），别把外部方法讲成自己的。

## 格式统一（硬规矩，主人明确要求过）

- **新增的行/列必须继承相邻行的样式**：`cell._style = copy(相邻格._style)`，不要自己另设对齐/字体。
  翻车实例：给总表追加一行时把 A/B/D 列设成居中，而上面 41 行都是左对齐——一行跟上下文不一样，一眼就难受。
- **无特殊理由就按全表统一**：标题/表头居中；文本列左对齐；短值/数值列（序号、要求、频率、✓、日期）居中。
- 同一类列要前后一致：新加的“细化表（章名）”列必须跟原有的“学习内容”列一样左对齐，不能因为它是链接就居中。
- **交付前跑一遍对齐审计**：逐表逐列统计正文行的 horizontal，同一列出现两种对齐就说明有地方不统一
  （跳过合并单元格所在行）。

## 细化计划表：把大章节拆成“逐章知识点清单”（实测做法）

**两段式，不要一步到位**：先用子代理（或自己）写**内容 JSON**（每章一张表的数据），
再写一个 `generate_sheets.py` 把 JSON 渲染成工作表。分开的好处：可重复运行、改内容不用碰排版代码、
子代理超时也不会把排版成果丢掉。

**表结构（已验证好用）**
- 每章一张表，表名 `M8 无穷级数`（带编号，与总表对得上；Excel 表名 ≤31 字符）
- 表体固定 8 列：序号｜知识点｜考纲要求｜真题频率｜掌握标志（能做什么题）｜完成✓｜完成日期｜备注
- 章末两段：**【学习顺序】**与**【易错提醒】**（考前只看这几条）
- 首行合并 A:H 做标题（含本章分值/题位），第 2 行列头，`freeze_panes='A3'`
- 「完成✓」列加数据验证下拉：`DataValidation(type='list', formula1='"✓,×"')`
- 每科工作簿最前面插一张【使用说明】（三列：步骤｜做什么｜在哪张表）
- 总表加一列可点击跳转：`cell.hyperlink = "01-数学一.xlsx#'M8 无穷级数'!A1"`
  （表名带空格必须用单引号包——这是跳转能不能点开的关键）

**生成器的硬要求**
1. **幂等**：重跑前先删同名旧表，不要越跑越多。
2. **原地覆盖前先备份**：先把原工作簿 `cp` 到临时目录再生成（这次就是靠备份才敢直接覆盖）。
3. **自动补齐总表缺失行**：拆出新章节（如把寄存的动载荷条目拆成 S15）时，总表要能自动追加该行 + 跳转链接，
   不要只在新表里加而总表漏掉。
4. 样式照原工作簿：表头深蓝 1E3A5F + 白字粗，列头浅蓝 D9E2F3，输入格黄 FFF2CC，全表细边框，
   正文微软雅黑 10pt，数字/短列居中，长文本列左对齐 + wrap_text，列宽逐列显式设置。

**内容怎么搞（防止“看起来很多但没用”）**
- 让每个子代理**只写 JSON、不碰 Excel**；schema 固定为
  `{subject, sheets:[{id, name, score, order, points:[{no, point, req, freq, pass, note}], traps:[]}]}`。
- 约束写死在任务里：`req ∈ {了解, 理解, 掌握, 会}`（用大纲原话）、`freq ∈ {高, 中, 低}`（按真题次数不是感觉）、
  每条点 ≤40—45 字、`traps` 2—5 条、`no` 连续编号。
- 要求它对**本地已有的考纲/真题文件**对齐，并在汇报里交出“每章条数 + 总数 + 枚举自检结果”（只回摘要，不贴全文）。
- 子代理可能把边界内容“寄存”在别的章节里（这次把考纲第十一章动载荷寄存在“基本概念”表尾）——
  **验收时要看章末备注，该拆就拆成独立章节**。

**验收清单（全对上才算完）**：每科表数、每章知识点条数、末条序号、表头文字、下拉存在、冻结位置、
总表跳转条数（要等于章节总数）。回读脚本用 openpyxl 直接读单元格值，不靠“应该没问题”。

**交付**：文件夹 + 同名 zip（zip 里放 xlsx + 一张 `00-知识点细化说明.txt`：哪一科多少章多少条、怎么用、
数据来路、硬规矩）。数据 JSON 与生成脚本另存一份到 `桌面\考研\备考计划细化源码\`，以后要再拆细直接重跑。

**现成脚本**：`scripts/generate_chapter_sheets.py`——吃一个配置文件 JSON
（`workbook_dir` / `backup_dir` / `maps` / `index`），自动备份、建表、建总表跳转列、
并**补齐总表里缺的章节行**。已在工作簿副本上实测过一轮（42 张表 + 42 条跳转全对，含自动追加的新章节行）。
两个坑：① 给它的路径必须写原生 `C:/Users/...`，bash 的 `$HOME` 展开后会变成 `C:\c\Users\...`（真撞过）；
② 它是“约定结构 + 样式”的生产器，**首次用于一批新数据要逆表核对**（表数/条数/章末区/跳转列/没有空表）。
