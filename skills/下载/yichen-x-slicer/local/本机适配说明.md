本机适配说明（Windows 11 + Hermes CLI）
安装日期：2026-09-29   技能路径：D:\hermes-skills\yichen-x-slicer

一、结论：半个能用（已实测，分两截）
  能用的前半截：抓取与素材落盘（--source-only 模式）——不需要 Playwright，本机实测通过。
  不能用的后半截：切片渲染成 PNG/ZIP/成片——需 Playwright + Chromium，本机未装。
  没装之前的定位：当"X 帖子素材采集桥"用，别当"发帖成图"用。

二、网络前提（中国大陆必须）
  export https_proxy=http://127.0.0.1:17890 http_proxy=http://127.0.0.1:17890
  不加代理连不上 X 与 pbs.twimg.com/video.twimg.com。

三、实测通过的命令（source-only）
  node D:/hermes-skills/yichen-x-slicer/scripts/yichen_x_slicer.mjs \
    --url "https://x.com/<user>/status/<id>" --source-only --output "D:/<新的输出目录>"
  产物：source.md、assets/（含 media-*-source.mp4 与海报图）、selected-source.json、
        routing-audit.json、source-import.json
  实测样例（@bbkirstry 的 1080p 视频帖）：unit_count=1 media_count=1 asset_count=2
        native_video_count=1，视频与海报都落盘成功。

四、报错与设计边界（不是 bug）
  1. X Article（长文）链接会被明确拒绝：错误 x_article_route_required。
     长文要走 X Article 专用流程，本技能按设计不处理。本机遇到长文链接先用 fxtwitter 取正文。
  2. 找不到 Playwright 时的报错原文：
     "未找到可用的 Codex Playwright。可设置 YICHEN_X_SLICER_PLAYWRIGHT_MODULE。"
     要跑完整切片需：npm 装 playwright + 下载 Chromium（体积较大，装前先跟用户确认）。
  3. 只允许匿名读取公开 X 数据（FxTwitter），不允许用登录态或 Cookie。

五、其他可用姿势
  node .../yichen_x_slicer.mjs --list-templates   # 列 11 套版式：sunset/editorial/data/fire/...
  已有 source-json 时可跳过抓取：--url <链接> --source-json <selected-source.json> --output <目录>

六、许可与边界
  只读公开数据；不操作微信、剪映或任何发布后台；不生成 TTS/配音/BGM，只保留所选原生视频的原声。
