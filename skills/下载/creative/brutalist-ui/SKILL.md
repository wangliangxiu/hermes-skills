# Protocol: Brutalist Web Design

## Philosophy
Brutalism in web design embraces raw structure, exposed grids, and deliberate roughness. It rejects polish in favor of honesty. Every element serves a purpose — decoration for decoration's sake is banned.

## 1. Core Rules

### 1.1 Typography
- One typeface only. Monospace or strong grotesk.
- Font size is a tool: headings at 48-96px, body at 18-24px.
- No font-weight below 400. Bold is preferred.
- Text alignment: left-aligned always. No justified, no centered (except short CTAs).

### 1.2 Color
- Maximum 3 colors total (including black and white).
- High contrast only. Backgrounds are white or black. No gray-on-gray.
- Accent color: one. Use it sparingly and deliberately.
- No gradients. No transparency blending.

### 1.3 Layout
- Exposed grid: show the columns. Use borders between sections.
- No rounded corners. Radius: 0.
- No shadows. No depth. Everything is flat.
- Asymmetry is welcome. Perfect symmetry is boring.

### 1.4 Components
- Buttons: thick border (2-3px), solid fill on hover.
- Links: underlined always. No color-change-only hover.
- Forms: thick borders, monospace input text.
- Navigation: stacked vertical menu or raw horizontal list.

## 2. Banned Elements
- Smooth scroll
- Fade-in animations
- Glassmorphism
- Gradient buttons
- Card shadows
- Rounded anything

## 3. When to Use
- Personal portfolios (especially dev/designer)
- Editorial / zine-style content
- Experimental landing pages
- Any project that wants to stand out from the SaaS template crowd
