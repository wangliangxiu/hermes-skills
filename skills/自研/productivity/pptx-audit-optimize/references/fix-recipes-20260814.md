项目：智能炮孔设计系统_报名PPT_v1.pptx（12页，微软雅黑统一，封面/尾页深色、内页浅色）
体检工具：python-pptx 布局dump + COM 导出/溢出检测 + PIL 像素统计

## 发现的问题 → 修法

### 1. P10 财务括号明细与总额矛盾
- 原文：`首年10.3万（研发4.8万一次性+迭代1.5+维护3.6+服务器0.4+保险预留1.5），此后约7万/年`
  → 括号合计 4.8+1.5+3.6+0.4+1.5 = 11.8 ≠ 10.3（评委一眼能抓）
- 定稿口径（BP v3）：首年10.3万 = 研发4.8+迭代1.5+维护3.6+服务器0.4（**不含保险**）；
  此后约7万/年 = 迭代1.5+维护3.6+服务器0.4+保险预留1.5（**含保险**）
- 修正：`首年10.3万（研发4.8万一次性+迭代1.5+维护3.6+服务器0.4），此后约7万/年（含保险预留1.5）`
- 验证：修正后与三年营收（税后 2.9 / 31.4 / 56.8 万）完全自洽（第1年固定10.3+变动1.5，此后固定7+变动1.5×n）

### 2. P6 三张实拍图高度不齐 → 居中裁剪统一
- 点云图框 4.05×2.23in（原图 1578x867，比例1.820），另两张 4.05×2.13in（1560x820）
- 修法：`half = (1 - (4.05/2.23)/(4.05/2.13)) / 2 ≈ 0.0224`
  ```python
  pic.crop_top = pic.crop_bottom = 0.0224
  pic.height = Inches(2.13)   # 宽保持 4.05
  ```
- 说明卡片 y 统一为 3.93（标题）/ 4.28（说明）

### 3. P8 "1,650万~4,950万" 30pt 粗体换行 → 内边距归零
- 症状：`BoundWidth=218pt < 框宽255.6pt` 却 `Lines=2`（"万"落单行），非常丑
- 根因：文本框左右内边距默认各 7.2pt，实际可用宽 241pt，粗体30pt中文比 BoundWidth 估算更宽，临界换行
- 修法（COM）：
  ```python
  tf.MarginLeft = tf.MarginRight = 0
  sh.Width = 267.0   # 3.71in
  # 复查: Lines().Count == 1, BoundHeight == 36.0
  ```
- 教训：加宽框无效时先查内边距；判断换行用 `TextRange.Lines().Count` 而非 BoundHeight

### 4. P9 残留 6pt 空 run → 删除（无视觉影响，洁癖项）
```python
for r in list(p.runs):
    if not r.text.strip() and r.font.size and r.font.size.pt <= 8:
        r._r.getparent().remove(r._r)
```

## 验证流程（安全改稿）
1. 改前 `shutil.copy2` 备份到 TEMP
2. 改后读回备份/当前，逐段对比 runs（字号/粗体/字体）→ 格式无损证明
   （子串匹配"固定成本"会误伤副标题/毛利段——被误处理段落也对比确认）
3. COM 溢出复查：`bh > usable + 4`，12 页 0 溢出
4. 重新导出 PNG：P6 三图区域像素统计（深色 24~59%）确认非白屏
