## 商业计划书（BP）框架

### 标准BP章节
1. **执行摘要** — 项目介绍 + 核心亮点 + 市场机会 + 团队（最重要，评委最先看）
2. **市场分析** — 痛点 + 用户 + TAM/SAM/SOM + SWOT
3. **产品方案** — 功能 + 架构 + 原型 + 技术壁垒
4. **商业模式** — 价值 + 收入 + 成本 + 盈利
5. **运营计划** — 路线图 + 里程碑
6. **团队介绍** — 成员 + 导师
7. **财务预测** — 3年预测 + 资金用途

### 路演PPT框架（8分钟，12页）
1. 封面（15s）
2. 痛点（45s）— 引起共鸣
3. 方案（60s）— 核心内容
4. 市场（45s）— 数据支撑
5. Demo演示（90s）— 全场亮点
6. 商业模式（45s）— 清晰明了
7. 优势/壁垒（45s）
8. 数据/成果（30s）
9. 团队（30s）
10. 财务（30s）
11. 未来规划（30s）
12. 致谢+联系方式（15s）

### 常见避雷点
- ❌ 选题太大太空 → 切口要小，痛点具体
- ❌ 只讲技术不讲商业 → 技术与商业并重
- ❌ 路演超时 → 宁可删减不超时
- ❌ Q&A答不上 → 备20+问题
- ❌ PPT字太多 → 多用图表，一页一个核心信息
- ❌ 忽视评委 → 站在投资/评审角度思考

### 加分项
- ✅ 符合河南省产业需求（与政策对焦）
- ✅ 有知识产权（专利、软著）
- ✅ 已有试点数据（比纯PPT有说服力）
- ✅ 带动就业（社会价值）

## 术语解释速查

| 术语 | 全称 | 大白话 |
|:---|:---|:---|
| TAM | Total Addressable Market | 这个项目如果做到极致能赚多大 |
| SAM | Serviceable Addressable Market | 你能力范围能覆盖多少 |
| SOM | Serviceable Obtainable Market | 你第一口能吃下多少 |
| SWOT | Strengths/Weaknesses/Opportunities/Threats | 四个角度照镜子 |
| MVP | Minimum Viable Product | 最少功能先做一个能用的版本 |
| BP | Business Plan | 商业计划书 |
| Demo | Demonstration | 现场演示产品怎么用 |
| Q&A | Questions and Answers | 路演完评委提问环节 |
| ROI | Return on Investment | 投入产出比 |
| KOL | Key Opinion Leader | 关键意见领袖/网红 |
| KPI | Key Performance Indicator | 关键绩效指标 |

## 团队角色建议（5-7人）

| 角色 | 人数 | 职责 | BP负责章节 |
|:---|:---|:---|:---|
| 队长 | 1 | 统筹全局、对外沟通、决策 | 执行摘要、SWOT、团队介绍、里程碑、风险对策 |
| 技术 | 1-2 | 原型开发、技术方案、Demo | 产品概述、功能、技术架构、壁垒、开发进度 |
| 商业 | 1 | BP撰写、市场调研、财务 | 市场分析、TAM/SAM/SOM、竞品、收入模式、盈利预测 |
| 设计 | 1 | PPT美化、产品UI | 产品截图、界面设计、团队形象照、PPT制作 |
| 路演 | 1 | 现场路演、Q&A答辩 | 路演稿撰写、Q&A题库准备 |
| 文案 | 1 | 申报材料、文档整理 | 整章BP润色、附件材料、文档格式统一 |

### BP角色分工明细

BP各章节对应负责角色：

**一、执行摘要** → 队长+全体（队长主笔）
**二、市场分析** → 商业（所有子章节）
**三、产品方案** → 技术（功能/架构/壁垒）+ 设计（截图/界面）
**四、商业模式** → 商业
**五、运营计划** → 队长+商业
**六、团队介绍** → 队长（成员信息）+ 设计（团队照片）
**七、财务预测** → 商业
**八、风险与对策** → 技术+商业+队长（按风险类型分配）
**附录** → 技术+设计（产品材料）+ 文案（文档整理）

**路演相关**：路演稿初稿 → 路演；PPT初稿 → 设计+路演；Q&A题库 → 路演+文案

## 实用的参赛项目方向（AI+新媒体方向）

### 适合报社/媒体背景的团队
1. **AI政务新媒体助手** — 自动写稿/配图/排版，卖服务给基层政务单位
2. **乡村振兴农产品AI推广** — AI生成文案+短视频脚本，帮农户带货
3. **AI方言文化保护** — 语音合成+互动小程序，保护地方方言
4. **本地生活信息聚合平台** — AI抓取+人工审核，做本地生活指南
5. **AI个性化旅游规划** — 结合本地景区资源，AI生成旅游路线

### 适合工程/硬件背景的团队
1. **AI+BIM隧道智能炮孔设计系统** — 凿岩台车配套软件（参见主技能）
2. **机械设备智能运维平台** — AI预测性维护
3. **工程招投标智能辅助系统** — AI自动生成技术标/商务标

## 备战时间线示例（28天）

| 阶段 | 天数 | 任务 |
|:---|:---|:---|
| 闪电组队选题 | 3天 | 组队、头脑风暴、选题定稿 |
| 项目打磨 | 14天 | 市场调研→MVP开发→BP撰写→PPT设计→内部汇报 |
| 冲刺演练 | 9天 | 路演稿→模拟路演→迭代→终极打磨 |
| 初赛 | 1天 | 路演+Q&A |
| 决赛备战 | 8天 | 如晋级持续优化 |
