# 《晓妆》国画文物活化 - 实战案例

**画作信息：** 《晓妆》，赵玉平作，国画
**画面内容：** 古风水墨画竖幅，暖橙底色宣纸，七只灰白色珠颈斑鸠落在枯枝上。
**枯枝**从右侧伸向左方，嶙峋无叶，根部立太湖石。
**题字印章**在画面最左侧竖排。
**背景**全画暖橙色调。

## 七只鸟的分布

| 位置 | 动作 |
|:----|:------|
| 最上面（枝高处分叉） | 仰头鸣叫，头动，喉部鼓动 |
| 最左边（靠近题字处） | 背对镜头，头扭过来正对镜面，扭头+跳跃+鸣叫 |
| 从左往右第三只（枝干中段） | 来回跳 |
| 最右边（枝梢末端） | 飞走再飞回来 |
| 最下面（低处粗枝） | 飞到地上啄食然后飞回 |
| 另两只（枝干中间段） | 微动（转头、抖羽） |

## 命名字段速查

- **国画风格**：古风水墨画风，暖橙底色宣纸纹理，竖幅
- **枯枝**：从右伸向左，苍劲嶙峋如铁画银钩，无叶
- **太湖石**：枯枝根部，瘦漏透皱
- **珠颈斑鸠外观**：灰白色，颈部有细密珠状斑纹，翼下深褐色飞羽
- **题字印章**：画面左侧竖排

## 30秒标准版时间轴

0-3s → 全画静止
3-6s → 四只微动
6-8s → 最上鸣叫
8-11s → 最左扭头跳跃
11-14s → 第三只来回跳
14-18s → 最右起飞飞走
18-22s → 最下飞到地上啄食
22-25s → 两只先后飞回
25-28s → 逐一定格
28-30s → 全画归寂

## 5秒压缩版时间轴

0-1.5s → 最上鸣叫 + 最左扭头跳跃 + 第三只来回跳（同时）
1.5-3s → 最右起飞 + 最下飞地啄食（同时）
3-4s → 两只先后飞回
4-5s → 全画归寂

## 负向提示词（通用）

morphing, distortion, camera movement, style change to realism, flickering, watermark, text overlay, color shift, aspect ratio change

## 注意事项

- 珠颈斑鸠的"珠颈"指的是颈部细密的黑白斑点，不是珍珠色
- 国画活化必须强调"保持原画水墨风格不变"，否则AI容易跑偏成写实风
- Locked-off固定机位是"静态画活化"的核心——摄影机不动，画中世界自己动
