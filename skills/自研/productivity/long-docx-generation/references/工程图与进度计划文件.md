# 工程图与进度计划文件（脚本产出）

长文档交付里常要配几张图和一个进度计划文件。两类都是脚本产出，各有各的坑。

## 一、matplotlib 出工程示意图

基本设置：

```python
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
plt.rcParams["font.sans-serif"] = ["SimHei"]     # Windows 自带，另有 Microsoft YaHei / SimSun / KaiTi
plt.rcParams["axes.unicode_minus"] = False
```

**画完必须自己渲染看一眼**（存成 PNG 后用视觉检查，不要只看脚本跑通）。反复出现的三个毛病：

- **标注压字**：节点密的地方文字互相盖 —— 把标注**分层**（上二层 / 上一层 / 下一层 / 下二层），
  按节点间距把相邻标注分到不同层，而不是全排在同一高度
- **色带里的白字被线穿**：箭头或水平线穿过色带，白色文字就糊了 —— 把箭头线画到色带外面，文字才干净
- **边界文字被截断**：最左 / 最右的标注改左对齐 / 右对齐，并放宽 `xlim` 留出边距

### 拿不到地图数据时怎么出"工程位置图"

**按里程画线路走向与控制节点示意图**（数据全部来自文件的里程，不编地理关系）：

- 横轴 = 里程（DK 值，换算成 km 便于按比例画）；各段（高架 / 明挖 / 盾构 等）按长度画成首尾相接的
  色带，色带中央白字写段名 + 长度
- 控制节点用竖线加标注：起终点、跨河 / 跨路 / 跨高速、工法分界、工作井、风井、联络通道、
  下穿既有建构筑物、下穿管线
- 图注写明"本图按文件给出的里程与控制因素绘制，用于说明构成与关键节点，不表示周边地理形态"
- 横轴刻度标里程（DKx+xxx），轴标签写明"自起点往终点递增：小里程端 → 大里程端"

## 二、进度计划文件（横道图 / 网络图）

要交"施工进度计划"类文件时有三条路：

1. **图片 / Excel 横道图**：matplotlib 或 xlsx 出图，适合直接插进正文（附表里用）
2. **MS Project XML**（`.xml`，Project 双击可打开，也能另存为 `.mpp`）：**本机 Project 用不了时的
   可行路径** —— 直接写 XML 文件，不需要装或激活 Project 就能生成，对方有 Project 就能打开
3. 一定要 `.mpp` 且本机 Project 可用：先查 Office 激活状态再动手：
   `cscript //nologo "<Office 安装目录>\root\Office16\ospp.vbs" /dstatus`
   （看 LICENSE STATUS 与 ERROR CODE）。**未激活的 Office 组件会拒绝 COM 自动化**
   （客户端报 0x80080005 / 服务器运行失败），此时代码写得再对也白搭 —— 直接回到路径 2，
   不要在脚本上反复试

### MS Project XML 的关键写法

- 根元素 `<Project xmlns="http://schemas.microsoft.com/project">`，含 `SaveVersion`、`Name`、
  `ScheduleFromStart`、`StartDate`、`MinutesPerDay` / `MinutesPerWeek`、`DefaultStartTime` / `FinishTime`
- 每个任务：`UID` / `ID` / `Name` / `Type` / `IsNull` / `CreateDate` / `WBS` / `OutlineNumber` /
  `OutlineLevel` / `Priority` / `Start` / `Finish` / `Duration` / `DurationFormat` / `Milestone` / `Summary`
- 前置关系放在任务元素的**末尾**：
  `<PredecessorLink><PredecessorUID>2</PredecessorUID><Type>1</Type><CrossProject>0</CrossProject>`
  `<LinkLag>0</LinkLag><LagFormat>4</LagFormat></PredecessorLink>`（Type=1 是 FS 完成—开始）
- `Duration` 以**分钟**计（8 小时工作日 = 480 分钟 / 天）；`DurationFormat` 取"天"的取值
- **不要自己定义日历**：写了自定义工作日历它不认，会按默认的标准日历（周一~周五）重算，
  工期数字与你的设计全对不上（写"10 天"会变成"7 个工作日"，整列工期都变小）
- 正确做法：**按标准日历自己把日期算自洽再写进去** —— 工期按工作日数，日期用代码推进
  （跳过周六周日），里程碑工期 0、与前置同日。这样 Project 打开后不会再改
- 生成完**用 Project 打开核对一遍**日期、工期与显示单位，别只看脚本打印
- 现成生成器见本技能 `scripts/make_msproj_xml.py`（改起始日期与工序表即出文件）
