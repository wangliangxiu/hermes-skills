## 法定公文12种（摘录）

| 文种 | 适用场景 | 结尾语 |
|------|----------|--------|
| 通知 | 下行/平行告知办理执行事项 | 明确对象、事项、责任、时限 |
| 通报 | 表彰/批评/传达重要情况 | 事实准确，评价克制 |
| 报告 | 向上级汇报工作 | "特此报告"；不夹带请示事项 |
| 请示 | 请求指示/批准/批转 | "妥否，请批示/批复"；一文一事 |
| 批复 | 答复下级请示 | 明确同意/不同意及依据 |
| 函 | 不相隶属机关商洽/询问/答复 | "特此函告/函复""盼复"；语气平等 |
| 纪要 | 记载会议议定事项 | "会议认为/指出/要求"；不写流水账 |
| 决定 | 重要事项安排/奖惩/变更 | 权威明确 |
| 通告 | 一定范围公布周知事项 | 条款清楚 |
| 公告 | 向国内外宣布重要事项 | 级别较高，慎用 |
| 意见 | 对重要问题提出见解和处理办法 | 政策性较强 |
| 议案 | 政府向人大提请审议 | 注意法定主体和程序 |

## 反AI味核心规则（完整版）

### 事实密度
删除形容词和四字口号后，段落仍须回答：**谁做什么、怎么做、做到什么程度**。

### 判断强度分级
| 级别 | 表达 | 使用条件 |
|------|------|----------|
| 1 | 已启动、正在开展 | 仅部署或初始行动 |
| 2 | 有序推进、稳步推进 | 有计划步骤，效果有限 |
| 3 | 取得进展、初见成效 | 有阶段成果或反馈 |
| 4 | 取得明显成效、形成机制 | 有数据/制度/流程支撑 |
| 5 | 重大突破、历史性成就 | 权威认可/关键指标/行业对比 |

规则：**宁可稳妥，不要拔高。**

### 抽象词控制（必须跟具体内容）
| 词 | 必须跟 |
|----|--------|
| 赋能 | 赋能对象和方法 |
| 体系 | 体系组成部分 |
| 机制 | 机制名称和运作方式 |
| 协同 | 谁和谁协同 |
| 闭环 | 闭环的各个环节 |
| 生态 | 主体关系和环境变化 |

### 严禁出现的AI痕迹
1. 空泛套话（方向和态度没有工作信息）
2. 过度拔高（普通事实叫"重大突破"）
3. 机械排比（"要…要…要…"）
4. 四字词堆叠（一句话堆三个以上）
5. 万能结尾（"谱写新篇章"用于任何场合）
6. 虚假具体（"相关部门""重点领域"反复用但不指实）
7. 动词无宾语（"扎实推进""全面加强"不加具体对象）
8. AI连接句式过密（"不仅…而且…""一方面…另一方面…"）
9. 聊天机器人痕迹（"当然可以""以下是我为你""希望有帮助"）

### 出口检查
输出前问自己：**"如果这篇公文被退回，最可能被批评哪里像AI写的？"**

常见的答案和改法：
- "空" → 加事实、主体、机制、时限
- "飘" → 降级判断、去掉宏观拔高
- "整齐得假" → 根据内容变化句式长度
- "不像这个文种" → 按对应文种模板重写
- "像聊天回复" → 去掉助手框架和元评论

## 公文人类化检查清单（Humanizer Pass）

在反AI味检查之后使用，专门处理"看起来工整但仍然像AI"的问题。

| AI痕迹 | 公文中的表现 | 改法 |
|--------|-------------|------|
| 意义膨胀 | `具有重要意义、标志着、彰显了` 无证据使用 | 陈述实际任务、结果或政策依据 |
| 假深度 | `推动...促进...助力...` 在一句后连锁 | 保留一个主要动作，给对象和过程 |
| 宣传腔 | `亮点纷呈、成效斐然` 用于日常工作 | 替换为可衡量的进展或观察到的变化 |
| 模糊归因 | `有关方面认为、群众普遍认为` 无来源 | 写明来源、调研、反馈渠道，或删掉 |
| 格式化困难段 | `虽然面临挑战，但前景广阔` | 写明实际困难和下一步处理方法 |
| AI词汇聚类 | `关键、赋能、生态、格局、体系、动能` 堆叠 | 保留必要术语，紧跟具体内容 |
| 回避简单动词 | `发挥着重要作用、承载着重要使命` | 优先用`是、有、完成、建立、解决` |
| 三点式包装 | 每段恰好三个整齐要点 | 按实际任务数分，不硬凑三 |
| 同义词轮换 | `单位/部门/机关/主体` 交替使用 | 重复用最清晰的词，公文允许重复 |
| 元话语 | `下面从三个方面展开、本文将进行阐述` | 直接进入正题，不预告 |
| 万能正面结论 | `未来可期、再上新台阶` | 以时限、责任、报送、下一步结尾 |
| 格言公式 | `安全是发展的底线` 作填充 | 只有直接引出具体任务时才保留 |

### 句式节奏规则
- 避免每段开头相同的动词（强化、强化、强化）
- 避免每段标题等长
- 优先用简单动词：是、有、建成、完成、发现、整改、报送、反馈、纳入、公开
- 正式的公文里，**平实中立就是人味**，不要故意注入个性来显得像人

### 硬删除清单
输出前删掉：
- `当然可以`、`以下是我为你`、`希望有帮助`、`如需继续`
- `下面我们来看`、`让我们深入探讨`（教程式过渡）
- 表情符号、加粗的内联标签、不必要的英文格式

### 第二遍自检
输出前再问一次：**如果这篇公文被退回来，最可能被批评哪里像AI写的？**
