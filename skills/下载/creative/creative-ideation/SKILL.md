# Creative Ideation

A library of ideation methods for any domain. Read the user's situation, route to the matching method, execute it step by step.

## How to Use

1. **Listen** to the user's situation or creative block
2. **Route** to the matching method from the catalog
3. **Execute** the method step by step, involving the user
4. **Output** concrete ideas, not just abstractions

## Method Catalog

### Divergent Methods (generate many ideas)

- **SCAMPER** — Substitute, Combine, Adapt, Modify, Put to another use, Eliminate, Reverse
- **Random Input** — Force-connect a random word/concept to the problem
- **Reverse Brainstorming** — How would you cause the problem? Reverse those actions
- **What If?** — Pose extreme hypotheticals
- **Analogies** — Compare to nature, sports, cooking, etc.
- **Six Thinking Hats** — White (facts), Red (feelings), Black (caution), Yellow (benefits), Green (creativity), Blue (process)

### Convergent Methods (narrow down)

- **Dot Voting** — Each person gets N votes for best ideas
- **Impact/Effort Matrix** — Plot ideas: high impact + low effort = do first
- **NUF Test** — New, Useful, Feasible — score each
- **Concept Fan** — Start broad, narrow step by step

### Reframing Methods (see differently)

- **Five Whys** — Ask "why?" five times to find root
- **Challenge Assumptions** — List all assumptions, invert them
- **User Journey Map** — Walk through the user's experience step by step
- **Empathy Map** — What does the user see, hear, think, feel, say, do?

### Combinatorial Methods (mix ideas)

- **Morphological Matrix** — Create a grid of attributes x options, combine
- **Idea Combination** — Take two unrelated ideas, merge them
- **Forced Association** — Combine the problem with a random object

### Playful Methods (unlock creativity)

- **Worst Possible Idea** — Get the bad ideas out first
- **Draw It** — Sketch the solution, no words allowed
- **Storyboard** — Tell the solution as a 6-panel comic
- **Crazy 8s** — 8 ideas in 8 minutes

## Workflow

1. Identify the user's goal (new product? content? solution?)
2. Pick 1-2 methods based on their personality and the problem type
3. Guide them through the method interactively
4. Capture and organize the output
5. Suggest next steps (prototype, test, refine)
