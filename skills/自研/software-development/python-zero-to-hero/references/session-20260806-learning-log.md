## 特征值特征向量讲解框架（成功，可复用）
1. 概念锚点：矩阵=滤镜/变形器，特征向量=方向不变只拉伸的向量，特征值=拉伸倍数
2. 手算例子 [[2,1],[1,2]]：v=[1,1] → [3,3]（特征值3）、v=[1,-1] → [1,-1]（特征值1），先让使用者直观看到"方向不变"
3. 公式用汉字念：A 乘以 v 等于 lambda 乘以 v（lambda=λ 兰姆达）
4. 应用铺垫：PCA降维 / PageRank / 马尔可夫链，为后面概率分布埋伏笔
5. np.linalg.eig 返回值：w=特征值数组、v=特征向量矩阵（**按列排，第 i 列对应第 i 个特征值**）——延续 8.4 教学
