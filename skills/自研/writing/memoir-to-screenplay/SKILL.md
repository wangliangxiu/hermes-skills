# 自传/回忆录 → 纪录片文学剧本

把真实人物的一生（自传、回忆录、生平资料）改写成"纪录片式文学剧本"（供阅读/拍摄的分场镜头本）。常配合 `director-narrative-flow`（叙事节奏、景别交替原则）使用，但本 skill 专管传记改编的纪律与交付格式。

完整分场清单与 docx 排版参数见 `references/suiyue-ruge-example.md`（《岁月如歌》实测样例）。

## 核心铁律（对应使用者"写作铁律：不许瞎编"）

- 剧情零增改，只做画面呈现。旁白（画外音）直接引用原文文字。
- 对白仅用文中明确记载的话：家训、口号、可考原话（例：《岁月如歌》里只有"老老实实做人、踏踏实实做事"家训和"质量就是生命，安全就是底线"口号可作对白）。其余一律不写台词，用旁白叙述代替。
- 人名、地名、年份、数字、部队番号等全部照抄原文，不推理、不补全。
- 画面/环境/感官细节可以艺术铺陈（光线、声音、气味、物件质感、时代道具），但时代道具须有原文依据（如原文提到驴吉普、搪瓷脸盆、唯一一台电脑），不凭空加戏。
- 剧本开头加【说明】段：注明旁白取自原文、对白未虚构，保护使用者。

## 结构模板

1. 序幕：黑场片头 + 画外音开篇（引"回望这大半生……"类总结原文）+ 片名渐显。
2. 分场：按人生阶段/工作经历切场（少年→从军→军校→带兵→整编→转业→各岗位→驻村→至今）。每场头部：第X场　标题；时间/地点/内外景。
3. 尾声：山河意象（太行山/黄河）+ 老兵站定 + 军功章党徽特写 + 心得四条 + 片尾字幕"献给……" + "根据XX自传改编"。

## 镜头序列（用 director-narrative-flow 的节奏）

- 开场建立全景（定地点氛围）→ 中景互动 → 情绪峰用特写 → 收尾镜头作结；景别交替不连排三个同景别。
- 紧张段落（新兵训练、凌晨盯岗）用快切收紧节奏；舒缓段落（散步、拉歌、星空）用全景放慢。
- 转场用空镜：铁轨延伸、印刷机飞转、车流。
- 情绪峰候选：接军功章、教导员探病、危房修缮、荣誉证书、离别拥抱。

## 镜头行格式

```
○ 远景·航拍（建立）　画面描述
音效：风声、鸡鸣……（细化版才加，黑体小字灰）
旁白："直接引原文。"
对白：（画外，语境）有据的原话。
```

## 细化增强（用户说"细化细节/环境镜头"时）

给每个镜头补：环境基座（季节、光线、声音、气味）、动作连贯细节（起手→接上）、情绪微表情、时代道具。音效单列"音效："行。剧情线不动。

## 交付（python-docx）

- 中文必须设：`run._element.rPr.rFonts.set(qn('w:eastAsia'),'宋体')`；标题黑体、正文宋体、旁白楷体斜体；页边距 2.5/2.8cm。
- 生成脚本放 %TEMP%，运行完删除，不留桌面。
- 版本管理：用户要"两个版本都给他看看"时，保留 初版/细化版 两个文件，命名 `<标题>_纪录片剧本_初版.docx` 与 `<标题>_纪录片剧本_细化版.docx`，不要覆盖；命名必须带"初版/细化版"字样，让人一眼分清，别只靠时间戳。

## 坑

- 别把"细化"做成"加戏"：环境可以厚，剧情和台词不能加。
- 别用 Markdown 交付；使用者要 Word(.docx)，剧本类也一样。
- 自传里时间线跳跃（如 1989→1990）照抄原文，不要"修正"年份。
- 用户说"改之前那个版本也保存着"= 我覆盖了旧版，此时要重生成旧版另存，不是只改名当前文件了事。
