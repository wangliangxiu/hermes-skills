# 第七章里的硬要求（写出来就必须回应）

> **声明：本文里的数字、面积、间数、天数、表名、章节号、项目名都是举例**（取自某一份招标文件），
> 不是通用要求。写的时候一律按**本次招标文件**的原文来 —— 它怎么写就怎么办，没有就不用管。

来源：招标文件"技术标准和要求"那一章。这些小节原文从 SKILL.md 里拆出来，按原样保留。

### 第七章"技术标准和要求"里已经写明的东西，投标文件必须逐条体现

招标人写出来的，就是他要求你答复的。这一章常见小节（举例，实际按本次文件扫）：
工程简况（工程概况 / 工程范围 / 工区划分及概况 / **工程重难点**）、
工作内容（建筑工程、安装及装修、前期工程、市政配套、甲供材料、乙供材料、其他）、
接口管理（前期工程接口、机电装修接口、系统设备接口、轨道工程接口、预埋槽道接口、市政交通接口；
管理接口：建设管理单位、监理咨询、当地政府）、材料供应方式要求（甲供 / 乙供、I 类乙供材料）、
工程目标（安全 / 质量 / 工期 / 文明施工 / 绿色环保）。

整章的结构大致是（举例，实际按本次文件扫）：
1 总则 → 2 工程简况（工程概况、工程范围、工区划分及概况、工程重难点、工作内容、接口管理、
材料供应方式要求、工程目标）→ 3 技术规范、标准 → 4 通用技术要求（图纸管理、前期专项工作管理要求、
施工现场管理要求与条件、验收与移交管理要求、勘察等其他管理要求）→ 5 专用技术要求
（项目总承包及工区管理要求、防水施工技术要求、盾构法施工技术要求、内置固定构件 + 槽道技术要求、
桥梁施工技术要求、停车场施工技术要求、人防施工技术要求、精细化施工技术要求、安全智慧管控系统要求、
资产管理技术要求、施工材料管理要求、创优要求、创新及科研要求）→ 附件：危险性较大工程。

**整章从头到尾都是要满足的要求**（这一章能写到一百多页），编投标文件时通篇照应 ——
别只抓前面"工程简况、工程重难点"那几节就以为看完了。

其中"工程重难点"那张表最值得当清单用：按车站 / 区间 / 车辆基地逐个列
"自身风险 / 环境风险 / 前期拆改难点"，每行还带"设计控制措施"和"施工要求"两列 ——
投标文件要把这些重难点逐条体现、逐条给对策，一条都不能漏。

写重难点这部分就按这两类走：**先按自身风险、环境风险（有前期拆改难点的再单列一类）逐条描述，
再写出对应的应对措施**。一条风险对一个措施，别写成一段笼统的话。

注意：设计控制措施是设计口径，不要原样抄来当自己的对策（评的是施工对策）。

### 接口管理单独写一节（有要求必须写，没要求也尽量写上）

接口是什么：说白了就是**工程空间上的衔接，跟施工缝一样** —— 两个单位、两个专业、两道工序
在空间上接头的那条缝（轨行区移交、预留预埋、孔洞封堵、标高对接、集水坑预埋钢管都算）。
是缝就容易出问题，所以接口管理要写清三件事：谁干、什么时候办交接、交完谁管。

- 招标文件里有"接口管理"这一节 → 必须写，一般单独成一章或一节（不要塞进别章里带过）
- 招标文件里没要求 → **也尽量写上**：这类内容是体现总承包协调能力的点，写了不亏
- 写什么：跟谁接口（对象）、接口内容是什么、怎么配合（谁牵头、谁总协调、按什么程序交接、
  日常找谁对接），工程接口与管理接口分开写
- 接口通常两类（举例，按本次文件扫）：
  工程接口——前期工程、机电设备安装与装修、系统设备、轨道工程、预埋槽道、市政交通；
  管理接口——建设管理单位、监理等咨询单位、当地政府

### 同一件事文件里写了好几遍：一致就照写，不一致就都写上

安全目标、质量目标、工期目标、文明施工目标、绿色环保目标这类，招标文件里往往出现不止一次
（合同条款里一处、"技术标准和要求"里一处、第八章投标文件格式的内容要求里还提一次），措辞还会有出入。
处理办法：把这些地方都扫出来对着比 —— **一致的照它写上就行；不一致的就都写上**（取大值，一处不丢），
别只挑一处写。这跟甲供材料那个"取大值"是同一个道理。

例（"合格"这件事在同一份招标文件里的三种说法，实际按本次文件扫）：
通用合同条款 21.2 写"本工程质量标准为：合格"；专用合同条款 21.2 与第七章 2.8.2 写
"合格率 100%…单位工程质量一次验收合格率 100%；确保省级质量奖项（"扬子杯"），争创国家级质量奖项
（鲁班奖、詹天佑奖、国家优质工程奖）"；第八章投标文件格式里投标人填的那张合同条款响应表写
"合格或投标人承诺的质量等级"、"不得低于达标（合格）标准或投标人承诺的等级" —— 也就是说承诺可以往高处写。

### 文明施工与环境保护：目标要写，措施更要一条条对上

"文明施工目标 / 绿色环保目标"那两条是**目标**（现场日常综合管理达标、安全生产标准化与绿色施工管理达标、
确保市级文明工地及举办市级观摩工程、江苏省标准化星级工地（争创三星）、环保各项指标 100%、
不发生环境破坏事件……）。**措施**在文件里另有一大块 —— 第七章"安全文明施工和环境保护管理要求"
（管理体系 / 安全施工隐患排查与风险管理 / 文明施工与环境保护），合同条款里的"文明施工""环境保护"
两条也各有要求。写施组时目标要写、措施也要一条条对上，别只把目标抄上去就完了（施组里通常单独成章：
文明施工、环境保护、消防、保卫、健康体系及措施）。

措施那块常见内容（举例，按本次文件扫）：标准化星级工地实施方案（开工前编制、报监理审批、
报建设管理单位备案）、现场安全生产标准化管理图集、围挡与封闭管理、材料堆放、宿舍与生活设施、
现场消防、标牌、扬尘管控（工地周边 100% 围挡、物料 100% 覆盖、出入车辆 100% 冲洗、地面 100% 硬化、
作业面 100% 湿法作业、渣土车 100% 密闭）、噪声（自动监测仪、隔声屏、夜间施工、中高考期间）、
污水与三级沉淀、固废分类、洗车槽、电动车集中充电、智慧工地（人员动态、扬尘视频监控与自动降尘、
与政府端对接）等。

### 文物保护 / 古树名木：有要求的尽量写一份保护方案

有的城市（尤其老城区、历史街区）在"前期专项工作管理要求"里会写"文物、古树保护管理要求"。
**只要有这类要求，就在施组里尽量写上一份文物保护方案**（跟古树名木一起写），别在别处提一句就过去。
方案里常见要落的东西（举例，按本次文件扫）：
- 受施工影响的文物、古树名木的保护措施；需迁移的树木、古树名木经园林单位确认后由承包商负责迁移
- 需保护的文物：由承包商提出监测保护方案，并取得文物保护单位 / 文物主管部门的认可
- 处于地下文物重点保护区范围内的工程：办理考古勘探手续、承担费用与现场配合；
  考古发掘期间不得擅自继续施工、指定专人保护现场；工期延误超过一定天数部分予以顺延
- 施工中发现地下文物：按《文物保护法》和当地条例、埋藏区通知等规定办理

### 小细节里的硬指标也要满足（面积、间数、时限）

"技术标准和要求"里"前期专项工作管理要求（临时工程与设施）"到"施工现场管理要求"这一段，
落到细处全是一行一条的硬要求（面积、间数、数量、报审时限）。写施组时最容易被当成背景材料跳过，
但**这些在编制过程中都是要满足的**，要落到施组对应章节里（临时工程方案、施工平面布置、资源配置、工地试验室）。

- 例（**只是举例**，面积、间数、天数都按本次招标文件的原文，文件没写的就不写）：
  承包商的现场工程调度、安全监控场所不少于 1800 ㎡；
  每个工区为招标人代表提供不少于 3 间全天候办公室和值班室，为设计代表、第三方测量、第三方监测检测
  各不少于 1 间，为驻地监理提供不少于 3 间办公室 + 不少于 2 间值班室；
  每个工区驻地设面积不小于 60 ㎡ 的现场会议室
  （用房面积还写了"以工程量清单中的相应约定为准"→ 要回清单核一遍，别只在施组里写）
- 时限类同理（天数按本次文件）：临时工程设计与说明开工前至少 21 天报监理审批（监理 7 天内批复）、
  临时用电专项方案开工前编制并报监理批准、施工工艺图开工前不少于 28 天报审、
  工地试验室在签约后 14 天内提交设备清单与平面布置图

### 程序性要求也照办（编报时限、编制方法、报批条件）

"施工现场管理要求与条件"这一段还有一批程序性要求，看着像开工以后的事，其实写施组时就得对上：

- 施工组织设计的编报：招标文件常写"合同生效后 X 天内编报实施性的施工组织设计"，并把内容清单列出来 ——
  拿这份清单逐块对齐自己的章节（例：总承包部及工区组织架构职责、工程重难点分析及对策、前期专项实施方案、
  施工总体部署、施工总体进度计划及措施、施工总平面布置、总体施工准备与主要资源配置计划、
  主要施工方法、安全管理体系及措施、风险管理体系及措施、专项资金流量计划、质量体系与质量保证措施、
  文明施工环境保护体系及措施、安全智慧管控系统与标准化工地建设方案、消防保卫健康管理体系及措施、
  分包计划及管理措施、协调配合及接口管理措施等），经监理单位批准后实施
- 进度计划的编制方法：招标文件可能直接指定编制方法（例：采用关键线路法 CPM 或监理单位确定的其他方法）。
  指定的就照它编；还有几条硬要求 —— 提交的逻辑网络图、横道图里的主要活动应与工程量清单中的项目一致，
  关键线路和里程桩的关联要清楚标明，年 / 月度任务（工程量和价值）、资源需求及累计进度都要标注清楚
- 交通组织：交通组织方案（招标人提供的、承包商自己提的）都要取得交管部门许可或批准后才能实施；
  施工期夜间运输、路口疏解人员、交通设施、既有市政道路改造与道路管养均由承包商负责，
  费用含在报价里、不提出变更或索赔

### "专用技术要求"可以在质量（检查）章节里引用上

第七章最后那部分"专用技术要求"（例：防水施工技术要求、盾构法施工技术要求、内置固定构件 + 槽道技术要求、
桥梁施工技术要求、墩柱盖梁与梁部技术要求……）就是这次要执行的技术标准。
写施组时**不用把设计说明重写一遍**，但可以在**质量保证措施 / 质量控制点与检查**那一章里直接引用：
标明"按本次招标文件第 X 章专用技术要求相关条款执行"，把它的指标当自己的质量控制标准、检查依据写进去。
道理很简单 —— **这都是我们要做到的**，引上就说明质量措施是对着它的要求来的。
（引指标和检查要求就行，别大段照抄招标文件原文。）

### 附件"危险性较大工程"清单表：上面写多少项，我们就写多少项

这一章后面常附一张"危险性较大工程清单表"。用法跟"工程重难点"那张表、跟风险源分析完全一样 ——
**清单上列了多少项，施组里就写多少项**，逐项做分析给措施，一项都不许少。

那张表的列一般是：单位工程名称 / 分部工程名称 / 危大工程名称 / **是否为超过一定规模的危大工程** /
保障工程周边环境安全和工程施工安全的措施。写的时候：

- 一项对一项落：单位工程、分部工程、危大工程名称都照它对应写，别自己并项、漏项
- **照它标注"超过一定规模的危大工程"** —— 标了的要在施组里写明组织专家评审论证，
  没标的按一般危大工程编专项施工方案；别把超规模的当普通项处理
- 措施那列可以接着用，但写进施组要成段成条（它自己常常只写"持证上岗、编制专项方案及应急预案、
  安全技术交底、专家论证"这四条，落到施组里要具体化）
- 依据摆上：住建部《危险性较大的分部分项工程安全管理规定》（37 号令）、
  当地住建部门的实施细则（例：江苏省 2019 版实施细则）
- 表前面通常还有一句"施工单位进场后应在此基础上进一步补充完善危大工程清单" ——
  施组里就照这句承诺：进场后复核补充完善
