## ① 钻孔执行表导出（build_hole_exec_table）

```python
CHARGE_COEF = {'掏槽眼': 0.75, '辅助眼': 0.55, '周边眼': 0.30, '底板眼': 0.55}
LINE_DENSITY = 0.9   # kg/m，φ32乳化炸药线装药密度

def build_hole_exec_table(holes, dy_cm=0.0, dz_cm=0.0, yaw_deg=0.0, D=6.0, meta=None):
    # 每孔：
    #   孔号 = C/A/Z/D + 序号（掏槽/辅助/周边/底板）
    #   设计Y/Z → 执行Y/Z = design_to_rig(h['y'], h['z'], dy_cm/100, dz_cm/100, yaw_deg)
    #   钻臂回转/俯仰 = check_reachability([单孔], D)[0]['az'/'el']
    #   装药量 = 0 if h.get('empty') else 深度×CHARGE_COEF[类型]×LINE_DENSITY
    #   可达 = check_reachability 的 reachable
```

- **空孔（掏槽中心孔 empty=True）药量必须=0**（首版漏了，回归抓到：掏槽8 = 1空+8装药）
- Tab1「💾 导出钻孔执行表」按钮（btn_export，绿色 #1E7A46，与"生成布孔"并排沉底）
  `_export_holes()`：取 design_holes + 定位面板当前 dy/dz/yaw/D → build_hole_exec_table →
  JSON（元数据：软件/版本/时间/围岩/断面/掏槽/台车定位/孔类型角度）+ 同名 CSV
  （`encoding='utf-8-sig'` 带 BOM，Excel 中文不乱码；`csv.writer`）
- 元数据含"台车定位"说明：定位校准后导出的执行坐标即为台车按此钻孔的坐标
- 验证：JSON/CSV 落盘往返、坐标平移单测（dy=12cm→执行Y-0.12）、空孔药量0/装药孔2.13kg

- `_fill_rec()`：围岩下拉 currentTextChanged → 填推荐值到 QDoubleSpinBox（可现场微调）
- `_apply_to_monitor()`：写 `monitor.dv[key]['val']` + `label.setText(f"{v:.1f}")` + `_check()`
- **与 Tab1 围岩双向联动**：
  `self.rock.currentIndexChanged.connect(lambda i: rp.rock_cb.setCurrentIndex(i))`
  反向同理——setCurrentIndex 相同值不触发 currentIndexChanged，不会死循环
- UI：围岩下拉 + 6 参数行（参数|推荐值|单位|说明 表头）+「应用推荐到钻进监控」按钮
