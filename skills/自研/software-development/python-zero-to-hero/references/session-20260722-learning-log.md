## 重要的教学风格调整（使用者明确表达的偏好）

**使用者原话：**「我的意思是，对照着程序语言讲一下呗」
- 使用者不要类比优先，要的是**逐行对照程序代码**解释
- 先讲「这行代码语法上做了什么」，再讲「变量在每轮循环的值是什么」
- 类比作为最后强化，不要一开始就用「就像一叠发票一张张翻」
- 使用者要的格式示例：
  ```
  第1行：`for r in records:` → 从 records 列表第1个元素开始...
  第2行：`print("- " + r)` → 第1轮 r="可乐：3元" 所以打印 "- 可乐：3元"
  ```
