# 凿岩台车布孔 爆破设计计算公式全链路

本文件的用户可展示版：《凿岩台车布孔计算书.docx》已生成，

## 一、围岩分级
- 普氏岩石坚固性系数：f = Rc / 10（Rc = 岩石单轴抗压强度，MPa）
- 分级参考：f<2 极软；2~4 软；4~6 中等；6~8 较硬；8~10 硬；>10 极硬
- 无试验数据时的现场快速判定：点荷载换算、回弹值、
  钻进参数反推（推进速度慢 + 冲击压力高 → 硬岩，即TFGM思路）

## 二、炸药单耗 q（kg/m³）
- 无单一理论公式，按 f 查经验表，常见范围 0.6~2.0
- 软岩取低值、硬岩取高值；不同炸药品种需修正
- 定值方法：工程类比 + 现场试爆标定（系统里做成可调参数）

## 三、孔深与循环进尺
- 循环进尺 L0 = L × η（L = 孔深 m，η = 炮孔利用率 0.8~0.9）
- 全断面一次爆破 L = 3~5 m；掏槽孔比普通孔深 0.1~0.2 m

## 四、孔网参数（布孔几何核心）
- 周边孔（光面爆破）：a = (8~15)d，W = (10~20)d，m = a/W = 0.7~1.0
  - a = 孔距，W = 最小抵抗线，m = 密集系数，d = 炮孔直径
  - W 太大→欠挖，W 太小→超挖；m 是控制超欠挖的关键比值
  - 算例：d = 0.045 m → a = 0.36~0.68 m，W = 0.45~0.90 m
- 辅助孔（崩落孔）：a = (1.0~1.5)W，排距 b = W（方形/梅花形）
- 掏槽孔：
  - 直眼掏槽：中心 1~2 个大直径空孔 + 周围 4~8 个装药孔，
    装药孔与空孔间距 l = 0.1~0.2 m，孔深 +0.1~0.2 m
  - 楔形掏槽：两排斜孔对向，倾角 θ = 60°~75°，孔深 +0.1~0.2 m
- 底板孔：参照辅助孔，抵抗线适当减小（防欠挖留根底）

## 五、单孔装药量
- 单孔药量 Q1 = q × V = q × a × b × L
- 实际装药长度 Le = ξ × L（ξ = 装药系数）：
  掏槽 0.7~0.8 / 辅助 0.5~0.6 / 周边 0.2~0.4（控制光爆）/ 底板 0.5~0.6
- 周边孔径向不耦合装药：不耦合系数 D = d孔/d药 = 2~3

## 六、爆破振动验算（安全核心）
- 萨道夫斯基公式：v = K × (∛Q ÷ R)^α
  v = 质点振动速度 cm/s；Q = 单响最大药量 kg（是"单响"非总药量）；
  R = 爆源到保护目标距离 m；K = 场地系数；α = 衰减指数
- 反算允许单响药量：Qmax = R³ × (v允许 ÷ K)^(3/α)
- K/α 参考范围（需现场实测标定）：
  岩石 K=30~70、α=1.3~1.8；土质 K=150~250、α=1.8~2.0
- v允许 按《爆破安全规程》GB6722 查表（不同保护对象限值不同）
- 用途：近建（构）筑物时先定 v允许，反算每响最多装多少药，
  决定分段起爆（微差爆破）的段数与每段药量

## 七、超欠挖验算
- 超挖量 Δ = S1 − S0（S1 = 爆破后实测轮廓面积，S0 = 设计轮廓面积；
  体积化：超挖方量 = Δ × 循环进尺）
- 周边孔外插角 θ = 3°~5°（越大超挖越严重）
- 钻孔开口偏差 ≤ 5 cm（视围岩而定），方向偏差用角度控制
- 超挖 1 m³ = 多运 1 m³ 渣 + 多喷 1 m³ 混凝土 → 写进汇报的"省钱数字"

## 经验系数边界（重要，不能省略）
理论公式（普氏f、萨道夫斯基）放心用；所有经验系数
（q、η、a/d、W/d、m、ξ、K、α、θ、D）是行业常见参考范围，
正式设计前必须查《爆破安全规程》GB6722-2014 原文核对 + 现场试爆标定。
系统实现原则：系数全部做成可调参数、分级保护（工人级微调/
工程师级二次确认），用现场超欠挖数据反推修正 → 闭环优化，越用越准。
