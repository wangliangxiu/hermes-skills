# 技能打包与发布前检查

配套 SKILL.md 的「出社区版」那一节。这里放可以直接照抄的做法，不是过程叙述。

## 1. 先盘同行（拿不准组织方式时）

思路：遍历已装技能目录（`~/AppData/Local/hermes/skills` 与外部技能目录），对每个含 `SKILL.md` 的目录统计
字符数、行数、同级有哪些 `references/`、`templates/`、`scripts/`，排出来看多数派。

看什么：

- SKILL.md 字符数的中位数/均值，以及「超过 10k / 20k 的有多少个」
- 有多少技能走「薄主线 + references」，多少走「单文件厚写」
- 同行怎么在主线里指向细则（常见写法：正文里 `详见 references/xxx.md`，再加一张「文件 → 讲什么」的表）

结论（多份已装技能的实际分布）：主线普遍 8~14k 字符；超过 20k 就该拆 `references/`；
单文件写 20~30 万字符的也存在，但那是个别大技能的做法，不是默认。

## 2. 切段拆分（原文不动，只挪位置）

做法：按标题行把 SKILL.md 切成段（以 `#` 开头的行作分隔），把每段整段写进对应文件，段内一个字不改。

要点：

- 拆前先备份：`cp SKILL.md SKILL.md.bak`；确认没丢内容后把备份挪出工作目录（别留桌面）
- frontmatter 与一级标题留在主线；`references/` 新文件开头写一行「本文件讲什么 / 来源是招标文件哪一章」
- 拆完在主线末尾加「细则文件（references/）」清单，每条一句「什么时候读它」
- 主线正文里原先指向被搬走章节的地方要改成指向 `references/xxx.md`（这类交叉引用最容易留下死链）
- 交叉引用、章节名改动后全库 grep 一遍旧称呼，确认没有残留

## 3. 发布前校验（可照抄）

```python
import re, yaml
c = open(p, encoding='utf-8').read()
assert c.startswith('---'), 'frontmatter 未从首字节开始'
m = re.search(r'\n---[ \t]*\n', c[3:])
assert m, 'frontmatter 没有闭合的 ---'
fm = yaml.safe_load(c[3:m.start()+3])
assert 'name' in fm and 'description' in fm
assert len(fm['description']) <= 1024
assert len(c) <= 100_000
assert c[m.start()+6:].strip(), '正文为空'
```

另加两条人工项：`name` 小写连字符、≤64 字符；正文结构完整（什么时候用 → 流程 → 常见坑 → 检查清单 → 不做什么）。

## 4. 去私人化 grep 清单

依次搜这些，逐处处理：

| 搜什么 | 处理 |
|:--|:--|
| 项目名 / 地名 / 站名 | 换成「××项目」「××市××路口」这类通用说法 |
| 人名、单位名 | 删掉或换角色（「项目负责人」） |
| 「使用者」「我」等第一人称 | 换成「你」「编标人员」这类面向使用者的说法 |
| 日期（`2026-09` 等） | 删；规则本身不需要日期就能立住 |
| 页码（`p192`、`第 3 页`） | 从社区技能里删掉，只留在私有索引；改用「第五章末尾那份附表」这种章节说法 |
| 举例用的具体数 | 标「举例」，或改成不带数的说法 |

搜完再看一眼 `references/` 里的每个文件（主角色的名字最容易只改一处、漏一处）。

## 5. 「数字与例子」声明模板

主线顶部（标题后第一条）：

```
> **数字与例子声明：文中出现的数字、面积、间数、台数、天数、时限、表名、章节号、项目名都是举例**，
> 一律以本次文件（本次项目）的原文为准。凡是牵扯到数据的地方都要回原文逐个核 ——
> 不能把别处抄来的数、或这里举例的数，当成本次的要求写进去；原文没写的就不写，要问的进问题报告。
```

每个 `references/*.md` 开头（两三行即可）：

```
> **声明：本文里的数字、面积、间数、天数、表名、章节号、项目名都是举例**，不是通用要求。
> 写的时候一律按本次文件的原文来 —— 它怎么写就怎么办，没有就不用管。
```

## 6. 同步与收尾

- 工作副本（他验收的那份）改完 → `cp -r <工作副本>/. ~/AppData/Local/hermes/skills/<name>/`
- `skill_view(name)` 确认读得到、`linked_files` 里 `references/` 都挂上
- 私有《进度与素材索引》里记一句：技能已拆分/已装、装在哪、工作副本在哪、旧备份在哪 —— 下次会话好接
