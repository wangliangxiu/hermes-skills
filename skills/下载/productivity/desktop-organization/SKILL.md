# Desktop Organization

Organize a messy desktop by classifying loose files into category folders. Works on Windows, macOS, and Linux.

## When to Use

- User says "帮我整理桌面" / "帮我分类桌面的文件"
- User asks to group/organize files into folders
- User complains about desktop clutter

## Workflow

### Step 1: Scan the Desktop

Use `execute_code` with `os.listdir()` to list desktop contents. On Windows:
- Desktop path: `C:/Users/<username>/Desktop/`
- Also try `C:/Users/<username>/桌面/` for Chinese Windows
- Use `os.path.join(os.path.expanduser("~"), "Desktop")` as universal fallback

List all items with type (file/folder), extension, and file size.

### Step 2: Identify Preserved Items

Items to NEVER touch (leave in place):
- `desktop.ini` (Windows system file)
- `此电脑.lnk`, `回收站` / `Recycle Bin` (Windows shell icons)
- Any existing folders the user created — keep them as-is
- The user may specifically say "文件夹不用动" — respect that

### Step 3: Classify Loose Files

Use file extensions and naming patterns to suggest categories:

| Extension | Category |
|-----------|----------|
| .pdf, .docx, .xlsx, .pptx, .txt | 文档 / Documents |
| .py, .js, .html, .css, .svg, .ts, .jsx, .json, .yaml, .toml | 代码 / Code |
| .mp4, .mov, .avi, .mkv | 视频 / Videos |
| .mp3, .wav, .flac, .m4a | 音频 / Audio |
| .jpg, .png, .gif, .webp, .svg | 图片 / Images |
| .zip, .rar, .7z, .tar.gz | 压缩包 / Archives |
| .lnk | 快捷方式 / Shortcuts |
| .tmp, ~$* (Office temp) | 临时文件 → delete |
| .doc, .docx | 文档 / Documents (or 简历模板 if they are resume templates) |

Combine video + audio into "媒体 / Media" if there are only a few files.

### Step 4: Identify Temp Files

Office temp files (starting with `~$` ) and `.tmp` files are safe to delete — they are auto-generated by Office apps and crash recovery, not user-created content.

**Always ask before deleting** — confirm with user:
- "临时文件（~$和.tmp文件）是要删除还是移到某个文件夹？"

### Step 5: Propose Classification to User

Use `clarify` to present the classification scheme. Include:
1. Each category folder name and files going into it
2. Temp files marked for deletion
3. Special cases (shortcuts, archives)
4. Ask about each edge case explicitly

**Example format:**
```
① 文档类 📄
   - file1.docx, file2.pdf

② 代码类 💻
   - script.py, index.html

③ 临时文件 🗑️
   - ~$temp.docx, .tmp files

问题：
1. 上面的分类你认可吗？
2. 临时文件删除还是保留？
3. 压缩包怎么处理？
```

### Step 6: Execute

Once confirmed, use `execute_code` with `os.makedirs()` + `shutil.move()` for files, `os.remove()` for temp files.

### Step 7: Show Final Result

Print the final desktop contents so the user can see the result:

```python
remaining = [i for i in os.listdir(desktop) if i != "desktop.ini"]
for i in sorted(remaining):
    full = os.path.join(desktop, i)
    typ = "📁" if os.path.isdir(full) else "📄"
    print(f"  {typ} {i}")
```

## Proactive Project Organization

This user prefers **not** to wait until the desktop is messy to clean up. Whenever you generate a new project (script, app, tool, executable, ZIP, etc.), create a dedicated subfolder for it immediately inside an umbrella folder on the desktop.

**Rule:**
- Before creating any deliverable file on the desktop, check if a parent umbrella folder already exists
- Use `我的小项目` as the umbrella for any standalone tool/app/program
- Create per-project subfolders inside the umbrella: `我的小项目/<项目名>/`
- Exceptions: learning materials (use `大模型学习计划/`), resume-related (use `简历模板/`)

**Step-by-step:**
1. When about to write a new desktop file, decide which umbrella it belongs to
2. Create the subfolder with `mkdir -p`
3. Write the file inside the subfolder
4. Report to user: "已放到 我的小项目/<项目名>/ 下"

**File update rule: "always replace the old one"**
- When updating a deliverable (guide, document, script), ALWAYS remove the previous version first
- Use `rm -f "C:/Users/使用者/Desktop/旧文件名"` before writing the new file
- Do NOT keep old versions with different filenames — user will not know which is the latest
- Exception: explicitly ask if the user wants to keep a backup

**Python learning folder stays on Desktop (not inside umbrella)**
- `Python学习/` stays directly on the Desktop, NOT inside `我的小项目/`
- The user wants it visible at a glance to stay reminded to practice
- Inside `Python学习/`, use per-topic subfolders like `hello_world/`, `variables/`, etc.

**Existing umbrella folders:**
- `我的小项目/` — all standalone tools/apps/programs (except Python学习)
- `大模型学习计划/` — learning plans and progress trackers (each phase as separate .xlsx files)
- `简历模板/` — resume templates
- `Python学习/` — on Desktop directly, visible reminder to practice

## Pitfalls

- **Chinese Windows**: Desktop may be `桌面/` instead of `Desktop/` — check both paths
- **Windows shortcuts (.lnk)**: These are regular files in Python — just `shutil.move()` them like any file
- **Office temp files**: `~$` prefixed files are invisible in File Explorer by default but visible in Python — don't skip them
- **Read-only files**: `shutil.move` on Windows can fail if file is open in another app — warn user to close Office apps first
- **desktop.ini is hidden**: It will not show in `os.listdir()` on some Windows configs, but guard against it anyway
- **User has existing folders**: Ask specifically whether to keep existing folders. Common answer: "文件夹不用动" (don't touch folders)
- **NEVER touch Windows registry for icon arrangement**: Do not modify `HKCU\Control Panel\Desktop\WindowMetrics` (IconSpacing, IconVerticalSpacing) or `HKCU\Software\Microsoft\Windows\Shell\Bags\1\Desktop` (FFLAGS, IconSize, IconPositions) to adjust desktop icon layout. Registry-based icon changes often don't take effect cleanly, can make things worse, and the user cannot see what happened on their screen.
  - **Specific failure mode**: Setting IconVerticalSpacing to non-default values (e.g. -1695) plus restarting explorer.exe can cause icon labels to disappear entirely — the user sees icons without filenames. Reverting to defaults (-1125) requires a full explorer restart and may still leave broken state. The registry approach is unreliable because:
    1. Windows caches icon positions in multiple places (ItemPos* values in Bags keys, FFLAGS bitmask, and Icon*Spacing in WindowMetrics)
    2. Changes require explorer restart but some only take effect after full logout/login
    3. The agent cannot see the screen to verify results
  - Do NOT use `reg add` to set FFLAGS — this only changes the registry value without actually repositioning icons on the desktop.

- **Programmatic icon alignment (C# + Win32 API, GOOD APPROACH)**: To programmatically align icons left while keeping vertical spacing, use a compiled C# program that sends `LVM_SETITEMPOSITION` (0x100F) messages to the desktop `SysListView32` window. This approach is safe because:
  1. It directly sets icon pixel positions — no registry side effects
  2. Works immediately without explorer restart
  3. Preserves grid alignment (vertical spacing doesn't change)
  4. Is reversible — user can manually drag icons back or toggle auto-arrange

  **Technique**:
  - Find the desktop `SysListView32` via `FindWindow("Progman", ...)` → `FindWindowEx(..., "SHELLDLL_DefView", ...)` → `FindWindowEx(..., "SysListView32", ...)`
  - On Windows 10/11, if that fails, try the WorkerW fallback: enumerate `WorkerW` windows looking for one that contains `SHELLDLL_DefView` → `SysListView32`
  - Get icon count: `SendMessage(listview, LVM_GETITEMCOUNT, ...)`
  - Set positions: `SendMessage(listview, LVM_SETITEMPOSITION, (IntPtr)i, (IntPtr)((y << 16) | (x & 0xFFFF)))`
  - Pack x into low word, y into high word of LPARAM
  - Use `csc.exe` (C# compiler, ships with .NET Framework at `C:\Windows\Microsoft.NET\Framework\v4.0.30319\csc.exe`) to compile a temp .exe
  - Reference `System.Windows.Forms.dll` to get screen dimensions if needed

  **Save the compiled .exe** to a temp path and run it. The program outputs "Icons found: N" and "Done! N icons aligned left."

  **Icon spacing defaults**: startX=15, iconSpacingY=100, startY=10 (for default icon size). For larger icons, increase spacing proportionally.

  **Example flow**:
  1. Write C# code to a temp `.cs` file
  2. Compile with `csc.exe /target:exe /out:temp.exe temp.cs /reference:System.Windows.Forms.dll`
  3. Run the compiled exe
  4. Clean up temp files

- **Manual approach (when user doesn't want programmatic)**: Tell the user to right-click the desktop → View → disable "Auto arrange icons" → select all icons → drag to left edge. For spacing adjustments, Ctrl+Mouse wheel on the desktop changes icon size (which effectively changes spacing).
