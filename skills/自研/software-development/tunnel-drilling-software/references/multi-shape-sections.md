# 多形状掌子面几何（v0.10，2026-08-10）

7种断面形状的轮廓生成/面积周长/布孔适配完整实现笔记。

## 坐标系与约定

- 掌子面系：y=横向（右正）、z=高程（上正），轮廓为**逆时针凸多边形**折线点集
- `_arc_pts(cx, cz, R, a0, a1, n)`：圆弧采样，角度 0=右、π/2=上（数学角）
- `section_contour(shape, span, height, steps)`：返回 [(y,z),...]
- `section_metrics(shape, span, height)`：面积（鞋带公式）/周长（折线累加），
  与解析公式误差 <1%（验证：圆形 28.19/18.84 vs 理论 28.27/18.85）

## 各形状轮廓构造公式

| 形状 | 构造细节 |
|:----|:---------|
| 圆形 | r=span/2，θ 从 -π/2（底部）逆时针整圆：`(r·cosθ, r·sinθ)` |
| 拱形 | 半圆拱 `_arc_pts(0,0,r, 0, π)`（右拱脚→左拱脚过拱顶）+ 直墙 hw=h-r + 平底 |
| 城门洞 | 拱矢高 f=min(r, 0.5h)，R=(span²/4+f²)/(2f)，圆心(0, -(R-f))；弧从右拱脚角 atan2(0-cz, r) 到左拱脚角 atan2(0-cz, -r) |
| 三心圆 | 顶大弧过(0,f)与(±ys,hs)，圆心(0,cz_t)，cz_t=(ys²+hs²-f²)/(2(hs-f))，R1=f-cz_t；肩(±ys,hs)直接斜线连拱脚(±r,0) + 直墙 hw=h-f |
| 五心圆 | 复用三心圆轮廓（近似，规范五心圆为5段弧，工程示意差异小） |
| 马蹄形 | 三心圆轮廓 + 底部仰拱反弧：过(-r,-hw)、(r,-hw)、(0,-hw-δ)，δ=0.2m；圆心 cz_inv=(r²-δ²)/(2δ)-hw，R_inv=cz_inv+hw+δ |
| 矩形 | 4角点 (±r, ±h/2) |

三心圆参数（可调占位）：f=min(r·1.1, 0.62h)（拱矢高）、hs=0.55f（肩高）、
ys=0.42·span（肩半宽）。

## 布孔适配

- **周边孔**：`section_contour(shape, span, height, max(120, perim*8))` 高密度
  轮廓 → 累计弧长数组 seg → n_contour=round(total/0.65) → 每孔 target=total·k/n
  → 在 seg 内二分定位线段 → 线性插值取点。**等弧距**不是等角度。
- **辅助孔**：梅花形网格（孔距0.8×排距0.8，隔行偏移半格），裁剪条件：
  掏槽区外（dist>0.55）且 `_in_polygon` 且在轮廓内且 `_dist_to_polygon ≥ 0.3`
  （margin 0.4 - 0.1 容差）。**不要用外接圆近似**——拱形/矩形会误裁。
- **底板孔**：`_bottom_line` 对轮廓每条边做 y 向插值取最低 z（每0.15m一个点），
  再按 n_floor=max(4, min(len(bottom), span/0.7)) 等距布孔。
- **掏槽孔**：与形状无关。

## 踩坑记录（实测）

1. **拱形弧角度反了**：`_arc_pts(0,0,r, π, 2π)` 画出的是**下半圆**
   （a=3π/2 → (0,-r) 在底部），面积只剩 2.1 m²，布孔全错。
   上半圆必须 `0 → π`（a=π/2 → (0,r) 拱顶）。
2. **三心圆侧弧几何无解**：肩点(ys,hs)到拱脚(r,0)距离 L > 2×R2 时，
   "圆心到两点都=R2"无解（R2=0.2span=1.2，L≈1.77 → 需要 R2≥0.885 才有点解，
   且解出的圆心让弧凸出断面 y=3.18>3.0）。结论：小半径圆角在"肩→脚"长边
   上不可行 → 改"顶大弧+斜肩直线+直墙"。
3. **稀疏轮廓点测试误报**：验证"周边孔是否在轮廓上"用
   `min(点到轮廓采样点距离)` 会误报——矩形只有5个角点，边中点离角点3m。
   必须用 `_dist_to_polygon`（点到线段最小距离，含闭合边）。
4. **QPolygonF.drawPolygon 自动闭合**：轮廓点集最后一点自动连回首点，
   底部段（-r,-hw）→（r,-hw）由闭合补上，不用手动加。

## 应用选择原则（调研整理）

公路→三心圆/五心圆；铁路→马蹄形/五心圆；地铁区间→马蹄形/拱形；
引水→圆形；矿山→城门洞/矩形；明挖/车站→矩形；软弱围岩高地压→圆形/马蹄形。
