# ST7789 屏幕模块排针顺序参考

> 不同厂家、不同尺寸的 ST7789 模块，排针顺序可能不一样。
> **绝对不要假设顺序！** 拿到屏幕后，先让用户念出排针旁边的丝印（silkscreen）文字。

## 已知顺序 A（本次会话确认）

**用户说：**「从左到右是 gnd vcc scl sda res dc cs blk」

```
  [GND] [VCC] [SCL] [SDA] [RES] [DC] [CS] [BLK]
    1     2     3     4     5     6    7     8
```
- GND = 地
- VCC = 电源 (3.3V)
- SCL = SPI 时钟 (SCLK)
- SDA = SPI 数据 (MOSI)
- RES = 复位 (RST)
- DC = 数据/命令选择
- CS = 片选
- BLK = 背光 (BL/LED)

**对应的 YD-ESP32-23 接线：**

| 屏幕脚 | → | 开发板 |
|-------|---|--------|
| GND (脚1) | → | GND |
| VCC (脚2) | → | 3.3V |
| SCL (脚3) | → | GPIO14 |
| SDA (脚4) | → | GPIO13 |
| RES (脚5) | → | GPIO12 |
| DC (脚6) | → | GPIO11 |
| CS (脚7) | → | GPIO10 |
| BLK (脚8) | → | GPIO15 |

## 另一种常见顺序 B

常见于一些 1.14寸/1.3寸 ST7789 模块：

```
  [VCC] [GND] [CS] [RES] [DC] [MOSI] [SCLK] [BL]
    1     2     3     4     5     6      7      8
```

## 接线前必做

1. **让用户念引脚名**：问「屏幕排针旁边印的小字，从左到右分别是什么？」
2. 记录用户念的顺序
3. 对照上面已知顺序确定是哪一种
4. 如果跟已知的都对不上——按用户念的顺序自己编写接线方案
5. **不要在确定顺序前就画接线图或写代码！**
