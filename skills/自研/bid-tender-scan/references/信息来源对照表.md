# 信息来源对照表（写标要用的东西各去哪找）

> **声明：下面的章节号、册数、文件名都是举例**（取自实际招标资料），不是通用要求。
> 每份招标文件的章序、附件、配套册都可能不同 —— 一律以本次文件的目录和附件清单为准。

## 一、招标文件正文

| 要找什么 | 去哪找 |
|---|---|
| 项目名称、标段划分、建设地点、建设规模、招标范围、合同估算价、总工期、评标方法 | **第一章 招标公告**（公告是整份文件的索引页，细则都指向后面） |
| 资格要求（资质、业绩、人员）、分包规定、澄清截止日期、备选方案、正副本份数与册数、装订、页数限制、是否暗标、保证金与有效期、递交与开标时间 | **第二章 投标人须知（含前附表与附件）** |
| 总分怎么构成、"评分标准"那一列（= 内容要求）、废标/无效标条款 | **第三章 评标办法**（前附表 + 评分表 + 评审工作表） |
| 质量等级、工期违约、奖罚、材料与价格约定、奖优条款 | **第四章 合同条款及格式**（通用 + 专用 + 合同附件） |
| 要干哪些活（开项）、施工顺序 | **第五章 工程量清单**：各单位工程"分部分项和单价措施清单"（表-08 那类）的开项汇总去重；末尾《工程量清单项目及计算规则》附表（按工法分节，节内一级项目＝施工顺序） |
| 工程位置、控制因素、风险源、尺寸 | **第六章 图纸**（图纸另册，见下） |
| 技术标准、材料与工艺要求、工程重难点、工作内容、接口管理、材料供应方式、工程目标、危大工程清单 | **第七章 技术标准和要求**（整章逐节扫到底） |
| 施组要写哪些内容、附表和各类表格的格式 | **第八章 投标文件格式**（技术部分格式：施组编制要求 + 附表；经济部分；商务部分） |
| 各标段总工期与分阶段工期、节点日期 | 第二章附件（总工期及分阶段工期要求）／第七章"工程目标"里的里程碑与逐车站区间节点 |
| **总体目标**（安全、质量、工期、环保含水土、文明施工、信息化、科技研发等） | ①第七章"工程目标"那一节（逐项给目标原文）；②合同条款里的质量等级、工期违约、奖罚与创优约定；③招标公告与投标人须知里的工期要求；④第八章技术部分格式的内容清单（告诉你"要写哪些目标及措施"）。几处说法不一致 → 按"取大值"都写上 |
| 施组章节骨架（铁路标） | **指导性施组**（若随文件下发 —— 章节照它搭，评分也拿它对标） |

## 二、正文之外，必须另外找的几处

| 要找什么 | 去哪找 |
|---|---|
| 图纸 | 单独图纸册（招标文件"图纸"章常常只写"另册"）；先看**图纸目录**（xlsx） |
| **地质与水文资料**（层序、分布特征、水文、岩土评价、液化、地基均匀性、不良地质） | 两种给法都要找：①**单独出勘察报告** —— 夹在图纸册里，往往单独一册、按工点再分册；②**没有单独报告** —— 就写在**图纸文件最前面的"设计说明"**里（这种情况更多），所以要翻图纸册开头那几页；细则见 `图纸册与勘察报告怎么用.md` |
| 澄清、补遗、答疑 | 补遗书 / 补遗答疑文件夹 —— **与招标文件同等效力，必须逐份看**（常改工期、改条款、改格式） |
| 单价、指导单价、造价构成 | 工程量清单（软件版）、项目造价分析表等 |
| **气象条件**（气温、降水、风、灾害性天气） | 设计总说明的"建设条件 / 自然条件"里的气象一节（跟水文地质挨着）；**有就写，没有就先不写** |
| 参考写法（施组、技术标） | 参考标书 / 往期最好的那一版（例：某标 779 页那版） |
| 招标文件之外的项目资料 | 招标图纸册里的其他专业分册、业主提供的其他材料 |

## 三、用法

1. 扫标时按这张表逐行落实：每行都答出"在本次文件里的哪一处"，答不出就是还没扫到
2. 第 1 章到第 8 章是主线；**图纸册、补遗答疑、指导性施组**这三处最容易被漏，专门过一遍
3. 引用时把出处记下来（哪一章哪一节、哪一册），写问题报告和核查提醒时好指认
