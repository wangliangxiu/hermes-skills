# 材料怎么写（甲供 / 乙供）

> **声明：本文里的数字、面积、间数、天数、表名、章节号、项目名都是举例**（取自某一份招标文件），
> 不是通用要求。写的时候一律按**本次招标文件**的原文来 —— 它怎么写就怎么办，没有就不用管。

## 材料怎么写（先分甲供 / 乙供，再按自己的视角写）

"技术标准和要求"里会写清甲供材料是什么、乙供材料是什么（有的还有"I 类乙供材料"的特殊要求）。
写之前先把这两类分开，各自按承包商该干的活写 —— 不该你干的不写，该你干的一条不能漏。

- 甲供材料（招标人 / 建设管理单位供应实物）：采购、订货、供货商管理、供货进度这些不是承包商的活，
  **不写**；承包商该写的是接收、进场验收、质量检验（复验）、报验、保管、成品保护，
  以及安装 / 预埋及其质量验收。
  例：甲供的桥梁支座，方案里不写材料采购，但要写支座的检验、质量验收这块怎么做
  （同理：甲供预埋套管、槽道这类，就写套筒预埋、安装质量验收）。
- 乙供材料：采购、进场检验、报审、标识、堆放保管这一整套都要写。而且**不能跟招标文件那张乙供材料表冲突**
  —— 要照着它去写采购、写施工：
  · 采购怎么写：照乙供清单里的材料写采购与报批流程（哪一类报谁批），把要承诺的供货单位资格业绩写上
  · 施工怎么写：材料品种、规格、等级照它写，别自己另立一套
  · 例（**只是举例**；指标一律照本次招标文件 / 工程量清单里写的抄，别照搬这里的数）：
    水泥强度等级不低于 42.5 级、混凝土 C20～C50 抗渗 P6～P10、预埋套筒 M20 / 316L 不锈钢、
    外置槽道材质不低于 Q355B 这一类
  - 分不清范围就先回第七章"工作内容"里那两条（甲供材料 / 乙供材料）核对，按它划。
    另外：正文里出现"***""**"这种打码的参数（管片外径、混凝土强度等级之类，公开版招标文件常打码），
    别当成"文件没写"就绕过去 —— 同一套文件的**工程量清单 PDF**（正文第五章末尾写着"工程量清单详见
    招标文件的其他材料部分"）里，"项目特征描述"那列往往写着实数；图纸里更全。
    例：管片外径 7900mm、管片厚度 400mm、管片宽度 1600mm 就是从清单里读出来的（=盾构直径的依据）
- 甲供范围怎么定：**把招标文件里所有写到"甲供材料"的地方都扫一遍，取并集** —— 提到的都算甲供
  （同一件材料前后用词可能不一样，比如"预埋套管"和"预埋套筒"其实是一回事，不算冲突，照并集处理）。
  文件里常有一句兜底话："除下表的外，其余均为乙供" —— 按它划。
- 乙供材料有的文件还分档（I 类 / II 类），采购方案的报批层级不一样 —— 写材料那节要按它的分档写。
  例：I 类材料采购方案报监理、总体设计单位、建设管理单位审批，II 类报监理、总体设计单位审批；
  I 类还另给供货单位的资格与业绩要求。
