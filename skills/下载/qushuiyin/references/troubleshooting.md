# 异常处理指南

## 图片处理

| 现象 | 原因 | 处理 |
|------|------|------|
| `⚠️ 无法读取：xxx` | 文件损坏或非图片格式 | 确认文件存在且为 jpg/png/webp/bmp |
| `⚠️ 未提供任何有效的水印区域` | 没传 `--box/--mask/--corner`，或区域超出画面 | 补上坐标参数；区域超出画面时脚本会提示 |
| `❌ 依赖安装失败` | 无 opencv-python/numpy 且 pip 安装失败 | 手动 `pip install opencv-python-headless numpy`，注意 python3 环境 |
| 修复后有残边/水印淡影 | 半径太小或掩膜不准 | 调大 `--radius`（3→5~8），加 `--alpha 2`，或改用 `--mask` 精修 |
| 修复后画面出现纹理失真 | 水印区域过大/背景复杂 | 如实告知用户效果有限；可换 `--mask` 只框水印本体 |
| 批量处理个别图效果差 | 每张图水印位置不一致 | 单张图分开指定坐标；整批共用同一区域只适合统一角标 |

## 视频处理

| 现象 | 原因 | 处理 |
|------|------|------|
| `❌ 未找到 FFmpeg` | 本机未装 FFmpeg | 按系统提示安装：macOS `brew install ffmpeg` / Linux `apt install ffmpeg` / Windows `winget install Gyan.FFmpeg` |
| `❌ 请指定处理模式` | 没带 `--box/--crop/--blur` | 按水印形态选择模式 |
| `❌ 未知参数` | 参数拼写错误 | 检查 `--box x,y,w,h`（逗号）与 `--crop 宽:高:x:y`（冒号）格式 |
| FFmpeg 报 `Option delogo not found` | FFmpeg 版本过旧/未包含该滤镜 | `ffmpeg -filters | grep delogo` 确认；brew 重装最新版即可 |
| 视频音画不同步/无声 | `-c:a copy` 对个别音频编码不兼容 | 脚本默认复制音频流，极少数情况可改用 `-c:a aac` 重编码 |
| 处理极慢 | 机器性能/视频时长 | 告知用户预计耗时；可加 `--preset faster` 提速（文件稍大） |
| delogo 区域偏了 | 坐标与画面实际水印不符 | 用 `--show` 调遮罩位置（见 coordinate-guide.md） |
| 裁剪后画面比例变化 | crop 改变了宽高比 | 属正常现象；如需保持比例让用户自行用播放器缩放 |

## 通用

| 现象 | 处理 |
|------|------|
| 用户给的素材是平台链接 | 说明本技能是本地去水印工具，不清平台分享链接；建议使用本地文件 |
| 用户要求上传第三方网站去水印 | 默认本地处理；用户明确要求且自担风险时才可提第三方方案 |
| 用户要求付费/购买次数 | 本技能免费，明确告知无需任何付费 |
| 处理失败但原因不明 | 保留原始报错给用户看，先自查坐标与依赖，再决定重试或建议其他方案 |
