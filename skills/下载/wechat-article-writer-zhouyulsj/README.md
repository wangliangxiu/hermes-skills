# 微信公众号写作 Skill

专为微信公众号定制的文章创作 Skill，支持 **4 种文案类型**（科普类/历史叙事类/学校宣传类/论文速递类），支持从素材（图片、大纲、模板）出发，生成符合公众号阅读习惯的完整文章。

---

## 功能概览

| 命令 | 功能 |
|:-----|:-----|
| `topic` | 选题分析，评估传播潜力，给出5个方向 |
| `title` | 生成10个多风格爆款标题备选 |
| `outline` | 构建完整大纲（含字数建议） |
| `write` | 撰写正文（科普/教育风格） |
| `polish` | 润色文稿，优化节奏和表达 |
| `format` | 排版格式化，输出可直接发布的 Markdown |
| `load` | 扫描素材目录（图片/文字/模板/大纲） |
| `start` | 一键完成全流程 |

## 文案类型选择

在使用 `write` 或 `start` 命令前，系统会先询问你要选择哪种文案类型：

| 类型 | 风格参考 | 适用场景 |
|:-----|:---------|:---------|
| 1. 科普类 | "丁香医生" | 健康科普、宠物护理、生活常识 |
| 2. 历史叙事类 | "卢克文工作室" | 技术发展史、产业变迁、国家叙事 |
| 3. 学校宣传类 | 党政办宣传干事 | 学校活动报道、教育成果展示 |
| 4. 论文速递类 | 学术科普大V | 顶级期刊论文解读、科研成果传播 |

每种类型都有独立的创作指令和排版规范，确保文章风格精准匹配。

## 快速开始

### 方式一：直接提供主题（会先询问文案类型）

```
start 为什么现代孩子越来越难专注？
→ 系统会先询问：请选择本文的文案类型（1/2/3/4）...
```

### 方式二：先加载素材（会先询问文案类型）

```
load C:\我的素材\量子纠缠科普
write 根据素材，写一篇面向高中生的量子纠缠入门科普
→ 系统会先询问：请选择本文的文案类型（1/2/3/4）...
```

### 方式三：只需标题灵感（不需要选择类型）

```
title 睡眠与学习效率的关系
```

### 方式四：优化已有草稿（不需要选择类型）

```
polish [粘贴你的文稿]
format [粘贴润色后的文稿]
```

## 脚本工具独立使用

除了在 AI 对话中调用，三个脚本也可以在终端独立运行：

### 素材扫描

```bash
python scripts/load_materials.py C:\我的素材\气候变化
python scripts/load_materials.py C:\我的素材\量子纠缠 --json
```

### 标题生成

```bash
python scripts/generate_titles.py --topic "睡眠与记忆" --style all
python scripts/generate_titles.py --topic "量子纠缠" --style number,story,authority --n 5
```

### 排版格式化

```bash
python scripts/format_article.py draft.md --output final.md
python scripts/format_article.py draft.md
```

## 素材目录规范

当你创建素材目录时，建议按以下命名规则存放文件，Skill 会自动识别：

```
我的素材/量子纠缠/
├── 模板-科普文章.md          ← 命名含"模板"→ 自动识别为模板
├── 大纲-量子纠缠入门.md      ← 命名含"大纲"→ 自动识别为大纲
├── 参考文献.md               ← 命名含"参考"→ 自动识别为参考资料
├── 量子纠缠概念解释.txt      ← 普通文字素材
├── 封面图.jpg                ← 图片素材
├── 量子纠缠示意图.png        ← 图片素材
└── 爱因斯坦照片.jpg          ← 图片素材
```

## 注意事项

1. **数据真实性**：Skill 不会捏造数据，如无法确认的内容会注明"建议核实"
2. **图片素材**：正文中用 `【配图：描述】` 标记，发布时替换为实际图片
3. **模板优先**：素材目录中有模板文件时，写作结构严格遵循
4. **字数控制**：每次输出后会标注实际字数，帮你控制篇幅
