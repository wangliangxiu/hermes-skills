## 使用者问过的概念
1. `for f in fruits` — f是临时变量名，随便起
2. `str` — string缩写，把数字转文字
3. `count` — 计数用的变量名
4. `+=` — 中间空格可有可无，count += 1 = count = count + 1
5. `def` — define缩写，定义函数
6. `result` — 结果，变量名
7. `add` — 加法，函数名
8. `#` — 注释符号
9. `with...as` — 固定句式，类比借书自动还
10. `utf-8` — 文字编码，不是时区
11. `r` — read，不是随便起的，是固定参数（⚠️ 容易误以为是不定代词）
12. `len` — length缩写，数个数

## 使用者对概念的理解难点
- **把 `"r"` 当成不定代词** — 需要区分"变量名可以随便起" vs "模式参数是固定写法"
- **print和f.write的区别** — 以为print的内容会进文件
- **相对路径vs绝对路径** — 第一次跑文件说"没看到txt文件"
- **全角/半角括号** — 多次出现 SyntaxError: invalid character '（'
