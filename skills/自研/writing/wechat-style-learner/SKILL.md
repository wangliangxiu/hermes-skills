# 公众号范文风格学习器

## 概述

你（LLM）不能真正"学习"新风格，但这个 skill 用**结构化分析+参考文件保存**来模拟学习效果。

每次用户给一篇范文链接，你执行：
1. 抓取文章内容
2. 按固定维度分析风格参数
3. 输出风格参数报告
4. 保存到桌面 `参考范文` 文件夹
5. 以后写文案时，加载这份报告，按参数写

## 触发词

- "学这篇的风格"
- "看看这个样式"
- "照这个风格写"
- "参考这篇"
- "像这样写"
- "按这个调调来"

## 工作流程

### Step 1: 确认用户意图

先确认用户想要什么：
- 是学一篇特定的范文？
- 还是已经有了，直接开始分析？

### Step 2: 抓取文章内容

**默认方法**：直接在终端运行分析脚本（推荐）：

```bash
python scripts/fetch_wechat_article.py <公众号文章URL>
```

该脚本自动完成：抓取 → 提取正文 → 分析风格参数（字数/句长/节奏/高频词/开篇/结尾/图片数）→ 保存报告到桌面 `参考范文` 目录 → 更新索引。

**手动抓取**（当脚本不可用时）：用 Python `urllib`，关键是 User-Agent：
- 使用移动端 Android + 微信内置浏览器 UA
- PC端 UA 会触发微信反爬验证
- 参考用 UA：`Mozilla/5.0 (Linux; Android 13; Xiaomi 13) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.6099.230 Mobile Safari/537.36 MicroMessenger/8.0.47`

如果抓取失败（环境异常/验证），提示用户手动复制粘贴文章内容，不要反复重试不同 UA。

抓取成功后，用正则 `id="js_content"[^>]*>(.*?)</div>` 提取正文。

### Step 3: 分析风格参数

从正文中提取以下参数并输出报告：

- **基本信息**：总字数、句子数、平均句长
- **开篇方式**：场景描写型/设问型/故事型/数据型/观点型
- **句子节奏**：长短句比例，是否使用排比
- **高频词**：去掉虚词后的 TOP20
- **图片数**：按HTML中 `<img>` 标签统计
- **结尾收束**：最后3句可读句

输出格式见下方报告示例。

### Step 4: 保存报告

保存到 `C:\Users\<用户名>\Desktop\参考范文\` 目录。

文件名格式：`{序号}_{风格标签}_{文章标题}.txt`

风格标签推断规则：
- 标题含"桥" → 文艺叙事
- 标题含"碑" → 历史叙事
- 标题含"商" → 商业叙事
- 标题含"鸟" → 生态叙事
- 标题含"树" → 生态叙事
- 其他 → 根据内容判断

保存完成后更新索引文件 `索引.txt`。

### Step 5: 写作时调用范文

当用户说"照XX范文风格写"时：
1. 从 `参考范文` 目录读取对应的风格参数报告
2. 按参数写：开篇方式匹配、节奏感匹配、升华手法匹配
3. **只模仿写法，不套用范文的事实和数据**

## 写作铁律（此用户专属）

### 第一原则：不编事实，不夸张

写作前**必须先问用户**确认的事实清单：
- 年份/时间点（如本地站哪年更名）
- 地名/站名的准确关系（如道清铁路和本地站）
- 人物故事（用户给了才能用，没给就留空或模糊处理）
- 具体数据（不说"增长了XX%""运输了XX吨"）
- 因果关系（不说"因为A所以B"的历史判断）

安全写法：用模糊表述替代——
- ✅ "20世纪初，第一列火车驶过豫北平原。从此，这片土地与铁路结下了不解之缘。"
- ❌ "1902年道清铁路通车后，本地的煤炭开始运往全国各地。"

**绝对化表述禁止**：永远不说"最XX"类的绝对化判断（最快、最大、最好、第一次），因为你不知道科技还能发展成什么样子。
- ❌ "而最快的这一次，终究来了"（你不知道后面还有什么）
- ✅ 直接写事实，不加程度副词。比如"2020年12月，太焦高铁开通运营"结束就好。

### 第二原则：描写克制，不堆画面

用户特别反感**冗余的感官描写**和**资料性说明的堆砌**。已被明确纠正的写法：

**1. 资料性说明能省则省**
- ❌ "道清铁路是河南省境内的第一条铁路。史料记载，它的修建让本地从'豫北荒僻之区'，逐渐成为'豫省西北之重镇'。"
- ❌ "从滑县道口镇到博爱清化镇"
- ✅ "道清铁路蜿蜒穿过本地的田野与村庄。黑色的运煤车，一列列从矿场驶向远方。"
- 规则：起止点、史料引用、"第一条"、"最XX"之类资料性句子，除非用户明确要求，否则一律不写。保留画面感的描写即可。

**2. 细节信息不赘述**
- 同一个信息在一段内只说一次。
- ❌ "黑色的运煤敞车"（"运煤"已经暗示了是敞车）
- ✅ "黑色的运煤车"
- 规则：读者能脑补的细节不写出来。说一次就够了。

**3. 综述性句子可以保留**
- 有些全局性的总结句（如"从此，这片土地与火车结下了不解之缘"），不会引起争议也符合画面感走向的，留。这些是文章节奏的一部分。
- 判断标准：这句话删了会不会让上下文断？不会 → 可以删。会 → 留着。

**4. 火车外观描写点到为止**
- ❌ 大段描写车身细节（黑色铸铁、铆接铁板、铁棍等）
- ✅ "还是烧煤的蒸汽火车头，喷着滚滚白烟，拖着一节节运煤的敞车驶向远方。"
- 公式：一句话说明"这是什么时代的什么车"即可

**5. 每一段都要有"存在的理由"**
- 写之前自问：这段话删掉，文章损失什么核心信息？
- 如果只是"让画面更好看" — 删掉
- 描写只服务于主题（铁路与城市的关系），不服务于画面

**6. 用词通俗，不用术语**
- ❌ "蒸汽机车" → ✅ "烧煤的蒸汽火车头"
- ❌ "空调列车" → ✅ "空调火车"（看上下文，但优先更通俗的）

### 第三原则：语气节制，不夸张

此用户是本地本地人，对家乡的描述要求克制。

**1. 程度不要夸大**
- ❌ "铁路上跑的全是蒸汽机车"（暗示满街都是）
- ✅ "铁路上偶尔驶过的火车，还是烧煤的蒸汽火车头"
- 原则：当时火车是稀有的，用"偶尔""零星""间或"

**2. 生活场景不要童话化**
- ❌ "早上在本地喝胡辣汤，中午到郑州办事，下午回本地接孩子放学"
- ✅ "去郑州办事、看病、转车，当天去当天回，不再是奢望"

**3. 不编人物引语**
- ❌ "XX老人回忆说…""XX企业负责人感慨…"
- ✅ 直接写客观事实。如果用户说"等我找找再写"，就先留空

### 第四原则：不要拔高，留在本地视角

- ❌ "一条铁路的收归，就是一个国家在屈辱中挺直腰杆的缩影"
- ✅ "而本地，正是在这样的夹缝中，开始了它的城市之路。"
- 升华只到城市层面，不跳到国家/民族层面（除非用户明确要求）

### 第五原则：不解释本地人已知的事

- ❌ "月山站不在市区，在博爱"（本地人不需要解释）→ ✅ "提起月山站，就会想起那个绿皮车慢悠悠穿过田野的年代"
- ❌ "它不是一个高铁站"（大家都知道）→ 直接删掉，保留情感记忆即可

### 第六原则：时间线严格按年代排列

- 人物故事必须放在正确的年代段落中（如1920年代的铁路工运不能放在1966年之后的绿皮车段落）
- 每个大时代之间用空行+小标题分隔
- 同一章节内的内容时间顺序必须一致

### 第七原则：人物故事服务于城市精神

不要干巴巴罗列人名和事迹。每个人物写入文章时须回答：
- **先辈/工运人物**（詹天佑、童昌荣等）→ 服务于**民族尊严**高度：在屈辱年代挺身而出
- **当代铁路人**（吕小科、贾朝辉等）→ 服务于**职业精神**高度：在平凡岗位守住责任
- 每个人物都要有情感落脚，如"在那个外国人说了算的年代，本地的铁路工人第一次有了自己的组织"

**人物写法公式：**
- 人物介绍凝练成两三句话，**不分段**
- 不要说空话：❌"事迹上过央视" → ✅"因默默坚守的事迹登上过央视"（有因有果）
- 如果用户提供了多个候选人物，优先选政府/官方报道过的——可靠度更高
- 人物之后接"还有太多像他这样的XX人"一两个短句，即刻转入升华

**升华写法要求：**
- 升华到城市整体精神的篇幅，要比单个人物描述的篇幅**更**长
- 格式：先辈怎么做 + 当代人怎么做 → 时代不同但精神一致 → 提炼一句城市精神口号
- 例："当年的先辈们为了民族尊严站出来，今天的铁路人在平凡的岗位上守着安全——时代不同了，但那股子劲儿没变。不认命、不怕难、守得住、做得成。一座火车拉来的城市，养出了一群推着火车往前走的人。"

### 第八原则：文章排版

- 不加"点击蓝字关注我们"等公众号引导语
- 开篇直接从正文第一句开始
- 分标题前的综述段落要紧凑：几句话在同一个段落里连贯地写，不要每句独立成段。三个短信息可以合成一段，中间用句号连接。
- 小标题用 `【】` 包裹，格式统一：`【时代名称 · 主题提炼】`
- 结尾金句单独成段
- 不使用"往期推荐""编辑部声明"等栏目尾巴
- 图片位置用 `【配图：描述】` 标记

这些范文的共同结构公式：
1. 钩子开篇（场景/引语/反问）
2. 进入主题（"XXX，就是YYY"式的定义句）
3. 分小标题展开历史纵深（3-4个小标题）
4. 每个小标题下有真实人物或具体事件
5. 结尾提炼升华，首尾呼应
6. 金句单独成段收束

## 注意事项

1. **不编故事** — 风格分析只描述范文事实，不添加虚构内容
2. **不编数据** — 参数报告中的数据必须是真实统计
3. **每次独立分析** — 每篇范文单独分析，不混用风格
4. **用户确认** — 分析完先给用户看报告，用户说"好"再保存
5. **写作时** — 严格按风格参数写，关键事实先问用户，不确定的用模糊安全写法
