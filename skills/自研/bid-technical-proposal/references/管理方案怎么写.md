# 管理方案怎么写（第二章最后一节）

> 结构以某市域铁路总承包标的实例为准，**专题哪些、多少个按本次招标文件要求定**；
> 本文里的专题名、流程图名都是举例。

## 一、三级结构

```
2.3 管理方案
  2.3.1 管理工作内容                      ← 管理模式 + 管理手段（开篇定调）
  2.3.2 管理工作重难点及措施流程           ← 按专题一个个写
      2.3.2.x 某专题（质量 / 安全 / 进度 / 风险 / 文明环保 / 接口 / 验收竣工 /
                     专业分包 / 劳务分包 / 前期专项 ……）
          x.1 该专题的**管理流程**（配一张"××管理流程图"）
          x.2 该专题的**重难点及措施**（先说本工程的重难点，再说措施）
  2.3.3 创优工作程序及创优措施
```

## 二、2.3.1 管理工作内容：先把管理模式摆出来

实例的写法 —— 先点明承包模式与两级管理，再列管理手段（这几条是可复用的"话术骨架"）：

- 本工程实行施工总承包模式，采取"**项目总承包部、工区项目部**"两级管理模式
- 总承包部通过"**目标管理、跟踪管理、平衡管理、预控管理**"加强对工区项目部的管理，
  并通过**每周例会**强化，及时沟通化解问题
  - 目标管理：对各工区提出总目标和阶段性目标，目标明确的前提下实施管理
  - 跟踪管理：保目标落实，跟踪及时发现和解决问题
  - 平衡管理：抓重点，使施工过程有重点、有条理（资源与工序平衡）
  - 预控管理：提前预判、事前控制（把问题消灭在发生之前）

## 三、2.3.2 各专题：一节两小节 —— "流程 + 重难点及措施"

**每个专题都按这个套路写**（实例 10 个专题都这么写）：

1. **x.1 管理流程**：一句话"××管理流程见下图" + **一张管理流程图**
   （流程图同样可以用工具出：Visio / 脚本生成；节点是"谁干什么、交给谁、卡在哪一步"）
2. **x.2 重难点及措施**：先写**本工程在这个专题上的重难点**（越具体越好：本标段特有的
   地层、构筑物、专业交叉、外围条件），再写**措施**（体系 + 制度 + 专项方案 + 检查考核）

实例里各专题的"重难点"抓法（可作参照）：

- **质量**：质量是管理、技术、人员、装备综合实力的体现，风险点在**质量通病** →
  按 GB/T 19000 建立现场质量保证体系 + 编质量通病防治措施
- **安全**：把本标段的**具体风险源逐个点名**（盾构侧穿高压塔、下穿河道与桥梁、下穿学校体育场、
  密集自建房与酒店、小区……）→ 多层次建立安全体系 + 编各种专项安全施工方案
- **进度**：本工程**交叉施工干扰多、协调难度大** → 科学策划、工期动态管理、总工期网络计划，
  据此定年/季/月计划；**工期预警制度**（滞后按严重程度分级管理）；劳动竞赛；
  重难点项目**领导挂牌督办制度**（工程管理部评审提出 → 总承包部研究确定督办项目与责任人 → 启动警报）
- **风险**：管理流程图 + 风险源清单与分级管控、应急预案、监测预警
- **文明施工与环境保护**：按国家、省、市及建设管理单位要求；标准化、信息化、环保达标；
  扬尘噪声、渣土、污水排放的具体做法
- **接口管理**：专业之间、工区之间、与外部单位之间的接口界面与责任划分（见前面接口那节）
- **验收和竣工管理**：分部分项验收、阶段验收、竣工资料、移交程序
- **专业分包管理**：分包选择、进场、方案审批、过程检查考核、退场
- **劳务分包管理**：劳务用工、实名制、工资支付、教育培训
- **前期专项工作的管理**：临时水电、管线迁改、绿化迁移、交通疏解、桥梁拆复建等的组织与协调

## 四、2.3.3 创优工作程序及创优措施

- 结构：**创优目标 → 创优工作程序（谁在哪一步做什么）→ 创优措施**
- **创优目标照招标文件的"质量目标 / 创优要求"写，不自己定级、不加码**（文件说要创什么就写什么；
  文件没提就不写具体奖项，只写"创建优质工程"这类与文件口径一致的表述）
- 程序一般：策划（编创优规划）→ 分解（把创优目标分解到分部工程与工序）→ 实施（工艺与验收标准、
  样板引路）→ 检查（过程验收与创优检查）→ 申报（资料收集、影像资料、报奖）
- 措施一般：组织保证（创优领导小组）、标准保证（高于验收标准的创优标准）、技术保证（工艺优化、
  四新应用）、资料保证（创优资料与影像同步）

## 五、自检

- 专题**一个不缺**（对照招标文件里"管理"类的要求逐条对；招标文件要什么专题就写什么专题）
- 每个专题都要有：**流程图 + 重难点 + 措施**，别只写措施不写重难点（没有重难点等于没分析）
- 重难点必须落到本标段的实际（点名具体的构筑物、专业、外部条件），不写通用套话
- 流程图与正文说的步骤要一致（图上没有的步骤别在正文里冒出来）
## 六、成套照用就行，功夫花在"前后照应"上

管理方案这套东西**基本上是成套的、通用的 —— 不用大幅度改写**，但必须做到**全文一个口径、前后不打架**：

- **承包模式与机构口径要一致**：前面写了"施工总承包、项目总承包部 + 工区项目部两级管理"，
  后面就不能冒出"单独的项目部模式""只有项目部没有总承包部"这种说法（**这是最典型的前后矛盾**）
- 同类的口径还有：机构与部门名称、层级数、工区数量与划分、岗位设置、工期节点与目标值、
  材料甲供 / 乙供口径、机械台数、专业分包范围 —— **同一件事全篇只能有一种说法**
- 参照往期标时更要当心：稿子里留着旧项目的模式、部门名、工区数，就会跟本次自己写的前文对不上
- **交稿前做一次"口径一致性检查"**：把关键口径列成一张小表（承包模式 / 机构与部门名 / 层级 /
  工区数 / 岗位 / 目标值 / 节点 / 材料供应方式 / 分包范围），逐个全文搜一遍，看有没有两处说法不同
## 七、别忘了"管理体系图"（参照稿常见缺项）

管理方案的质量、安全两节里，除了一张**管理流程图**，按道理还应各配一张**管理体系图**
（**质量保证体系** / **安全管理体系**）—— 参照稿（某实例）这两节只有流程图，体系图**单独放在
后面的质量章、安全章里**（这样也成立，不是缺项）。我们做的时候按本次招标文件/评分要求定位置：

- **别两头都没有**：要么在管理方案这两节里把体系图给出（体系框图 + 体系说明），
  要么明确放在后面的质量章、安全章里出 —— 但同一张图别重复出两处
- **体系框图里画什么**：方针与目标 → 组织机构（领导小组 / 各岗位职责）→ 程序文件与管理制度
  （技术、质量 / 安全、检查考核）→ 过程控制（施工准备、过程检查、验收）→ 反馈与持续改进
- 体系图常与"保证体系"文字配对：正文点明"按 GB/T 19000（ISO 9000）标准建立健全质量保证体系"
  这类依据，图跟着给
- 参照稿里体系图的位置分布（供参考）：质量保证体系在图后面第五章、安全管理体系在第六章、
  风险管理保障体系框图在第七章、文明施工与环保管理体系图在文明环保节、消防保卫健康保证体系图
  在第八章
- **位置以本次招标文件与评分要求为准**，招标文件在哪一节要求出什么图，就放哪儿
