# 全平台内容矩阵 / Omni Content Matrix

一个人做内容，最难的不是写，而是**把有限的时间摊到对的地方、还不被平台规则吃掉**。这份手册就是你的指挥部：给方向、给拆解、给排期，最后吐一份能直接照做的周计划。它没有团队代运营的复杂流程，只服务一种人——你一个人，或者一个小到不能再小的作坊。

---

## 先看你是不是卡在这些局面里

不用记触发词，对照一下就知道该不该翻它出来：

- 平台盯着十几个，却说不清这周该守哪几个、哪些先放一放。
- 刚写完一篇长文或录完一条视频，想让这一份投入在好几个地方同时生效。
- 每周就那么几个钟头，排期一写就超载，执行两天就崩。
- 后台数据堆了一堆，但看不出哪个平台该加码、哪个该收手。
- 有点粉丝了，却没跑通变现，或者想摸摸同行到底强在哪。

命中任意一条，就顺着下面的思路走，别自己从零搭框架——重复造轮子最费时间。

---

## 核心心法：把内容做成飞轮，而不是流水线

很多人把多平台理解成「同一段话发十遍」，那是搬运，平台会限流，读者也烦。真正好用的是下面这个闭环：

```
        做厚一条母内容
              │
              ▼
   按平台调性拆成不同形态
              │
              ▼
   投到最契合的 2–4 个平台
              │
              ▼
   回收数据 → 反哺下一条母内容
              │
              └───────────┐
                          ▼
              放大跑通的，砍掉不行的
```

关键就一句：**母内容越厚，能拆出的版本越多；版本越契合平台，回收的数据越真实；数据越真实，下一条母内容越准。** 它是一个会越转越快的轮子，不是一条从头干到尾的流水线。

## 一个完整跑通的例子（照这个思路套自己）

假设你是做「职场效率」的个人创作者，每周能投入 8 小时，现在零基础起步。我们走一遍：

**定盘**——按内容形态，你擅长写长图文和做清单，所以主平台锁「知乎 + 小红书」，公众号做私域沉淀，抖音暂缓（口播不是你的强项）。8 小时落在「标准档」，最多 3 个平台，刚好。

**取材**——本周核心钉死一个母内容：「如何用一套模板管理全年工作任务」。跑评分：搜索热度 5、互动潜力 4、创作难度 2 → 分数 = 5×4×(6−2)/125×100 = 64，本周备选偏上，可以上。

**裂变**——一条母内容喂三个形态：
- 知乎：长答「系统讲解 + 可直接抄的模板」，目标是搜索长尾和收藏；
- 小红书：9 页攻略卡片「一图看懂任务管理」，封面突出「省下每天 1 小时」；
- 公众号：长文 + 文末送同款模板，引导加私域。
母内容是一篇结构化长文，三个版本只是换了「钩子、封面、转化入口」，主题一字没动。

**投放**——周二产母内容，周三发知乎，周四发小红书，周五把核心做成一张图发公众号，周六回评+收问题，周日复盘。七步压成核心五天，符合 8 小时预算。

**校准**——一周后看 CSV：知乎收藏率明显高于小红书互动率，下次把母内容往「可收藏的体系化」再倾斜，小红书改为更轻的「单点技巧」切片。

**转化**——零粉起步阶段不上商单，先用免费模板换私信线索，验证大家是不是真想要这套方法，再决定做 9.9 的进阶版。

你看，全程没有「先开十个号」，也没有「每条都从零写」。这就是这份手册要你养成的肌肉记忆。

## 平台怎么选：先问自己能稳定产什么形态

比查大表更快的入口，是先看内容形态，再倒推平台——因为形态决定你累不累、起不起得来：

- **你写得动长图文 / 问答** → 知乎、公众号、今日头条、百家号。这四条吃搜索和信任，适合做长期资产，冷启动不算难。
- **你做得动中长视频 / 教程** → B站、西瓜视频。系统讲解、开箱测评在这里最自然，且能沉淀成搜索入口。
- **你擅长短视频 / 口播** → 抖音、视频号、快手。强钩子、强节奏、强场景，靠转发和完播跑量；视频号还能借微信生态白薅一波。
- **你擅长图文卡片 / 种草** → 小红书。攻略、清单、真实体验，收藏率是命门。
- **你爱聊观点 / 顺手接热点** → 微博、豆瓣。扩散和讨论为主，别指望它当主变现场。

找不到你的行业？**直接用上面这条分边就行**，不必硬归类。等跑顺了，再去看 `references/platform-rules.md` 里 12 个平台的详细卡（形态、定位、冷启动难度、商单门槛、黄金时段全在那）。

## 精力是硬天花板，别跟自己过不去

- 每周不到 6 小时：最多守 **2 个**平台，把一条母内容做透。
- 每周 6–12 小时：最多 **3 个**，母内容 + 一个搜索沉淀版 + 一个轻切片。
- 每周超过 12 小时：可以到 **4 个**，全形态铺开。

永远优先「一篇母内容能喂饱多个平台」的组合。代码里的 `MatrixPlanner.calculate_energy_budget` 会按你真实小时数换算，并且在总时间短时给关键项兜底——不会出现「某件必做的事排到 0 小时」的荒唐排期。

## 30 天从 0 到稳：一条不用动脑的启动路线

新人最容易卡在「第一天就想完美」，结果一周就放弃。照这个节奏走，第四周你就有东西可复盘了：

- **第 1 周｜定盘 + 只开 2 个平台**：用上面分边法锁平台，发 3 条母内容（不用多），先把发布流程跑顺。这周只求「能稳定产出」，不求数据。
- **第 2 周｜稳定节奏 + 开始一源多发**：同一条母内容拆 2–3 个形态发出去，并在每篇末尾埋一个私域入口（资料包/社群关键词）。开始攒私域线索。
- **第 3 周｜第一次认真复盘 + 试变现钩子**：导出 CSV 看哪个平台达标，达标的下周加码；同时放一个免费资料包，测大家愿不愿意留资。
- **第 4 周｜放大跑通的 + 补常青内容**：把第 3 周验证过的组合加量，用常青骨架补 1–2 条可持续选题，定下个月的方向。

更细的周动作、话术和 check 清单见 `references/launch-playbook.md`。

## 选题：先打分，再交叉挖，最后用常青库兜底

评分公式长这样（已修正，封顶 100，超出范围按 5 算不会崩）：

```
分数 = 搜索热度(1-5) × 互动潜力(1-5) × (6 - 创作难度(1-5)) / 125 × 100
```

分级很简单：≥80 优先做，60–79 本周备选，40–59 进题库待命，<40 先不碰。难度低、潜力高的「低垂果实」最该先做。

挖题三步：① 先翻内置行业选题库（`scripts/main.py` 的 `TOPIC_DATABASE`，21 个领域都有）；② 库里没有就用 **痛点 × 人群 × 形式** 交叉生成（痛点=不会/踩坑/浪费时间，人群=小白/职场人/宝妈，形式=清单/对比/避坑/案例）；③ 每条跑一遍分，按分排序。

怕枯竭？每个领域内置 3–4 个「支柱主题」，每周从这里挑 1–2 个做系列化——清单体、对比体、避坑体、案例体、问答体、复盘体随便套，不用临阵现想。

## 一条母内容到底怎么拆

记住：**一源多发不是复制粘贴，是换壳不换核。** 母内容可以是一篇长文、一条长视频、一次直播，甚至一个核心观点。拆的时候只动四样——形态、钩子、封面、转化入口——主题和价值纹丝不动。

每个平台最终给九项产出：标题、Hook（前 3 秒或首句）、封面思路、结构大纲、交付物、预计耗时、发布目标、黄金时段、行动号召。比如 B站那条：封面用对比图（左边「加班 3 小时」右边「10 分钟搞定」），大纲走「痛点场景 → 整体思路 → 分步实操 → 避坑 → 资料包」，CTA 是评论区置顶资料包关键词。标题和 Hook 的 12 平台写法在 `references/title-hook-library.md`。

## 投放、复盘、变现：三件让轮子转起来的事

**投放**别平均用力。把最厚的母内容给主平台，轻切片给辅助平台，私域承接永远放在最后一步。黄金时段这种细节别背，用的时候查 `references/platform-rules.md`，不同平台差很多（B站吃周末和晚间，知乎全天抢新问题，视频号吃午晚两个饭点）。

**复盘**靠你从后台导出的 CSV，不接任何 API。互动率 =（点赞+评论+收藏+分享）÷ 播放量——注意收藏和分享都算进去了，小红书这种收藏型平台才不会被低估。跨平台比的时候，有基准的平台达标就加码、掉太多就降频；**微博这种没稳定基准的，只展示数据、标「保持观察」，不参与加码判断**，免得瞎指挥。变量实验模板在 `references/experiment-templates.md`。

**对标**和**目标节奏**是锦上添花：提到同行就拆对方的选题/形式/标题/更新频率/变现方式，输出「你能抄哪 1–3 条、别硬抄哪几条」；设了「30 天涨粉 1000」这种量化目标，就对比两期数据算日均缺口，偏慢就建议你把精力压回主平台或换高潜力选题。

**变现**按粉丝分层走：千粉内用免费资料包验证需求和表达；千到万上 9.9–99 的小产品测付费；过万再叠中价训练营和高价咨询。从第一天就往私域导，别把命交给平台自然流量。发布前过一遍合规词库（最/第一/100%/稳赚/包过/加微信/国家级/万能/根治/零风险 这些），金融健康教育尤其容易踩强审核。

## 三个最容易让你前功尽弃的惯性

不是列八条禁令，就三条最致命的：

1. **一上来全平台铺开日更**——一人精力有限，先 2–3 个做深，质量永远胜过数量。
2. **一次改四个变量**——标题、封面、时长、转化入口同周全动，最后你根本不知道哪步有用，没法归因。
3. **数据差就立刻换方向**——同方向起码发 10–15 条再下判断，单条波动太正常，换太快只会永远在重启。

## 常见问答

**Q：我完全零粉新人，先开几个平台？**
A：两个，按你能稳定产出的内容形态分边，别贪多。先把发布流程跑顺比啥都重要。

**Q：一条母内容大概能拆几条？**
A：看精力档。极简档一条母内容 + 一个切片；标准档两主一辅；充裕档能铺满四个平台的不同形态。

**Q：数据不好要不要马上换赛道？**
A：别。同方向发满 10–15 条再做判断，单条扑街不代表方向错。

**Q：粉丝少能不能变现？**
A：先用免费资料包换私信线索，验证痛点和表达，别几百粉就接商单——那会反过来伤信任。

**Q：要不要追热点？**
A：不硬追。除非你本就做资讯向，否则顺手借势比硬蹭安全得多，也省时间。
