# 招标文件要查项清单（读标书时照着找）

**先分清两类**：【要查项】= 拿到招标文件后去这些地方看、找到什么算什么（本文都是这一类）；
【必有项】= 一定要有的内容，由使用者明确给出。
清单里出现的具体数值都来自宁扬那份，只是**示例**；新项目一律以手上那份招标文件为准——它怎么写就怎么办。

## A. 招标公告（第一章）要先标出来的

项目名称/标段名称 · 建设地点 · 建设规模（线路长度、车站数量、地下与高架各几座、站名、起讫点）·
合同估算价 · 工期要求（总日历天 + 计划开工/竣工日期）· 招标范围 · 工区划分及概况（几个工区、各几站几区间）·
招标人与招标代理及联系方式 · 资金来源/出资比例/批文号/项目业主 · 投标人资格要求（判断能不能投）·
招标文件获取时间与方式、图纸押金 · 投标截止时间 · 资格审查方式（资格后审/预审）· 评标方法

- 资金来源只是「项目投入资金从哪来」，投标方知道就行，不用考虑，也不写进投标文件
- 招标公告是整份文件的索引页：细则分别指向第三章（评标办法）、第七章（技术标准和要求）、第八章（投标文件格式）
- 公告里的「建设规模 + 工区划分」决定施组后面所有要分组的地方：组织机构、劳动力配置、各工区平面布置图

## B. 投标人须知（含前附表）要标出来的

- 是否允许分包（宁扬：允许，且点名几类必须分包给有相应资质业绩的单位）
- 要求澄清的截止日期 与 澄清文件发布日期
- 是否允许递交备选投标方案（口语「副标」）
- 其他编制要求：正副本份数、册数划分、装订方式、页数上限、是否暗标
- 投标保证金金额与形式、投标有效期
- 是否允许偏离
- **节点工期**：常写成「除总工期外，招标人还要求以下节点工期（如有）：详见第七章技术标准和要求」——
  要拐到技术要求里挖，挖出来落到施组进度计划那章的「关键节点工期计划/里程碑节点计划」
- 递交投标文件地点、开标时间和地点、投标截止时间（决定编制节奏：从截止往回倒，留出集体校核、
  印刷封装、现场送达或平台上传解密的时间；纸质递交还是远程开标，决定最后一天要不要派人跑现场）

## C. 评分环节怎么读

顺序：看分值构成（报价、施组、商务/资信各多少分）→ 把能确定的先算出来得基础分（信用分从企业数据库提取，
联合体取牵头人；商务分按岗位配齐基本能满）→ 开标公布各家报价后按评标基准价规则算报价分 →
剩下技术部分（施组）是唯一变量，反推自己技术分要拿多少。

- 三张评分表都在评标办法的附表里（宁扬：p51 商务、p52 施工组织设计、p53 投标报价，另 p54 市场信用评价）
- 报价分算法看基准价公式：宁扬是 基准价 = A×50% + B×50%（A=有效评标价算术平均，家数多时去掉最高最低；
  B=最高投标限价），报价等于基准价得满分，每低 1% 扣 0.5 分、每高 1% 扣 1 分，不足 1% 插入法
- 商务评分表不只看岗位齐不齐，还看**每个人的资格条件**对不对得上资历要求表（缺岗、人不满足都扣分）
  → 商务册里的人员汇总表、简历表要逐条对资历要求表

## D. 废标（无效标）条款：有的话必须遵循

**不是每份招标文件都有这类条款**，有的没有——没有就不适用，别当成本来就有的通用规则。
有的话，它比「拿多少分」更硬：评分是拿多拿少，红线是直接没资格。
宁扬那份叠了三层，都在第三章评标办法里：

1. 评标入围条件：保证金未足额、投标函工期超招标期限、质量标准不响应、报价高于控制价——占一条不再往下评
2. 初步评审（形式/资格/响应性）：一项不符合即作无效标；形式评审里单列一项「暗标：符合招标文件有关暗标的要求」
3. 无效标情形十条：弄虚作假、资格不符、投标文件雷同、明显不符合技术规范、关键内容模糊无法辨认等。
   与施组直接相关的两条——「施工组织设计存在明显技术方案错误、或者不符合暗标要求」、
   「承诺的盾构机到达时间不能满足招标文件工期要求」

## E. 人员与数字

- 资历要求表下面的备注常给**人数下限**（宁扬：总承包部≥30 人、正线 1/2/3/4/6 工区≥40 人、停车场≥25 人）。
  编排人员时不能低于这个数，也不能跟施组别处、商务册的人员表互相打架（投标文件数据不一致以纸质正本为准，
  这种矛盾得自己先消掉）。注意它是**管理人员**数，跟第十章「劳动力配置计划」的作业层劳动力不是一回事
- 岗位只许多、不许少：商务分按缺岗扣（总承包部每缺一岗 0.1 分、工区每缺一岗 0.2 分）
- 有的项目要求**工人自有率**：不用严格达标，但必须在施组里写上「我方自有工人比率是多少」
- 数字一律整数：拆不整就向上取整多写一个；总量已定死就在工区之间按工作量调剂（工作量小的 2、大的 3）
- 资历要求表能反推出组织架构：上级领导指挥部 → 项目总承包部（班子 + 职能部门）→ 工区项目部（班子 + 部门）→ 作业层

## F. 术语对照（招标文件用语 ↔ 项目上叫法）

- 项目负责人 = 项目经理
- 技术负责人 = 总工
- 工区负责人 = 工区经理
- 安全负责人 = 安全总监（资历表里总承包部写「安全质量管理负责人」、工区写「安全副经理」，合同罚则里写「安全总监」）

## G. 第七章「技术标准和要求」里已经写明的东西＝投标文件必须逐条体现

（本节是使用者明确过的【必有项】，不是要查项：招标人写出来就是要你答的，一条都不能漏。
本章有哪些小节仍要去本次招标文件里扫，别拿本节当通例清单。）

这一章常见小节与落点（页数只指路，值都是示例）：

- 2.1 工程概况 / 2.2 工程范围（标「工程范围一览表」：每个车站、区间的工法与规模）→ 施组的项目介绍
- 2.3 工区划分及概况：逐工区（宁扬 01~06）写明含哪些车站、哪些区间、起讫里程、周边环境与控制因素
  - 工区数量由标的规模决定：大标（几十亿）才分几个工区；地铁、铁路标一般一个项目 10 亿上下，
    房建、市政标按实际情况
  - 工区划分由招标人定，承包商不允许调整（文件常带注：招标人可按管理需求增减工区，
    承包商无条件执行、不提费用要求与索赔）
  - 落点：组织机构（工区项目部按给定工区数设）、劳动力与机械配置、进度计划、各工区平面布置图都按工区配
- 2.4 工程重难点（表）：按车站 / 区间 / 车辆基地逐个列「自身风险 / 环境风险 / 前期拆改难点」，
  每行带「设计控制措施」和「施工要求」两列
  - 写法：先按自身风险、环境风险（有前期拆改难点的单列一类）逐条描述，再写对应的应对措施，
    一条风险对一个措施，别写成一段笼统的话
  - 「设计控制措施」是设计口径，不要原样抄来当自己的对策（评的是施工对策）
- 2.5 工作内容：建筑工程 / 安装及装修 / 前期工程 / 市政配套 / 甲供材料 / 乙供材料 / 其他工程 / 其他工作
  - 甲供材料（招标人供应实物）：采购、订货、供货商管理、供货进度不是承包商的活，**不写**；
    写接收、进场验收、质量检验（复验）、报验、保管、成品保护、安装 / 预埋及其质量验收
    （例：甲供桥梁支座 → 不写采购，写支座检验与质量验收方案）
  - 乙供材料：采购、进场检验、报审、标识、堆放保管整套都要写
- 2.6 接口管理：单列一章或一节；有要求必须写，没要求也尽量写（体现总承包协调能力的点）
  - 接口＝工程空间上的衔接，跟施工缝一样（使用者原话）：两个单位 / 专业 / 工序在空间上接头的那条缝
  - 写清三件事：谁干、什么时候办交接、交完谁管。工程接口（前期工程、机电安装与装修、系统设备、
    轨道工程、预埋槽道、市政交通）与管理接口（建设管理单位、监理等咨询、当地政府）分开写
  - 实体例子：主体结构预留预埋与孔洞封堵、管内穿放镀锌铁线、车站外通信人孔、集水坑与泵房间预埋钢管
    由土建承包商施工、盾构井回填要满足道床混凝土标高、轨行区与铺轨基地移交（属地管理权移交）
  - 有的标里本标段承包商还是全部前期工程的「总牵头人和总协调人」（别人进你围挡施工你配合给条件，
    配合费含在你报价里）
- 2.7 材料供应方式（甲供 / 乙供、I 类乙供材料的专门要求）→ 落到材料那章
- 2.8 工程目标（安全、质量、工期、文明施工、绿色环保）→ 逐条对着写
- 3 技术规范、标准 / 4 通用技术要求（前期专项工作管理要求：临时工程与设施、临时用电用水、临时道路、
  临时用地、驻地建设、工地试验室、管线保护拆除改移、建构筑物与财产保护、文物古树保护、
  施工期间交通组织；施工现场管理要求：施工准备、劳动用工、机械管理、施工测量与监测、进度管理）
  → 写对应章节时照它的要求写，别自创

## H. 第五章工程量清单末尾的《工程量清单项目及计算规则》附表

- 位置：工程量清单那一章的最后（宁扬：p192 起），按工法分节——明挖（盖）挖 / 盾构区间 / 梁桥拆复建 /
  前期专项工程 / 高架区间 / 高架车站 / 单价措施项目 / 总价措施项目 / 其他项目清单
- 每节按「序号 / 项目编码 / 项目名称 / 项目特征描述 / 计量单位 / 工程量计算规则 / 工作内容 / 备注」列
- 用法一：节内一级项目的排列顺序**就是施工顺序**（例：明挖＝围护结构 → 土石方工程 → 主体结构 →
  防水工程 → 杂散电流及综合接地；梁桥拆复建＝拆除 → 基础 → 下部结构 → 上部结构 → 附属 → 桥面铺装 → 便桥）
  → 施工方案那一章按这个顺序写，不用自己猜
- 用法二：「工作内容」列＝这道活包含哪些工序，拿来给施组查漏
- 前期专项工作就照「前期专项工程」那节的开项写（道路破除、道路恢复、交通导改、管线迁改、园林绿化）
