# 面包板接线零基础指南

> 写给完全没碰过电子元件的新手。不需要任何基础。

## 面包板长什么样

## 面包板是怎么连的（核心规则）

1. **每行左右各5个孔是相连的**（中间凹槽断开）
   - 比如 a1-b1-c1-d1-e1 这5个孔在内部是连通的
   - 同样 f1-g1-h1-i1-j1 也是连通的
   - **但是** e1 和 f1 之间被凹槽隔开，**不通**
   
2. **上下两条长母线是连通的**
   - 红色/标 `+` 的那一整条，所有孔都连通
   - 蓝色/标 `-` 的那一整条，所有孔都连通
   - 通常红色接 **3.3V（电源正极）**，蓝色接 **GND（地/负极）**

3. **不同行之间不通**
   - a1 和 a2 是不通的，必须用杜邦线连

## 第一步：把开发板插到面包板上

> ⚠️ **先别着急插！先看面包板有几列（列数 = 最右边最大数字）**

面包板常见的两种规格：
- **小号（22列）**：a1~j22，共22列×10行=220孔
- **大号（30列）**：a1~j30，共30列×10行=300孔

**用户确认你的面包板是几列的（看最右边那个数字），后面好规划屏幕位置。**

1. 拿起 ESP32-S3 开发板（USB口朝外）
2. 找到面包板中间的凹槽（一般位于 d~e 或 e~f 之间）
3. **跨过凹槽**插下去，让开发板两排针分别在凹槽两侧
4. 这样：
   - 一排针在 a1-e1 那侧
   - 另一排针在 f1-j1 那侧
   - 中间凹槽正好让两侧不短路

**注意**：开发板的两排脚之间通常隔了1~2条凹槽（面包板中间有d-e或e-f之间的沟，以及f-g或g-h之间的沟）。插好后，查看开发板引脚标记，从a1开始报引脚名，确认哪排对应哪排。

**技巧**：如果开发板排针未焊接，可以直接将排针插入面包板孔中，面包板夹紧力足够临时固定。

**重要**：USB口要朝面包板边缘方向，方便插线。

## 第二步：接电源

用一根杜邦线（公对母，就是一头针一头孔）：
- 开发板的 `3.3V` 脚 → 插到面包板红色母线的任意一个孔
- 开发板的 `GND` 脚 → 插到面包板蓝色母线的任意一个孔

这样整条红色母线都有了 3.3V，蓝色母线都有了 GND。

## 第三步：接屏幕

> ⚠️ **接屏幕线之前，先让用户念一下屏幕排针旁边的丝印文字！** 不同模块的排针顺序不一样，不能猜。

屏幕是排针的，它自己有 8 个脚。**先问用户**屏幕排针从左到右印的是什么字。

### 本会话确认的顺序（供参考）

用户念的顺序是：**GND, VCC, SCL, SDA, RES, DC, CS, BLK**

（详见 `references/st7789-module-pinouts.md`）

### 两种接线方式

**方式A：直接接线（最简单）**
拿公对母杜邦线，母头插屏幕针，公头直接插开发板的对应脚。
不需要经过面包板中转，就是线会比较多。

**方式B：通过面包板中转**
屏幕插在面包板右侧空位（比如 j 排靠后的列），用杜邦线从面包板连到开发板。

下面是方式A的接法：

| 屏幕脚 | 线色 | → | 开发板脚 |
|--------|:---:|---|---------|
| GND | ⚫ 黑 | → | GND |
| VCC | 🔴 红 | → | 3.3V |
| SCL | 🟠 橙 | → | GPIO14 |
| SDA | 🟣 紫 | → | GPIO13 |
| RES | 🔵 蓝 | → | GPIO12 |
| DC | 🟢 绿 | → | GPIO11 |
| CS | 🟡 黄 | → | GPIO10 |
| BLK | ⚪ 白 | → | GPIO15 |

### 操作建议（针对零基础）

**一根一根来！** 不要一次性告诉用户所有线，容易晕：
1. 先接供电线（GND 和 VCC）
2. 用户说「好了」
3. 再接一根信号线
4. 用户说「好了」
5. 重复直到接完

### 如果屏幕插在面包板右侧的空列

用户可以先确定面包板最大列数（比如30），然后把屏幕插在右侧空列：
- 比如大号30列面包板，开发板在1~22列，屏幕插在 j23~j30
- 这样空间充足，互不干扰

## 什么叫"排针的"

屏幕背面有一排金属引脚（叫排针），像梳子齿一样。排针模块的意思是：
- 屏幕焊在一块小电路板上
- 电路板边缘伸出一排针
- 杜邦线的母头（孔）可以直接插到这些针上

## 常见问题

**Q: 面包板上的孔太紧了插不进去怎么办？**
A: 正常，新面包板都紧。稍微用点力按住插进去。

**Q: 开发板两边都有针，但我只用了其中一边？**
A: 正常。ESP32-S3 开发板只有一侧的针是信号脚，另一侧也有电源脚，但用的时候按需要接线就行。

**Q: 杜邦线怎么分公母？**
A: 
- **公头**：一根针露在外面（像针一样）
- **母头**：有个孔可以插针（像插座一样）
- 屏幕排针 → 用杜邦线母头插
- 开发板排针 → 用杜邦线母头插
- 面包板上的孔 → 用杜邦线公头插

所以一般用的都是 **公对母杜邦线**，一头插模块，一头插面包板。

**Q: 接好线之后怎么知道接对了？**
A: 写好固件烧录进去，屏幕亮了就对。如果不亮，最可能的原因：
1. 线没插紧（松了）
2. 线插错孔了（对照上面的表检查）
3. 屏幕的 BL（背光）没接好

## 极简清单（新手接线必备）

- [ ] 面包板 1 块
- [ ] 公对母杜邦线 约 10~15 根（推荐不同颜色好区分）
- [ ] 开发板的 3.3V → 红色母线
- [ ] 开发板的 GND → 蓝色母线
- [ ] 屏幕 VCC → 红色母线
- [ ] 屏幕 GND → 蓝色母线
- [ ] 屏幕 CS/DC/RST/MOSI/SCLK/BL → 各自对应的 GPIO
