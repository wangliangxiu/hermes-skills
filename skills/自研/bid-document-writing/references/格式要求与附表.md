# 格式要求与附表

> **声明：本文里的数字、面积、间数、天数、表名、章节号、项目名都是举例**（取自某一份招标文件），
> 不是通用要求。写的时候一律按**本次招标文件**的原文来 —— 它怎么写就怎么办，没有就不用管。

来源：招标文件"投标文件格式"那一章（技术部分格式、附表、编完之后复查）。

### 附表那几张表：格式原封不动照抄

格式要求那一章跟的附表（例：拟投入主要施工机械表、试验 / 测量 / 质检仪器设备表、
建（构）筑物保护 / 管线保护 / 管线拆除 / 管线改移表、交通导改表、临水引入表、
临时用地及地上物拆迁表、临电需求表、拟投入大型机械情况说明），**一律照本次招标文件的格式照搬**
（不是固定套路：有几张表、长什么样、有没有这些表，都按本次文件来）。
**唯一可以自己动的只有表格里的行数**（数据几行按自己情况增减），其余一律不改 ——
列、列名、表头分格与行高、单位与大小写、表格外那行小字、表后的注 / 说明 / 备注及其缩进与位置。

具体到每一处：

- 有几列、列名称叫什么、表头怎么排 —— 一律照抄；**表头的分格（合并 / 拆分单元格）结构也要一模一样**。
  就照这个格子结构画，别自己合并成一格、也别另起一套分法（这种分格结构也是格式要求的一部分）。
  **分格要精确到行高（横跨几列、纵跨几行都要对上）** —— 还是"数量（台）"这块：它下面横向拆成
  "小计"和"其中"；**"小计"这一格是两行高（纵跨两行）**，因为它右边第一行是"其中"、
  第二行是"自有 / 新购 / 租赁"，"小计"要跟这两行整体齐平；"其中"占第一行，
  第二行横着分"自有 / 新购 / 租赁"三格。行高、合并方式照着它一格一格对。
  **落笔时把每格的跨列数、跨行数标出来**（按"横跨几列 × 纵跨几行"记），就不用再猜：
  拿"拟投入本工程主要施工机械表"这张举例（**列数、表头、分格一律按本次文件那张表，别照这里的数**）——
  表头 3 行、共 10 列：
    序号 / 机械名称 / 规格型号 / 额定功率(Kw)或容量(m3)或吨位(t) / 厂牌及出厂时间 / 新旧程度(%)
      → 各 1 列宽 × 3 行高（表头三行整块合并）
    数量(台) → 4 列宽 × 1 行高（横跨 小计 + 自有 + 新购 + 租赁 那 4 列）
    小计 → 1 列宽 × 2 行高（跨"其中"那行和"自有 / 新购 / 租赁"那行）
    其中 → 3 列宽 × 1 行高（横跨 自有 / 新购 / 租赁 三列）
    自有、新购、租赁 → 各 1 列宽 × 1 行高
  （量到这一层，照着填格子和排宽度，出来的表就跟招标文件一模一样）
- **表格外左上角或右上角那行小字（"注：……""备注：……"）也要一字不改抄下来** ——
  它不是多余说明，是填表口径（例：格式 1 的表外写着"注：新购和租赁为投标人计划在本工程中新购或租赁的数量"；
  格式 3-1 写着"备注：本表的构筑物不包括管线"；盾构机明细表那页写着"注：……（2）本表适用于本工程 1、2、6 工区"）
- 表名、格式编号（格式 1、格式 2……）照排；文件里把一张表拆成几小张的（3-1 建（构）筑物保护表、
  3-2 管线保护 / 管线拆除 / 管线改移表）就照它拆
- 这种表要做几张，看**类型**不看台数：**同一类型的合并到一张表**，类型不同才各做一张。
  例（"拟使用盾构机主要情况详细表"）：先看这份文件里哪些工区用盾构（表后注写了适用范围），
  再数盾构机有几种类型 —— 都是同一规格的就合成一张，有大小盾构之分就做两张。
  既不是"一台一张"，也不是"一个工区一张"。
- **表后（文件后面）跟着的"注 / 说明 / 备注"也要一起加上**，别只抄表格就完事 ——
  这些注常常就是填表口径或执行口径（例：危大工程清单表后面的"说明：是否超过一定规模依照实际施工状况
  加以调整"；格式要求章末尾"所需的用款计划格式由投标人自定，但不得出现投标报价的数额"）。
  一句一条照抄，位置也照它放（在表格下方就在下方）；**缩进也照它** —— 这类注常常是首行缩进两个字符
  （跟表格左边缘对齐后缩进两字），别自己顶格写，也别改成居中
- **表头里的单位、大小写也完完全全按它来，一个字都不能改** ——
  文件写 "额定功率(Kw)" 就写 Kw，别自作聪明改成 kW；写 "m3" 就别改成 m³；
  百分号、括号用半角全角、单位是(t)还是（t）都照原样。这些地方"看着像笔误"也照抄 ——
  改动了就不叫按格式要求编制了
- 要填的行数、数量按自己情况填，但**表结构与表内表外的文字（含单位与大小写）一律照抄**

## 编完之后：拿"投标文件格式"那一章当检查清单再核一遍

投标文件格式那一章从头到尾都是格式要求，编完之后要**照它逐条检查**，查出问题提醒编标人员：

- 技术部分格式：施组编制要求那份内容清单（逐项有没有）、附表（格式 1~8 有没有出齐、格式对不对）
- 经济部分格式
- 商务部分格式：投标函、投标函附录、法定代表人身份证明、授权委托书、投标保证金资料、投标人基本情况表、
  联合体协议、投标安全承诺书、各类承诺书、类似工程业绩汇总表、项目部组织机构框图、项目部职能划分表、
  主要人员汇总表与简历表（总承包部 / 工区 / 指挥部）、工区负责人业绩表、拟分包工程情况表、
  商务合同条款响应表、**技术部分响应偏离表**、控股管理关系说明、盾构机情况表、需补充的资料……
- 其中"技术部分响应偏离表"是硬要求：**要对"技术标准和要求"的全部内容逐条响应**（完全响应 / 有偏离 / 偏离简述），
  等于又逼着把第七章从头到尾过一遍 —— 技术标写完不等于完事，这张表也要填出来
- "盾构机情况表"里要选供应方案（新购 / 自有 / 租用）、填制造商与主要技术指标 —— 这正是要跟机械部门、
  设备厂家核实的内容，别自己猜
