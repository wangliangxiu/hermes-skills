# 大模型学习计划 Excel 表格生成参考

## 表格结构

**文件夹：** `C:/Users/使用者/Desktop/大模型学习计划/`

**文件列表：**
- `00-总表.xlsx` — 6个阶段概览，每阶段一行
- `01-Python基础.xlsx` — 11项详细内容
- `02-数学基础.xlsx` — 6项
- `03-机器学习入门.xlsx` — 8项
- `04-深度学习.xlsx` — 7项
- `05-大模型核心.xlsx` — 12项
- `06-工程与面试.xlsx` — 7项

**每份表格的列：** 阶段 | 学习内容 | 完成✓ | 完成日期 | 备注

## 样式参考

- 表头：白色粗体，蓝色背景（#4472C4），居中
- 已完成行：✔️ 用绿色（#C6EFCE），文字绿色（#006100）
- 各阶段颜色不同：Python基础浅蓝、数学浅绿、机器学习浅橙、深度学习浅灰、大模型浅黄、工程浅紫
- 冻结首行 + 自动筛选

## 更新方式

用临时 Python 脚本（openpyxl），每次生成后删除脚本：
1. 读取现有表格（或重新生成全部）
2. 在对应行列打 ✔️ + 填写日期
3. 保存
4. 删除临时脚本
