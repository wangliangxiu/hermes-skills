# 人员与资源配置

> **声明：本文里的数字、面积、间数、天数、表名、章节号、项目名都是举例**（取自某一份招标文件），
> 不是通用要求。写的时候一律按**本次招标文件**的原文来 —— 它怎么写就怎么办，没有就不用管。

## 人员与资源配置

- 职责别自己编：照"技术标准和要求"里"项目总承包及工区管理要求"那节列的要求写
  （例：总承包部"授权管理、协调配合、全面管控"、建立健全组织架构与管理体系、部门级岗位设置齐全、
  制定前期 / 进度 / 安全 / 质量 / 风险 / 文明施工各项管理制度、对工区监督检查与考评、编制综合应急预案、
  按月计量签认与资金需求计划；工区项目部按"组织机构精干高效、施工队伍专业精炼、机械设备装备精良、
  现场布置管理有序、生产资源优化配置"组建，对本工区安全质量工期负责）
### 组织架构怎么摆（常见的一套）

按**投标单位（自家公司）的实际组织**来定，同时对着招标文件的人员要求配 —— 一般就是这么几层：

1. **项目经理**（投标文件里叫项目负责人）—— 一个，项目第一责任人
2. **领导班子 / 项目管理层**（使用者 2026-09-16 给的常见构成与排序）：
   **项目经理（最大）→ 技术负责人 → 安全负责人 → 项目副经理 → 总经济师 → 总会计师 → 总机械师**
   —— 这层是管理层。**有的项目没有其中某些（如总机械师、总经济师），按本次招标文件来定**，
   招标文件没要求的别硬加
3. **各个功能部室**（职能部门）：工程技术部、安全质量部（安质部）、物资设备部（机料部）、
   计划合同部（计合部）、财务部、综合办公室（党群 / 后勤 / 协调），视项目再加试验室、测量队、
   信息（BIM）管理岗等
4. **往下再分层**：工区项目部（**招标文件划了工区才设** —— 例：某标分 6 个工区，就设 6 个工区
   项目部；没划工区就不设这一层，别虚设**）→ 作业队 / 班组（要求细到施工队层级就写到那层）

完整的一条链（从上到下）就是这样，画框图、写职责都照它展开：
  项目经理 → 项目领导班子（技术负责人 / 生产副经理 / 安全总监 / 商务、财务负责人）→ 项目各部室 →
  （划了工区才有）**工区经理（工区负责人）→ 工区领导班子 → 工区各部室 → 各施工队 → 各工班组**

写法两步：**先框图、后职责** ——

- 先给组织机构框图（招标文件常直接给"项目部组织机构框图"格式表，要"含总承包部及工区项目部、
  详细到施工队层级"就按要求画）
- 再逐个岗位 / 部室写职责：职责照招标文件里"项目总承包及工区管理要求"那类条款写，别自己编；
  岗位只许多不许少（有的项目按缺岗扣分），人数不低于资历要求表下的下限
- 层级名称（总承包部 / 工区项目部 / 指挥部）按本次承包体制定，**不是总承包制就不出现"总承包部"**

### 岗位与职能划分怎么写

**形式**：两张东西 —— **岗位职责**（逐个岗位写清楚干什么）＋ **职能划分表**（用表格，一行一个部门/岗位）。
招标文件常直接给格式表（例：某标第八章商务部分格式里的"项目部职能划分表"，列是
序号 | 总承包部（岗位部门 / 职能划分） | 工区项目部（岗位部门 / 职能划分））—— **有格式表就照它的列来**。

**内容怎么切**：

- **横向按部门切**（每个部室管什么）：工程技术（方案与技术交底、测量、试验、BIM/信息化）、
  安全质量（安全体系与检查考核、质量验收与创优）、物资设备（材料采购供应、机械设备）、
  计划合同（进度计划、计量支付、合同与分包）、财务（资金与成本）、综合办公室（后勤、对外协调、
  党群、资料档案）
- **纵向按岗位切**（谁分管哪块）：项目经理——全面负责；技术负责人（总工）——技术、质量、方案；
  安全负责人（安全总监）——安全与文明施工；项目副经理——现场组织与进度；总经济师——经济、
  造价与合约；总会计师——财务与成本；总机械师——机械设备与装备（**本项目没有的岗位就不写**）
- 每条职能写成"**动词 + 对象**"：组织编制……、审核审批……、监督检查……、对外协调……，
  并写清**对谁负责**（对项目经理 / 对上级公司 / 对建设管理单位与监理）

**对照招标文件自检**（评分点常用语）：

- "部门级岗位设置齐全、职责分工明确" → 部门一个不缺、职责不重叠不留空
- "各部门职责划分、管理制度合理可行" → 除职责外配一两句对应管理制度
- 岗位只许多不许少，人数不低于资历要求表的下限

- **机构层级看承包体制**：招标文件要求总承包（一个承包商管全标段、再分若干工区）才有
  "总承包部 / 总承包项目部 + 工区项目部"这层；**不是总承包制，全文就不能出现"总承包项目部"这种称谓**。
  层级、叫法都照本次招标文件的组织要求和公司实际的组织来 —— 而且**全文统一**：
  架构章改了，后面质量、安全、进度、协调配合各章里"总承包部负责……"的句子也要一起改，别只改一处
- 按主要人员资历要求表画三层框图：上级领导指挥部 → 项目总承包部 → 工区项目部，
  再逐岗补职责（评分点常写"部门级岗位设置齐全、职责分工明确"）；
  工区项目部按招标文件给的工区数设（给了几个工区就设几个）
- 机械这块：招标文件把数量都写明了的（例：每个盾构区间逐个标注"2 台盾构机""1 台盾构机"），
  就照它配、不能少；写之前提醒标书编制人员跟机械部门 / 设备厂家核实台数、机型与到场时间
  （盾构机到达时间不满足工期，有的项目直接算无效标）
- 岗位只许多、不许少（有的项目按缺岗扣分）；人数不低于资历表下的下限；
  人员的资格条件也要一条条对得上（不只查岗位齐不齐，还查人）
- 数字取整：拆出小数就往上取整、多写一个；总量已经定死就在工区之间按工作量调剂（小的 2、大的 3）
- 有自有工人率要求的，把自有工人比率写上（不严格要求达标，但要答上这点）
- 施组里的人数要跟商务册的人员表一致，不能两套数

### 组织机构图怎么出

- **形式**：A4 横向一张框图，标题"××项目部组织机构框图"，方框圆角、直角连线，从上到下分层
- **层级**：项目经理 → 领导班子 → 各部室 →（划了工区才有）工区项目部 → 工区经理 / 工区领导班子 /
  工区各部室 / 各施工队 / 各工班组
- **可以机器出图**：本技能带了脚本 `scripts/org_chart.py`（matplotlib 画，一次出 PNG + SVG）——
  改脚本里的层级与文字即可；PNG 直接插进 Word，SVG 是矢量、能再编辑改字
- 要"能直接在 Word / PPT 里改字"的，用 python-pptx 出方框 + 连线的可编辑版；要更精细的排版，
  用 HTML + SVG 画好再截图
- 字体按本次要求定（常见：标题黑体、框内仿宋或宋体），字号别太小（插进 A4 后能看清）

### 用 Visio 出图（本机可行，2026-09-16 已验证）

本机装了 Visio（Office16，`C:\Program Files\Microsoft Office\Root\Office16\VISIO.EXE`），
Python 有 pywin32 → 可以用 COM 自动化直接画，产出 **.vsdx 原生文件**（使用者后期能在 Visio 里改）。

- 脚本：`scripts/org_chart_visio.py`（改参区即可复用）
- 关键点：`wc.Dispatch('Visio.Application')` → `Documents.Add('')` → `DrawRectangle` / `DrawLine`
  （**坐标是英寸**，mm ÷ 25.4）→ 形状里设 `Rounding`（圆角）、`FillForegnd`、`Char.Size`、
  `Char.Font`（`doc.Fonts.ItemU('微软雅黑').ID`）、`VerticalAlign`/`Para.HorzAlign` 居中；
  `Page.Export(路径.png)` 逐页导图；`doc.SaveAs(路径.vsdx)` 存原生文件
- 页尺寸：`PageSheet.CellsU('PageWidth').FormulaU = '420 mm'`（A3 横向）
- 连线画法（使用者教的，务必照做）：每排**上面一根横线**（由上一排的单线喂入，每格竖线接上去）
  ＋ **下面一根横线**把这一排收口（每格底边竖线接下去）＋ **从下横线中间一根单线**接到下一排的上横线
  —— 这样上下排层层连通，中间干线也不会穿方块
- 只画框图/流程/平面示意这类"线条图"没问题；真正的施工详图（图签、比例尺、图层、尺寸标注）
  做不了，那还得专业人员在 CAD 里画
- **坑（务必记住）**：`Dispatch('Visio.Application')` 会**接管已经打开的 Visio 实例**，
  脚本结尾 `app.Quit()` 会把使用者正在看的 Visio 窗口一起关掉；写新文件前先确认同名文件没被占用，
  或者干脆先关掉 Visio 再跑脚本 / 跑完再打开给他看
- **末端不收口**：树状图**最下面那一排不画下横线**（它已是末端，下面不接任何东西）——
  只有中间各排才"上横线进 + 下横线收 + 中间单线下接"

### 现成的组织机构图长什么样（照它复用，不用从头画）

从一份真实投标施组里抠出来的两张图（Visio 源文件都在，见"图库"），版式是这样 —— 直接照这个版式复用：

**版式要点**

- **最上面一个方框**：项目名称 + 机构名（例："××工程（扬州段）土建施工项目总承包部" / "……土建施工工区项目部"）
- **三层横排，右侧竖排标注层名**：**领导层 / 管理层 / 作业层**，每层用**虚线大框**圈起来
- 连线：每层上方一根横线（总线），各框用竖线接到横线；层与层之间一根单线中接
- 领导层里 **经理与书记并排**（项目书记 / 工区书记），旁边挂一个**专项组**方框
  （总承包部是"专家顾问组"，工区是"科技攻关组"）
- **作业层**：总承包部这张写成"土建 01 工区 …… 土建 06 工区"（**有几个工区画几个**）；
  工区这张写成"各专业施工队"一行（不再往下铺班组，保持图面清爽）

**两张图的岗位（实例，照本次文件取舍）**

- 总承包部：项目经理、项目书记｜技术负责人、安全负责人、总经济师、生产副经理、前期副经理、
  总机械师｜工程管理部、安全环保部、前期工作部、物资设备部、计划合同部、财务部、工地试验室、
  综合办公室｜土建 01~06 工区
- 工区：工区经理、工区书记｜技术负责人、安全副经理、商务副经理、生产副经理、**盾构副经理
  （标注"01、02、06 工区"）**｜工程管理部、安全环保部、前期工作部、物资设备部、
  **机电部（标注"仅盾构工区"）**、计划合同部、财务部、综合办公室｜各专业施工队

**复用做法（能少改就少改）**

- 拿现成的 .vsd / .vsdx 源文件 → 在 Visio 里改**项目名称与工区划分**即可；
  岗位有增减就删/加框，层名与虚线框照旧
- 只有图片（EMF）时：插进 Word 后"取消组合"再改字（EMF 是矢量，改完还是矢量）

### 攒一个自己的"施组图库"（做一次，以后省事）

**做法**（可复用，一次攒好长期用）：

1. 拿一份内容全的往期投标施组（.docx）——里面的图多数是**嵌入的 Visio 对象**
2. 把嵌入对象导出：docx 就是 zip，取 `word/embeddings/*.vsdx|.vsd`（也可以直接在 Word 里双击图进 Visio）
3. **按"图题"给它命名**：解析 `word/document.xml`，找到图片所在段落，往后（或往前）找最近的
   图题段落（"××图 / ××框图 / ××流程图"），用图题当文件名 —— 比按内容猜准得多；
   找不到图题就退而用最近的小节标题
4. 老格式 `.vsd` 用 Visio 另存为 `.vsdx`（脚本里 `doc.SaveAs(新路径.vsdx)`）
5. 分门别类放好，附一份索引：**01 组织机构图 / 02 管理体系图 / 03 管理流程图 /
   04 工艺流程图 / 05 信息化与智慧工地 / 06 其他**
6. 下次写标书：**直接从图库拿，改项目名称与工区数** —— 能少改就少改

**注意**：图片类的（.emf/.png）也收进图库，标上"EMF 是矢量、可在 Word 里取消组合改字"。
命名以**文档里原来的图题**为准（哪怕图题与画面内容略有出入），这样跟往期标对得上。

### 2.2.1 "工区组织机构"这一节写什么（别漏了那张表）

它其实就两块：

**一块是文字（说工区怎么分、每个工区配什么人）**

- 开头一句点明：本工程项目总承包部下设 **N 个工区**（N 按本次招标文件的划分）
- 再写各工区的**班子配置**（例：工区主要领导层为项目经理 1 人、项目书记 1 人、技术负责人 1 人、
  安全副经理 1 人、商务副经理 1 人、生产副经理 1 人、盾构副经理 1 人（土建施工 01、02、06 工区）、
  前期副经理 1 人）；**括注只设在部分工区的岗位**（如盾构副经理只设在有盾构的工区）
- 接着写工区**管理层部门**与作业层（各专业施工队）

**一块是"工区划分表"（一行一个工区，把管什么、什么工法列清）**

- 列（以招标文件给的表格为准，实例是）：**序号 ｜ 工区 ｜ 划分 ｜ 工区概况 ｜ 单位工程 ｜
  结构型式及施工方法**
- 每一行 = 一个工区；"划分"写几站几区间（例：2 站 1 区间）；"单位工程"逐个列出该工区管的车站与
  区间名称（含起终点与里程，如"××～××区间"），后面跟上它的**结构型式与施工方法**
  （明挖 / 盾构 / 高架 / 支架现浇……）
- 例（实例第 1 行）：土建施工 01 工区｜2 站 1 区间｜万年路站（框架结构、明挖施工）＋
  万年路站～工农路站区间（盾构施工）＋工农路站（框架结构、明挖施工）
- **数据来源**：招标文件"工程范围与工区划分"那一节（有的直接给工区划分表）＋
  工程量清单（单位工程与结构型式、工法）＋图纸；打码或没写的进问题报告
- **作用**：一眼看清每个工区管哪些站点区间、用什么工法 —— 后面施工方案的分节、工期节点、
  人员机械配置都要跟这张表对得上（表里没有的工区，方案里也不能冒出来）
