# 图纸册和岩土勘察报告怎么用

> **声明：下面的大小册数、文件名、章节名都是举例**（取自一份实际招标资料），不是通用要求。
> 手上这份招标文件的图纸怎么给、给到哪一阶段，一律以本次文件为准。

## 一、图纸不只给图纸；地质资料有两种给法

招标文件"图纸"那一章往往只写一句"图纸另册"，真正的图纸在单独的图纸册里。
**地质与水文资料有两种给法，两种都得找**：

1. **单独出勘察报告**（有的标会这样）—— 夹在图纸册里，往往是一册，按工点再分册（下面第二、三节讲的就是这种）
2. **没有单独报告**（**大部分是这种**）—— 地质、地层的描述就写在**图纸文件最前面的"设计说明"**里，
   所以要翻图纸册开头那几页（设计说明 / 总说明 / 工程概况），别只翻后面的图

也就是说：拿到图纸册，先看**开头有没有设计说明**，再看**有没有单独的勘察报告分册**，两处都别漏。

举例（某标段，19 册）：
- 一～十八：施工招标图（按专业 / 工点分册）
- 十九：**岩土工程初步勘察报告**（按工点再分册）
- 另有一份"施工招标设计图图纸目录"（xlsx，先看它，一眼知道有哪些册）

招投标阶段看到的是**初步勘察报告（初勘）**，不是详勘 —— 施工图阶段还有详勘 / 补勘；
招标文件里通常也写着承包商要"配合补充勘察"，进场后地质参数以补勘、详勘更新。

### 第二种给法的实例（施工图设计总说明）

举例：某快速化改造项目的招标图纸，"第一册 总体设计"里就有一份**总说明**（图表号 SI-2，44 页，
带自己的目录），结构是：

- 1 概述（项目概况 / 设计依据及测设经过 / 遵循的标准规范 / 设计范围及工程内容 / 主要工程规模）
- 2 现状评价及建设条件 → 2.1 现状道路状况 …… **2.3 工程建设条件**：
  - **2.3.1 气象**（气温、降水、日照、灾害性天气 —— 写施组"气候条件""冬雨季施工"那节用得上）
  - **2.3.2 水文地质**（所属水文地质分区、含水层组划分（潜水 / 承压含水层组）、
    地表水（经过哪些河道）、地下水类型（孔隙型潜水、基岩裂隙水）、初见与稳定水位标高）
  - 2.3.3 起 **工程地质**（地层、勘察结论，往后几页）
- 后面还有若干页含地质结论、不良地质等

→ 所以要养成习惯：**拿到图纸册，先翻第一册（总体设计）开头那份总说明**；
地质、水文、气象、勘察结论常常全在里面，不必等单独的勘察报告。

## 二、勘察报告怎么分册（举例）

按工点分：每个车站一册、每个区间一册、停车场一册（有的把出入线并进相邻区间那册）。

每册里两类东西：
1. **主报告**（如"00B-XX初勘报告.pdf"）—— 正文 + 结论与建议
2. **附件 CK 系列**（编号不尽相同，内容大同小异）：
   勘探点一览表 / 图例 / 勘探孔平面位置图 / 工程地质断面图 / 物理力学指标统计表 /
   分层土工试验成果 / 岩石试验成果 / 双桥静力触探分层统计 / 标准贯入试验成果 /
   **标准贯入试验液化判别及液化指数计算成果表** / 动力触探 / 热物理试验 /
   钻孔柱状图 / 静力触探柱状图 / 土工试验成果 / 三轴试验曲线 / 高压固结与综合固结曲线 /
   **水质分析、土壤化学分析报告** / 电阻率测试 / 波速测试 / 旁压试验 / 地温与电阻率测井

## 三、主报告的章节（举例）

1 概述（工程概况 / 工点概况 / 勘察目的与任务 / 执行的技术标准 / 勘察方法与工作量）
… 4 岩土层特征与物理力学指标
5 地表水与地下水（地下水类型及水位 / 水土腐蚀性 / 地层渗透性 / **抗浮设计水位**）
6 场地和地基的地震效应（场地类别 / 抗震设防烈度与设计基本地震加速度 / **饱和砂性土液化判别** /
  抗震地段 / 软土震陷 / 地震动参数）
7 工程地质评价（区域与场地稳定性、适宜性 / 岩土层工程地质评价 / 地基均匀性 /
  **不良地质作用及特殊性岩土**：液化土、填土、软土、混合土、膨胀土、风化岩 / 土石分级）
8 天然地基分析与评价（持力层选择 / 承载力设计参数）
9 桩基础分析与评价（桩型选择 / 持力层选择 / 桩基设计参数）
… 结论与建议

## 四、要提取的是这四类信息（使用者 2026-09-16 明确）

看勘察报告不是从头读到尾，是按顺序取这四样：

1. **标准土层层序** —— 层号、土名、状态、密实度、成因、代号（报告里"地基土的分布"那节 +
   土名状态密实度代号表，层序、成因、代号、主层编号是统一编制的）
2. **工程地质层分布特征表** —— 各层埋深、厚度、分布范围、层顶 / 层底标高
3. **水文地质条件** —— 分两块：
   - **地表水**（水位、流量、水质、与地下水的相互关系）
   - **地下水**：先分**孔隙水**与**其他类型水层**（潜水 / 承压水 / 上层滞水之类，各层水位与
     水力联系），再看水土腐蚀性、地层渗透性、抗浮设计水位
4. **岩土层工程地质评价** —— 逐层的强度、变形特征、渗透性、工程地质性能（报告里通常是一张表：
   层号 / 岩土名称 / 状态 / 强度变形特征及渗透性 / 工程地质性能）

**取这四样是为了支撑后面的结论**：地基均匀性评价、不良地质作用及特殊性岩土（液化土、填土、软土、
混合土、膨胀土、风化岩）。**再拿这些结论去定施工工艺** —— 同样一个"桩"，地质不同，做法就不同：

- 用**钻孔灌注桩**（成孔现浇）还是**打套桩 / 套管成孔**还是**直接买成品桩**
- 是**现浇**（灌注、成桩）还是**直接锤击 / 静压打进地层**（预制桩沉桩）
- 基坑围护用地下连续墙还是灌注桩 + 止水帷幕、降水怎么降（看承压水、渗透性）、
  盾构怎么选型（看地层与磨蚀性、孤石 / 上软下硬）

**一句话：地质资料是为"定工艺"服务的，不是抄一段地质描述摆在那里。**

## 五、取用套路（操作建议）

1. 先看图纸目录 xlsx → 知道有多少册、哪个工点在哪册
2. 进某工点文件夹读主报告：**地基土的分布（层序 + 分布特征）→ 地表水与地下水（孔隙水与其他
   水层、腐蚀性、渗透性、抗浮水位）→ 岩土层工程地质评价表 → 地基均匀性评价 → 不良地质作用及
   特殊性岩土 → 结论与建议**，六块读完就能写施组里跟地质有关的部分
3. 要具体数值（承载力、渗透系数、液化指数、桩基参数）：翻对应的 CK 附件表
4. 要画地质断面 / 看层位：用"工程地质断面图"

两条纪律：
- **数字照报告原文**：承载力、抗浮水位、液化判别结论、渗透系数这类参数，抄报告里的值，
  不许自己估、不许用别处的数
- 报告是**初步勘察**：措辞按报告写（"初步勘察"），进场后以补勘 / 详勘更新 —— 招标文件里一般也有条款

## 六、写施组时哪儿用得上它

| 施组里的位置 | 从勘察报告取什么 |
|---|---|
| 工程概况里的"工程地质与水文地质" | 层序与分布特征、地下水类型与水位、抗浮设计水位 |
| 工程特点、重难点与对策 | 地基均匀性、不良地质与特殊性岩土（软土、填土、混合土、膨胀土、风化岩）、液化、承压水 |
| 主要施工方案 | **定工艺**：桩型与成桩方式（灌注桩 / 套管成桩 / 成品桩；现浇还是打进去）、围护与成槽成孔、降水与止水、盾构选型、土石分级影响开挖 |
| 监测与沉降控制 | 周边建构筑物、软土震陷、抗震地段、基坑变形控制要求 |
| 风险源分析 | 承压水突涌、流砂、暗浜 / 暗河 / 孤石、既有管线与建构筑物 |
| 临时工程 / 试验 | 水土腐蚀性（影响结构耐久与防腐）、电阻率（接地）、地温 |

## 七、施组里是"摘"，不是全抄（按篇幅要求选摘）

勘察报告几十页，施组里的"工程地质与水文地质"只是**摘取一部分** —— 摘什么、摘多少，
看**本次招标文件的篇幅要求**（页数上限、评分里"尽量精炼文字"这类），不是把报告搬过去。

举例（某 779 页投标施组，工程概况那一节实际就是三小块）：

- **地形地貌**：两三句话 —— "地貌主要为长江漫滩平原区，地势平坦，近地表岩性主要为……；
  场地周边多为道路、居民住房、农田和水沟，某某站周边地下管线密集，环境较复杂"
- **岩土工程地质分布及参数**：一张**工程地质层分布特征表**，列是
  **时代成因 | 层号 | 地层名称 | 状态 | 特征描述 | 分布范围**（逐层一行，写清"均有分布 / 普遍分布 /
  仅东侧分布 / 局部缺失"这类分布范围）
- **水文地质**：地表水 + 地下水（类型、水位、腐蚀性）

**这些内容来自哪**：招标公告（工程规模、地貌、周边环境）＋ 招标图纸里的岩土工程初步勘察报告
（层序、分布特征、水文、评价表）。

**其余的地质内容不放在工程概况里，而是分流到别处**：
- 不良地质与特殊性岩土、地基均匀性、液化 → **重难点与对策**那一节
- 桩型、成桩方式、降水、围护、盾构选型 → **主要施工方案**里（用地质结论论证工艺选择）
- 承压水、暗浜、孤石、周边建构筑物 → **风险源分析**

一句话：工程概况里只交代"场地的底子"，工艺与对策要在方案章里用这些底子去论证。
## 八、找不到勘察文件时，按这个顺序找

招标文件到手，没看到"勘察报告"三个字，别就此认为"没有地质资料" —— 按顺序找：

1. **图纸册里有没有单独的勘察报告分册**（有的标会单独出，按工点分册）
2. **没找到 → 翻图纸册第一册（总体设计）的那份"总说明"**：
   地质、水文、气象、勘察结论通常就写在里面（章节名多为"建设条件 / 工程建设条件 / 自然条件"，
   下面分气象、水文地质、工程地质）
3. **再看图纸册其他册的前言 / 说明页**（分册说明、设计说明）
4. 三处都没有 → 进问题报告，向招标人澄清要地质资料；同时提示编标人员：
   地质参数是定工艺的依据（桩型、降水、围护、盾构选型），缺了不能凭空写

一句话：**先翻图纸册开头，再翻有没有单独报告册；实在没有就问招标人。**
