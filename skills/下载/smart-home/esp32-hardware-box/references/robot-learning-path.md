# 机器人学习路径 — 从 ESP32 盒子到竞赛机器人

用户目标：从手搓 ESP32 桌面盒子起步，最终能挑战大学生机器人大赛级别的项目。

## 三阶段学习路线

### 第一阶段：嵌入式入门（2~4周）
**你现在在这里 ✓** — 通过小盒子项目实战

- Arduino 编程（已掌握）
- ESP32 开发（正在搞）
- 传感器/执行器基础
- **输出：** 可用的语音交互桌面终端

### 第二阶段：机器人基础（1~3个月）
做完小盒子后的下一步

| 子方向 | 推荐入门项目 | 预算 |
|--------|-------------|:----:|
| 移动机器人 | 2WD/4WD 循迹小车（淘宝底盘 ¥50-80） | ¥200-400 |
| 机电控制 | 舵机/步进电机/直流电机PID调速 | ¥100-200 |
| 通信 | I2C、SPI、UART、CAN总线（小盒子已涉及前三个） | ¥0-50 |
| 驱动板 | L298N、TB6612、A4988 | ¥20-50 |

**推荐资源：**
- B站：太极创客（ESP32教程）、古月居（ROS教程）
- 图书：《Arduino从零开始》
- 工具：EasyEDA/立创EDA（免费学PCB设计）

### 第三阶段：竞赛级机器人（3~6个月）

| 技能 | 说明 | 所需硬件 |
|:-----|:-----|:---------|
| ROS 2 | 机器人操作系统，必学 | 树莓派 / Jetson Nano |
| SLAM建图导航 | 让机器人自己认路 | 激光雷达 / 深度相机 |
| 计算机视觉 | OpenCV + 摄像头识别 | USB摄像头 |
| 机械臂控制 | 运动学正逆解、轨迹规划 | 6自由度机械臂 |

**推荐资源：**
- 图书：《ROS机器人开发实践》（胡春旭）
- B站：机器人工匠
- 硬件：NVIDIA Jetson Nano（¥800-1000）

## 我（AI Agent）能帮你到什么程度

| 任务 | 我能做的 | 需要你自己做的 |
|:-----|:---------|:--------------|
| PID控制 | 写代码、调参数范围建议 | 实测拧参数 |
| OpenCV识别 | 写识别算法 | 调摄像头角度、光照 |
| 运动学解算 | 正/逆解代码 | 物理验证 |
| 路径规划 |  A*/Dijkstra 实现 | 现场避障测试 |
| 电机驱动 | 驱动层代码 | 接线、电压匹配 |
| **调试** | 分析现象出方案改代码（你试我改模式） | 跑起来看效果反馈给我 |

**核心模式：** "你试我改" — 用户描述现象（"往左偏了"、"走S型"），我来分析原因并出修改方案/代码。
