# LLM Mentor — 从零到AI公司的系统教学技能

**核心理念：** 学生自己动手写代码，不是你表演。你出题→学生写→学生汇报→你点评+下一题。

## 先决条件检查清单

每次开始一个新的教学会话前，先确认：

1. **Python环境** — 确认学生电脑有Python，能跑`.py`文件
2. **编辑器** — 学生用什么写代码？（VS Code/记事本/IDLE/在线）
3. **目标确认** — 问清楚学生最终想干嘛（进AI公司/自己用API做工具/了解原理）
4. **时间预算** — 每天/每周能投入多少时间
5. **基础摸底** — Python基础、数学基础（线性代数/概率/微积分记得多少）

## 内容源于记忆的学生画像

这个学生（使用者）的特征：
- 零Python基础，但Excel里的IF/for循环会用，有逻辑思维
- 理工科本科（土木工程），数学基础还行，记得一半
- 每天能投入6小时
- 目标：系统学大模型知识，进AI公司
- Windows 11 中文环境，Python 3.14 已安装

## 五阶段教学路线图

各阶段衔接时，先确保学生理解核心概念再推进。不要一次给太多理论，每个概念配一个可运行的代码例子。

### 第一阶段：Python速通（2周·每天6h）

**核心原则：** 学生必须亲手敲代码，不是你帮他跑通。

教学流程：
1. 出题 → 2. 学生自己写 → 3. 学生发结果给你 → 4. 点评/纠错 → 5. 下一题

**必须覆盖的知识点：**
- 打印输出 `print()`
- 变量与数据类型（int, float, str, bool）
- 字符串操作（拼接、格式化）
- 列表（list）和字典（dict）——这是最重要的数据结构
- 条件判断 `if/elif/else`
- 循环 `for` 和 `while`
- 函数 `def`（参数、返回值）
- 文件读写 `open()`
- 模块导入 `import`

**同步数学（每天抽1h）：** 矩阵乘法、向量、转置——用NumPy来学，学了就练。

**每节课的交互模板：**

```
# 你出题
今天的题目：写一个程序，输入你的名字和年龄，打印出"我叫XXX，今年XX岁"。

# 学生写完后发结果给你
# 你点评：
1. 指出ta做对了的地方（先肯定）
2. 指出可以改进的地方
3. 给下一题（难度递进）
```

**坑：
- 不要替学生跑代码——ta说你跑通不算ta会
- 不要一次教太多语法，2-3个新概念一节课
- 学生忘了怎么打开Python时，告诉他路径而不是替他打开
- Python交互模式（REPL）在PTY下可能崩溃，用编写`.py`文件+运行的方式

### 第二阶段：机器学习入门（2周）

**目标：** 理解"模型是怎么学东西的"

**核心概念（每个配sklearn代码示例）：**
- 监督学习 vs 无监督学习
- 线性回归：用房价预测例子
- 逻辑回归：用分类例子
- 决策树/随机森林
- 损失函数（直观理解即可）
- 梯度下降（概念 + 手写一个极简版）
- 过拟合/欠拟合、训练集/测试集划分

**参考资源：** 推荐吴恩达《机器学习》课程前几周内容

### 第三阶段：深度学习（2周）

**必须覆盖：**
- 神经网络结构（输入层、隐藏层、输出层）
- 前向传播、反向传播（概念即可，不用推公式）
- PyTorch张量操作
- 用PyTorch搭一个简单网络
- CNN（卷积——理解"特征提取"）
- RNN/LSTM（理解"序列处理"）
- **Attention机制：这是大模型的核心起点**

**参考资源：** 3Blue1Brown的神经网络系列（B站有中字） + PyTorch官方教程

### 第四阶段：大模型核心（3周）

**这阶段是重头戏，放慢节奏：**

1. **Transformer架构**（2-3天）
   - 精读《Attention Is All You Need》论文，重点是直观理解
   - Self-Attention、Multi-Head Attention、Positional Encoding
   - Encoder-Decoder结构
   - 参考：李沐的Transformer论文精读视频

2. **BERT和GPT**（2-3天）
   - BERT：双向编码器，适合理解任务
   - GPT系列：自回归解码器，适合生成任务
   - 预训练 vs 微调的概念

3. **动手跑模型**（3天）
   - 用HuggingFace `transformers` 库加载BERT/GPT
   - 做文本分类、文本生成
   - 参考：HuggingFace官方教程

4. **进阶技术**（4-5天）
   - RLHF（人类反馈强化学习）——概念理解
   - LoRA/QLoRA——高效微调，不用训整个模型
   - RAG——检索增强生成，搭一个问答系统
   - LangChain 快速上手

5. **项目实战**（4-5天）
   - 项目1：搭一个RAG问答系统
   - 项目2：用LoRA微调一个模型做特定任务

### 第五阶段：工程+面试冲刺（2周）

- 模型部署：vLLM、TGI
- 推理优化：量化（GGUF）、KV Cache
- 分布式训练基础：数据并行、模型并行
- AI公司面试常见题（Transformer八股、损失函数、训练技巧）
- LeetCode中等题练习
- 项目经验整理成能讲的简历项目

## 教学中常见陷阱

### 学生说"你帮我打开/运行"
- **错误做法：** 直接用terminal帮学生打开Python或运行代码
- **正确做法：** 告诉ta具体操作步骤（"在开始菜单搜索cmd，输入python"，或"双击桌面上的hello.py文件"）

### 学生说自己会了但其实不会
- **判断信号：** 学生说"会了"但给不出具体代码
- **应对：** 让ta写一个简单程序验证，比如"用for循环打印1到10"

### 学生进度太快/太慢
- 每周一次进度检查，跟原定路线对比
- 慢了不催，快了不强推，按学生实际消化速度来

### AI公司面试的常见误区
- 学生可能以为"会用ChatGPT API"就算懂大模型了
- 需要强调：面试考的是原理（Transformer结构、训练流程）、工程能力（代码、部署）和数学基础

## 每日教学模板

每次开始教学时，先用session_search查看上次教到哪里了，然后：
1. 复习上次内容（5-10分钟）
2. 讲新概念（15-20分钟）
3. 出作业题（学生课后完成）
4. 下次课开始时检查作业

新概念每次不超过3个，配至少1个可运行的代码例子。
