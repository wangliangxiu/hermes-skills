# 投标文件各部分的表（技术 / 经济 / 商务）

> **声明：下面的表名、条数、章节号都是举例**（取自某一份招标文件），不是通用要求。
> 一律按**本次招标文件**"投标文件格式"那一章的原文来 —— 它给了哪些表就出哪些表，没给的不用管。

## 一、技术部分格式

1. 施工组织设计编制要求 —— 一份逐项内容清单（举例：①总体目标及重难点分析 ②项目总承包部及工区组织架构、
   职责及管理方案 ③前期实施方案及主要施工方案 ④进度计划及措施 ⑤质量保证体系及措施 ⑥安全管理体系及措施
   ⑦风险管理体系及措施 ⑧文明施工、环境保护、消防、保卫、健康体系及措施 ⑨智慧工地建设、标准化工地建设
   目标和方案 ⑩劳动力、材料、机械设备配置计划及保障方案 ⑪用款计划 ⑫合同管理措施、分包计划和管理措施
   ⑬协调配合措施及接口管理 ⑭降低造价、优化施工组织的合理化建议）
2. 附表（格式 1~8 那类）：主要施工机械表 / 试验、测量、质检仪器设备表 / 建（构）筑物保护、管线保护、
   管线拆除、管线改移表 / 交通导改表 / 临水引入表 / 临时用地及地上物拆迁表 / 临电需求表 /
   拟投入大型机械情况说明（里面可能再带"拟使用盾构机主要情况详细表"这类明细表）

## 二、经济部分格式

- 工程量清单与投标报价表，以及随附几条要求：要求签字盖章的地方必须由规定单位和人员签齐；
  任何内容不得随意删除或涂改；列明的单价与合价都要填报（未填视为已含在其他单价里）；
  金额以人民币表示

## 三、商务部分格式

投标函 / 投标函附录 / 法定代表人身份证明 / 授权委托书 / 投标保证金资料 / 投标人基本情况表 / 联合体协议 /
投标安全承诺书 / 投标人承诺书 / 类似工程业绩汇总表（总承包部、工区项目部）/ 项目部组织机构框图
（含总承包部及工区项目部，细到施工队层级）/ 项目部职能划分表 / 主要人员汇总表与简历表（总承包部、工区、
指挥部）/ 工区负责人业绩表 / 拟分包工程情况表（限于自行施工范围内的非主体、非关键工程）/
商务合同条款响应表 / **技术部分响应偏离表** / 控股管理关系说明 / **盾构机情况表**（供应方案：新购 / 自有 /
租用，填制造商与主要技术指标）/ 投标人需要补充的资料

## 用法

- 章节搭完先跟"技术部分格式"那份内容清单对一遍（见 SKILL.md 第 3 步）
- 各张附表照抄格式（列、表头分格与行高、单位大小写、表外小字、表后的注与缩进），细则见 `格式要求与附表.md`
- 编完之后拿这一章当检查清单逐条核（见 SKILL.md"编完之后"那节）
