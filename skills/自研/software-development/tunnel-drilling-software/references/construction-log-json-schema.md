# 施工日志 JSON 数据交换格式

## 用途

台车工控机打完孔后导出 JSON 文件，工程师笔记本上的 PyQt5 软件读取后自动生成 Word 版施工日志。

## 核心原则

- **JSON 是跨平台中间格式** — Windows/Linux/PLC/嵌入式都能读写
- **最终交付物是 .docx（Word）** — 可打印签字归档
- **下循环建议是纯规则（if-then），不是 AI** — 离线运行

## 字段属性速查

| JSON 路径 | 来源 | 编辑方式 |
|:----------|:----|:--------|
| 项目信息.*(项目名称/施工里程/班次) | 预设/手动 | 下拉选择 |
| 项目信息.施工日期 | 自动 | 日历可改 |
| 项目信息.循环编号 | 自动递增 | 手动微调 |
| 项目信息.(围岩等级/开挖方式) | 设计同步 | 只读 |
| 设计参数.* | 软件生成 | 只读 |
| 实际钻孔[*].* | 台车传感器 | 只读 |
| 异常记录[*].(时间/类型/描述) | 自动检测 | 只读 |
| 异常记录人工备注 | 操作员 | 可编辑文本框 |
| 施工信息.台车编号 | 预设 | 下拉选择 |
| 施工信息.操作员 | 手动 | 下拉选择（预存名单）|
| 施工信息.纯钻孔时间_h | 台车自动 | 只读 |

## 下循环建议——规则引擎

下循环建议不依赖 AI / 不依赖网络。纯 if-then 规则：

```python
def generate_suggestions(drilling_data, alarms):
    suggestions = []
    
    if drilling_data:
        devs = [sqrt(h["实际X"]**2 + h["实际Y"]**2) * 100 for h in drilling_data]
        avg_dev = sum(devs) / len(devs)
        max_dev = max(devs)
        
        if avg_dev > 3:
            suggestions.append("偏差偏大，建议检查围岩条件，调整布孔参数")
        if max_dev > 5:
            suggestions.append(f"最大偏差{max_dev:.1f}cm，需重点关注该区域")
    
    if alarms:
        high_pressure = [a for a in alarms if "压力" in a.get("类型","")]
        if high_pressure:
            suggestions.append("围岩硬度变化区域，建议下一循环对应位置辅助眼参数微调")
    
    if avg_dev <= 2:
        suggestions.append("整体质量优秀，保持当前参数")
    elif avg_dev <= 5:
        suggestions.append("整体质量合格，建议微调周边眼外插角")
    
    return suggestions
```

规则生成后显示在可编辑文本框中，操作员可以自己改或删，最后签字确认。
