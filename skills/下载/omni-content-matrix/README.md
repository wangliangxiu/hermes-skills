# 全平台内容矩阵 / Omni Content Matrix v1.0.0

一人公司 / 个人创作者的内容生产指挥部。把一个人的有限时间，沿「定盘 → 取材 → 裂变 → 投放 → 校准 → 转化」的回路，转成一份能直接照做的多平台周计划。

## 适用场景

- 想用内容获客，但不知道做哪些平台。
- 有一篇长文 / 视频 / 直播，想拆成多平台版本。
- 每周只有 5–15 小时，需要现实可执行的排期。
- 各平台数据分散，需要判断下周加码哪个。
- 想做竞品对标，看自己差在哪。
- 已有粉丝，想测试知识付费、私域、商单或带货。

## 相比同类工具的提升

- **行业更全**：内置 21 个领域适配（原版仅 6 个）、覆盖 12 个平台，未知领域自动走通用推荐。
- **逻辑更稳**：选题评分超出 1–5 范围时按 5 封顶并提示，不再抛异常中断。
- **互动率更准**：公式修正为包含收藏与分享，更贴近平台真实口径。
- **复盘更合理**：有基准的平台才算「加码/降频」线，微博等无基准平台标注「保持观察」，结论不再误判。
- **能量预算更贴心**：总时间短时关键动作也至少给 0.5h，避免「某项为 0h」。
- **新增竞品对标**：结构化差距分析，告诉你可抄什么、别硬抄什么。
- **新增标题生成**：按 12 平台风格批量产出标题候选。
- **新增内容简报**：每个平台顺带给出封面思路、结构大纲、CTA，省去再单独想。
- **新增目标节奏追踪**：对比两期数据，判断是否跑在达成量化目标的节奏上。
- **新增常青内容库**：按支柱主题×内容形式给可持续选题骨架，缓解选题枯竭。
- **合规更严**：敏感词库扩展（含国家级/万能/根治/零风险等），附平台规则速查。
- **体验更丝滑**：对话式开场，先诊断再出方案，缺信息用 ❓ 标注而非反复追问。

## 快速开始

```bash
python scripts/main.py            # 默认 Markdown 示例
python scripts/main.py --json     # JSON（供程序调用）
python scripts/main.py --with-metrics  # 带示例数据复盘
```
