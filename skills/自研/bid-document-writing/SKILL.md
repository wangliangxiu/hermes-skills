# 编写投标文件（章节、格式、各张表、编完复查）

> **数字与例子声明：文中出现的数字、面积、间数、台数、天数、时限、表名、章节号、项目名都是举例**，
> 一律以**本次招标文件**的原文为准。凡是牵扯到数据的地方（工期天数、节点日期、面积、间数、人数、
> 机械台数、材料规格与等级、报审时限、各类比例）都要回本次文件原文逐个核 ——
> 不能把别处抄来的数、或这里举例的数，当成本次的要求写进去；文件没写的就不写，拿不准的进问题报告。

## 什么时候用它

- 招标文件已经扫完（见 bid-tender-scan），现在要动手编投标文件
- 用户说：投标文件怎么搭、章节怎么定、格式怎么照、附表怎么填、编完了帮我查一遍

不适用：怎么把招标文件扫清楚（用 bid-tender-scan）；施工组织设计正文怎么写（用 bid-technical-proposal）。

## 三部分各有什么

- **技术部分格式**：施工组织设计编制要求（一份内容清单，逐项对齐）＋ 附表（格式 1~8 那类）
- **经济部分格式**：工程量清单与投标报价表，以及几条要求（要求签字盖章的地方必须签齐、不得删除涂改、
  单价与合价都要填报、金额以人民币表示）
- **商务部分格式**：投标函、投标函附录、法定代表人身份证明、授权委托书、投标保证金资料、投标人基本情况表、
  联合体协议、投标安全承诺书、各类承诺书、类似工程业绩汇总表、项目部组织机构框图（含总承包部及工区项目部，
  细到施工队层级）、项目部职能划分表、主要人员汇总表与简历表、工区负责人业绩表、拟分包工程情况表、
  商务合同条款响应表、**技术部分响应偏离表**、控股管理关系说明、盾构机情况表、需补充的资料

## 第 3 步 定章节

- 招标文件给了格式要求（内容清单）→ 按格式要求划章节
- 没有格式要求 → 按技术评分表的项目逐项设章节
- 格式要求那一章（"投标文件格式 → 技术部分格式 → 施工组织设计编制要求"）给的是一份逐项清单，
  **有这种就完全按格式要求来写**（举例）：
  ①总体目标及重难点分析 ②项目总承包部及工区组织架构、职责及管理方案 ③前期实施方案及主要施工方案
  （前期专项工作实施方案 / 主要施工方案 / 施工现场总平面布置方案）④进度计划及措施
  ⑤质量保证体系及措施 ⑥安全管理体系及措施 ⑦风险管理体系及措施
  ⑧文明施工、环境保护、消防、保卫、健康体系及措施 ⑨智慧工地建设、标准化工地建设目标和方案
  ⑩劳动力、材料、机械设备配置计划及保障方案 ⑪用款计划 ⑫合同管理措施、分包计划和管理措施
  ⑬协调配合措施及接口管理 ⑭降低造价、优化施工组织的合理化建议；
  后面还跟一张附表清单（主要施工机械表、试验 / 测量 / 质检仪器设备表、
  建（构）筑物保护 / 管线保护 / 管线拆除 / 管线改移表、交通导改表、临水引入表、
  临时用地及地上物拆迁表、临电需求表、拟投入大型机械情况说明），照它出齐。
- 判断章节搭得对不对的土办法：拿一份成熟的投标施组（或自家旧标）的章节，跟这 14 条并排对一遍 ——
  能一条一条对上（比如第十四条就是"降低造价、优化施工组织的合理化建议"那一章），说明章节没搭错
- 拿这份格式要求跟文件前面提到施组内容的地方（合同条款、"技术标准和要求"）比对一遍：
  一致就没事；**冲突就按格式要求这份来写，同时把前后要求冲突提给编标人员**（进问题报告）
- 格式要求那章常顺带几条硬话，照办：技术部分所有内容文字不得出现投标单位名称、相关人员姓名等
  可识别投标人身份的字符与徽标（暗标）；用款计划格式自定但不得出现投标报价的数额；
  总页码不宜过多（多了可能影响评标委员会对技术部分的综合评价）
- **分块（章）数按招标文件来**：招标文件给几个分块，就写几章 —— 它给 9 个分块就写 9 章；
  上面那 14 条只是"某一份文件"的举例，条数不能当标准（具体问题具体分析，以手上这份文件为准）
- 不管按哪个划，另一份都拿来对一遍查漏（评分表此时只是参照）
- 目录一般呈现到三级，为的是让专家评审看得清（常规做法，不是硬性规定，招标文件另有要求从其规定）；
  正文标题层级可以做得更深，更深的标题不进目录

## 编完之后：拿"投标文件格式"那一章当检查清单再核一遍

投标文件格式那一章从头到尾都是格式要求，编完之后要**照它逐条检查**（技术 / 经济 / 商务三部分的表齐不齐、
格式对不对），查出问题都提醒编标人员。其中：

- **技术部分响应偏离表**要对"技术标准和要求"的全部内容逐条响应（完全响应 / 有偏离 / 偏离简述），
  等于又逼着把第七章从头到尾过一遍
- **盾构机情况表**（大型机械那类也一样）要选供应方案（新购 / 自有 / 租用）、填制造商与技术指标 ——
  这正是要跟机械部门、设备厂家核实的内容，别自己猜

细则（含附表照抄那套）见 `references/格式要求与附表.md`。

## 时间节奏

提前三天完稿 → 发到群里大家集体校核 → 提前一天上传 / 送标（按本次投标截止时间往回倒）。

## 出标前检查清单（照顺序过一遍）

1. 章节与招标文件要求一致吗？评分标准每一项都有对应内容吗？逐条对过招标文件的硬要求
   （工期节点、材料范围与规格、驻地与临建面积、程序报批、文明环保、文物保护）——
   施组里没有跟它们冲突的地方吗？招标文件已经写明的内容
   （工程重难点、工作内容、接口管理、材料供应、工程目标）逐条回应了吗？
2. 措施部分：工法 / 工程类型改过来了吗（有没有还留着地上或桥梁那套）
3. 暗标项目：公司名、人名、非本标段项目名清干净了吗（含文档属性里的作者、单位信息）
4. "其他要求"逐条核过吗：文物保护、明标暗标、格式细则（标题层级、字号、样式、页边距、页数）
5. 两张图：位置图有吗？布置图按施工阶段齐了吗？
6. 工期：没超招标给定的期限吗？节点工期对上了吗？横道图、网络图都齐吗？
7. 人员机械：人数不低于下限吗？数字都是整数吗？跟商务册一致吗？
8. **所有数字都回本次招标文件的原文核过吗** —— 面积、间数、台数、天数、节点日期、时限、人数、
   机械数、材料规格与等级、各类比例；有没有哪一处是从往期标或举例里抄过来的？
9. 照"投标文件格式"那一章逐条过完了吗（技术 / 经济 / 商务各部分的表齐不齐、格式对不对）？
   技术部分响应偏离表对"技术标准和要求"全部内容逐条响应了吗？查出问题提醒编标人员了吗？
10. 提前三天完稿了吗？集体校核了吗？提前一天上传 / 送标预留了吗？

## 常见坑

- 以为"格式要求只有铁路标才有"，结果电子标的项目也给了格式细则
- 章节自己另搭一套，没照格式要求那份内容清单（14 条那类）搭；或者搭完不回头查漏
- 格式要求跟文件前面的说法冲突时，自己挑了一个写，没提醒编标人员
- 附表照自己习惯改了：列、表头分格、单位大小写、表外小字、表后的注被改动或漏掉
- 暗标项目没清身份信息（投标单位名称、人员姓名、徽标、文档属性里的作者单位）
- 技术部分响应偏离表没填，或者只写"完全响应"而没逐条对
- 只盯技术内容，漏掉招标文件零散位置的其他要求（文物保护、明标暗标、评审用表要逐条核的项）
- 页码、份数、册数、装订、密封这些"形式"上的事到最后才想起，来不及改
- 扫文件时发现的前后不一致没进问题报告，自己判了就算了

## 本步的检查清单

- [ ] 章节按格式要求那份内容清单搭齐，附表 1~8 出齐、格式（列 / 表头分格 / 单位大小写 / 表外小字 / 表后的注）没改
- [ ] 跟文件前面的相关要求比对过：一致，或冲突处已提给编标人员
- [ ] 暗标项目清过身份信息（含文档属性）
- [ ] 技术部分响应偏离表对"技术标准和要求"全部内容逐条响应
- [ ] 份数 / 册数 / 装订 / 密封 / 页数这些形式要求逐条过完
- [ ] 出标前检查清单逐条过了一遍

## 不做什么

- 不替用户判断能不能投（资质、业绩是投标决策前置，公司定）
- 不碰商务标、报价、人员证件类材料
- 不套用地区性规则：各地区交易中心和招标单位要求不同，一切以手上这份招标文件为准
- 不把示例当规则：文中出现的页码、数字、项目名都是举例，实际以扫描本次招标文件得出的结果为准
