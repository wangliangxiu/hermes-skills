### 选型提示

- **开发板**：选合宙ESP32-S3 N16R8（16MB Flash + 8MB PSRAM），带Type-C口，支持3.7V锂电池直插
- **屏幕**：一定要买「模块版」（带PCB底板、排针已焊好），不要买裸屏。
  - 1.14寸(240x135) / 1.8寸(128x160) / 1.9寸(170x320) 都可用
  - 非标尺寸（如1.9寸）需要确认驱动芯片型号（ST7789/ST7735/ILI9341）
  - 能显示颜文字的最小尺寸是1.14寸
- **麦克风**：买模块版（带排针焊好），选INMP441（I2S数字麦克风，接线最简单）
- **功放**：MAX98357走I2S协议，只需3根数据线（BCLK、LRC、DIN）
- **喇叭**：3W 8Ω小喇叭，¥8.8套餐里的通常够用但声音偏小
- **面包板**：400孔足够，830孔太大（17cm太长）
- **供电**：建议先用充电宝 + Type-C线，不买电池。以后可加3.7V锂电池 + TP4056充电模块

### 电子元件常识

- **轻触开关**：6x6x5mm高脚版有4个引脚，同侧两个脚内部导通。接法：一组接GND，另一组接GPIO
- **杜邦线**：公对母（开发板→模块）、公对公（面包板内部跳线），买套装两种都有
- **螺丝刀/镊子**：建议备一把小十字螺丝刀和尖头镊子（家里通常有）

## 完整接线图（ESP32-S3）

```
ESP32-S3 开发板
┌─────────────────────────────────┐
│                                 │
│   GND ───────────────→ 所有模块的 GND                   
│   3.3V ──────────────→ 屏幕 VCC、按键一端
│   5V   ──────────────→ 麦克风 VCC、功放 VIN
│                                 │
│   GPIO 10 ─── CS     ─┐
│   GPIO 11 ─── DC      │
│   GPIO 12 ─── RST     ├── ST7789 屏幕
│   GPIO 13 ─── MOSI    │
│   GPIO 14 ─── SCLK    │
│   GPIO 15 ─── BL      ┘
│                                 │
│   GPIO 4  ─── BCLK    ─┐
│   GPIO 5  ─── LRC      ├── INMP441 麦克风 (I2S)
│   GPIO 6  ─── DIN      ┘
│                                 │
│   GPIO 7  ─── BCLK    ─┐
│   GPIO 8  ─── LRC      ├── MAX98357 功放 (I2S)
│   GPIO 9  ─── DIN      ┘
│                                 │
│   GPIO 1  ─── 按键1(唤醒)
│   GPIO 2  ─── 按键2(模式切换)
│   GPIO 3  ─── 按键3(确认)
└─────────────────────────────────┘
```

**关键要点：**
- 所有模块的 GND 必须连在一起（共地）
- I2S 麦克风和 I2S 功放共用 BCLK/LRC 可节省引脚，但需要分时复用
- 按键用 INPUT_PULLUP 模式，按下为 LOW
- 屏幕背光引脚（TFT_BL）接 GPIO 15，可通过 PWM 调亮度

## 环境搭建步骤

### 1. 安装 Arduino IDE
- 下载：https://www.arduino.cc/en/software（Windows版）
- 装完后打开

### 2. 添加 ESP32 开发板支持
- 文件 → 首选项 → 附加开发板管理器网址
- 粘贴：`https://espressif.github.io/arduino-esp32/package_esp32_index.json`
- 工具 → 开发板管理器 → 搜索 "esp32" → 安装 "ESP32 by Espressif Systems"

### 3. 安装所需库
- 工具 → 管理库 → 安装：
  - `TFT_eSPI` by Bodmer（屏幕驱动）
  - `Adafruit MAX98357`（I2S功放驱动）
  - `WiFi`（内置，无需安装）

### 4. 配置 TFT_eSPI 引脚（关键步骤）
安装后打开 `User_Setup.h`（通常在 文档/Arduino/libraries/TFT_eSPI/ 下），替换为以上接线图的引脚定义：

```cpp
#define ST7789_DRIVER
#define TFT_WIDTH  170   // 按实际分辨率改
#define TFT_HEIGHT 320   // 按实际分辨率改

#define TFT_CS    10
#define TFT_DC    11
#define TFT_RST   12
#define TFT_MOSI  13
#define TFT_SCLK  14
#define TFT_BL    15

#define SPI_FREQUENCY  40000000
```

**注意**：非标尺寸屏幕（如 1.9寸 170x320）需手动设置 TFT_WIDTH / TFT_HEIGHT，库默认配置可能不包含。

### 屏幕显示函数

| 函数 | 用途 |
|:----|:-----|
| `showEmoji(emoji)` | 居中显示颜文字，字号2 |
| `showText(text, size)` | 显示文字，可调字号 |
| `showStartup()` | 开机画面：显示「甄der」+颜文字 |
| `showListening()` | 录音中：显示「听着呢」+颜文字 |

### 颜文字组设计

颜文字按情绪分组，每组4-6个，每次随机选取，避免重复：

| 分组 | 触发场景 |
|:----|:---------|
| `emoji_happy[]` | 用户开心、收到夸奖 |
| `emoji_greeting[]` | 开机、唤醒、打招呼 |
| `emoji_sad[]` | 用户道歉、出错、委屈 |
| `emoji_cute[]` | 卖萌、日常互动 |
| `emoji_shy[]` | 被夸害羞 |
| `emoji_sleep[]` | 待机、晚安 |
| `emoji_proud[]` | 完成任务、求表扬 |

### 全双工音频管道

```
用户说话 → [INMP441 麦克风]
                 ↓ I2S
         ESP32 录音缓冲区
                 ↓ WiFi (HTTP/WebSocket)
         [电脑端 Hermes Agent]
                 ↓ LLM处理、TTS合成
                 ↓ WiFi
         ESP32 音频缓冲区
                 ↓ I2S
         [MAX98357 功放] → 喇叭播放 🔊
```

**关键点**：
- ESP32 本身不跑语音识别和TTS，只做音频采集和播放
- 所有AI处理（ASR + LLM + TTS）在电脑端 Hermes Agent 完成
- 盒子通过 WiFi 与 Hermes Agent 通信，支持 HTTP 和 WebSocket
- 音频格式：16-bit, 16000Hz, 单声道 PCM

## 开发流程

1. **买齐物料**（参考上方 ¥100 购物清单）
2. **安装开发环境**：Arduino IDE + ESP32板支持包 + esptool
3. **面包板搭电路**（参考接线图，先不焊接）
4. **配置 TFT_eSPI 引脚**（替换 User_Setup.h）
5. **烧录固件**（Arduino IDE → 选 ESP32S3 Dev Module → 上传）
6. **配置WiFi + Hermes Agent连接**（固件中填入SSID/密码）
7. **测试语音对话**（按唤醒键 → 说话 → 等待回复）
8. **做外壳**：先用纸盒/亚克力，后面3D打印精修

## 常见坑 & 解决方案

| 问题 | 原因 | 解决 |
|:----|:----|:-----|
| 屏幕不亮 | TFT_eSPI 引脚配置不对 | 检查 User_Setup.h 引脚是否与接线一致 |
| 屏幕花屏 | SPI 频率过高 | 降低 SPI_FREQUENCY 到 26MHz 或 13MHz |
| 麦克风无声 | I2S 引脚接错或 GND 未共地 | 检查 BCLK/LRC/DIN 接线，确保所有GND连通 |
| 喇叭不响 | MAX98357 使能脚未拉高 | SD_MODE 引脚必须接 3.3V 或高电平 |
| 烧录失败 | 未进入下载模式 | 按住 BOOT 键再按 RESET，或选对 COM 口 |
| WiFi 连不上 | 2.4G/5G 频段问题 | ESP32-S3 不支持 5G WiFi，确保路由器有2.4G频段 |
| 充电宝自动断电 | 电流太小触发保护 | 选支持小电流模式的充电宝，或在电路中加100μF电容
