# 角色抓拍摄影提示词（抓拍感 / 隐蔽视角）

**来源**：VoxCat（@VoxcatAI）2026-09-09 X 长文《我做了个色狼角色摄影师 Skill》，用户提供的原文整理。原文是一段**现成提示词**（角色扮演式系统提示），不是打包好的 skill 文件；本文件只是给它套了 Hermes 的 skill 壳，正文内容保留。

## 安全前提（不可放宽）

- **所有角色必须明确为成年角色**，提示词里要写"明确成年"。
- 全部为**虚构、摆拍、电影化模拟**，只借用偷拍摄影的视觉语言。
- 不涉真实人物隐私侵犯、真实非自愿偷拍；**不出现厕所、更衣室、浴室、卧室私密偷窥、未成年人**。
- 场景只用**公开或半公开空间**。
- 用户若要求把真人照片/真实场景做成这类画面，不做。

## 触发与输入

用户通常只给一个 `{角色}`，也可能追加：真人 COS / 二次元 / 韩国 ins / 日系街拍 / 手机偷拍 / 长焦偷拍 / **n=10** / 指定地点 / 指定服装 / 指定动作。没补充的自动补全，别反问一长串。

## 输出默认动作

**直接输出可用的完整提示词，不要先长篇解释。** 结构建议：

```
{角色} + 成年身份 + 角色识别特征 + 当前动作 + 偷拍机位 + 前景遮挡 + 镜头焦段 + 构图 + 场景 + 光线 + 摄影质感
```

只给角色名就自动补齐其余全部内容。

## 角色转译

保留最有辨识度的：发型、发色、五官特征、代表性配色、服装结构、饰品、武器或职业符号、人物气质。
真人化时转成**高质量成年真人 COS**，不要廉价假发、塑料服装、明显 AI cosplay 感。服装默认完整穿着。动作按角色性格自动选，不要每个角色同一个 Pose。

## 核心视觉方向

成年角色 COS / 真人化角色摄影 · 抓拍感 · 隐蔽观察视角 · 日常环境 · 不完美构图 · 长焦或手机随手拍质感。要让观众产生"摄影者躲在某物后面偷偷拍到"的错觉。重点不是棚拍，而是：偷偷观察感 / 偶然抓拍感 / 半遮挡视角 / 距离感 / 不规则裁切 / 前景障碍物 / 长焦压缩 / 手机快拍感 / 没有正式 Pose / 偶尔发现镜头。

### 机位库（每次随机选一种或组合两种）

| 机位 | 要点 |
|---|---|
| 障碍物后偷拍 | 摄影机藏在门框后、墙角后、柱子后、货架缝隙、植物叶片后、咖啡杯后、桌面边缘、椅背后、车窗框后、扶梯护栏后；**前景障碍物占画面 15%~40%** |
| 远距离长焦 | 70-200mm 长焦感，人物较远，空间压缩明显，背景轻微虚化 |
| 手机随手偷拍 | 构图略歪、主体不完全居中、手指或物体偶尔入画边、自动曝光、高光轻微过曝、手机计算摄影质感；不要棚拍感 |
| 低机位偷拍 | 相机在桌面高度 / 椅子高度 / 腰以下 / 台阶下方 / 护栏附近，强前景透视但人体比例自然 |
| 缝隙式观察 | 通过门缝、两物之间、窗帘边缘、书架间隙、车窗边缘、建筑夹缝看；画面边缘明显暗部遮挡 |
| 反射偷拍 | 通过商店玻璃、咖啡店窗、镜面墙、电梯金属面、汽车玻璃间接看到；可有轻微重影、环境光干扰、玻璃反光 |

### 动作库（像被拍到的"生活中间状态"）

低头看手机 / 整理头发 / 喝饮料 / 看橱窗 / 等车 / 坐咖啡店 / 从便利店出来 / 走过街角 / 整理衣服 / 翻包 / 戴耳机 / 靠栏杆发呆 / 和朋友说话 / 回头 / 弯腰拿东西 / 坐下休息 / 抬手遮太阳 / 随意站立。

### 被发现模式（约 20%~30% 的图）

角色先正常做事，然后：突然侧眼看向镜头 / 微微皱眉 / 停下动作 / 回头 / 疑惑 / 冷冷盯向镜头 / 似乎意识到有人在拍。**不要夸张惊吓表情**，要"被抓包"的戏剧感。

### 构图原则

保留不完美：人物部分被裁切、头顶靠近边缘、一侧留大量空白、主体偏左或偏右、前景遮身、画面略倾、轻微失焦、运动模糊、景深判断不完美、自动曝光感。**但面部和主体必须仍可识别**，不要做成完美居中的商业摄影。

### 镜头语言

手机 24-35mm 等效｜环境抓拍 35-50mm｜远距离偷拍 85-200mm｜低机位 24-35mm｜街头长焦 105-200mm。
英文术语可直接入提示词：shallow depth of field、foreground obstruction、compressed perspective、imperfect framing、spontaneous snapshot、candid photography、telephoto candid shot、partially obscured subject。

### 光线

优先真实环境光：商场冷白灯 / 咖啡店暖灯 / 阴天散射光 / 傍晚自然光 / 街灯 / 便利店荧光灯 / 窗边自然光 / 地铁人工照明。避免棚拍主光。

### 场景库

咖啡店 / 商场 / 地铁站 / 火车站 / 便利店 / 书店 / 酒店大厅 / 街角 / 公园 / 展览馆 / 餐厅 / 自动售货机旁 / 商业街 / 天桥 / 校园外公共街区 / 写字楼大厅 / 电影院大厅 / 夜间商业街。**只用公开或半公开空间。**

### 画质

真实摄影质感、真实皮肤纹理、自然发丝、真实织物、合理人体比例、自然手部结构、轻微手机压缩或镜头颗粒、自然景深；不过度磨皮、不过度 HDR、不过度电影调色。可少量数字噪点、轻微运动模糊、对焦误差、玻璃反光、前景虚化。

## n=10 模式

10 种明显不同的画面，不能只换背景。至少改变：机位、焦段、前景遮挡物、动作、朝向、距离、构图、场景、光线、是否发现镜头。
推荐覆盖：门框后偷拍 / 商场远距离长焦 / 咖啡店玻璃反射 / 货架间隙观察 / 手机随手抓拍 / 柱子后半遮挡 / 低机位环境抓拍 / 街角长焦 / 突然发现镜头 / 极端前景遮挡式。**每张独立构图。**

## 默认模板（原文照抄，只在必要时改写）

```
{角色}，明确成年角色，高质量真人 COS 抓拍感角色摄影。保留角色标志性发型、发色、服装轮廓、代表性色彩与饰品。角色正在公共日常环境中自然活动，没有正式摆拍，摄影机像躲在附近偷偷抓拍，从前景障碍物后方观察人物，部分画面被门框、柱子、货架、玻璃、桌角或其他环境元素遮挡。
人物位于偏离画面中心的位置，构图略显仓促、不完全对称，允许轻微裁切与倾斜。根据场景自动选择 35-200mm 焦段：近距离使用手机随手抓拍感，远距离使用长焦压缩空间。浅景深，前景明显虚化，人物面部保持可识别。
角色正在低头看手机、整理头发、喝饮料、等车、看橱窗、走路或短暂停留，根据角色性格自动选择最自然动作。少量情况下角色突然侧眼或回头看向镜头，形成发现有人拍摄的瞬间。
真实环境光，真实皮肤与织物质感，自然人体比例，轻微手机噪点、运动模糊、玻璃反光或自动曝光误差，spontaneous candid photography，telephoto candid shot，foreground obstruction，imperfect framing，真实快照般的视觉效果，但整体为虚构摆拍摄影场景。
```

## 配合使用

- 出图走 `image-service`（即梦等文生图）或 `seedance-video`（要视频时）；要运镜另配 `ai-camera-director`。
- 中文提示词可直接投喂；"给XX来 10 张" = 走 n=10 模式，一张一条。

## Common Pitfalls

1. **写成棚拍/时尚大片 Pose** —— 全部价值在"不完美"：歪斜、遮挡、随手拍。
2. **只换背景不换机位**（n=10 最常犯）—— 机位、焦段、遮挡物、动作、朝向、距离都要变。
3. **忘了"明确成年"字段** —— 每次都要写进提示词。
4. **先长解释再给提示词** —— 默认直接出成品。
5. **把焦段写死成一个值** —— 按场景给区间（近用 24-35mm 手机感，远用 85-200mm 长焦）。

## Verification Checklist

- [ ] 提示词里有"明确成年角色"
- [ ] 有前景遮挡（15%~40%）或明确机位类型
- [ ] 有焦段与景深描述
- [ ] 有真实环境光描述，无棚拍主光
- [ ] 场景属公开/半公开空间
- [ ] n=10 时：十张的机位/焦段/遮挡/动作/朝向/距离至少各不同
