# 全国公共资源交易平台（ggzy.gov.cn）招标/中标数据抓取

触发：挂网招标数据、公共资源交易平台、新公示施工标、中标公示统计。2026-09 实证。默认场景：按月出「新公示施工标」统计表（铁路/公路/水利），含把结果填进 Word 统计表并标黄。

## 接口（匿名可用，无需登录）

- 列表：`POST https://www.ggzy.gov.cn/information/pubTradingInfo/getTradList`
  表单：`DEAL_TIME=06` + `TIMEBEGIN`/`TIMEEND`（YYYY-MM-DD）+ `PAGENUMBER`
  可选：`DEAL_CLASSIFY=01`（工程建设）、`DEAL_STAGE=0101招标公告 / 0102开标记录 / 0104交易结果公示 / 0105澄清`、
  `DEAL_PROVINCE`、`DEAL_CITY`、`DEAL_TRADE`、`SOURCE_TYPE`、`FINDTXT`（关键词，标题命中）
  头：`Referer: https://www.ggzy.gov.cn/deal/dealList.html`、`Content-Type: application/x-www-form-urlencoded`、`X-Pass-Token: `（可空）
- **响应是嵌套的**：`{code,message,data:{records:[…],total,pages,current}}`
  —— 取 `data.records` / `data.total`，不要按扁平结构取（旧脚本踩过）。
- `DEAL_TIME` 取值：01当天 02近三天 03近十天 04近一月 05近三月 06时间区间（06 才看 TIMEBEGIN/TIMEEND）。
- 详情正文：列表 `url` 形如 `/information/deal/html/a/…`，**把 `/html/a/` 换成 `/html/b/`** 才是 iframe 正文；
  取 `/a/` 只有导航栏垃圾（旧版把导航当项目概况，就是这个原因）。

## 风控与限速（最关键）

- `code=800 您的操作过于频繁` = 按 IP 限速，退避重试；`code=829` = 要过验证码，机器过不了 → 停下报告，改人工。
- 被限后冷却时间长：连续抓 100+ 条详情可能被限十几分钟以上。**并发压到 1~2、请求间隔 3~5s，或挑夜间跑**；
  不要 8 线程连打（2026-09 实证：一天 138 条详情后整站对我 800 了好几分钟）。
- 详情返回以 `{` 开头 = 被限速的风控 JSON，不是页面；等 60~75s 再试，别当解析失败。

## 一定要切窗（防漏）

单次查询最多回 **1000** 条（`total` 顶 1000 即触顶）。一个月不切必漏：
实测 9/1–9/15 的 0104 就已顶格。按**一天一组**最稳，五天/十天一组也行，但要检测 `total>=1000` 时自动按省或按天再拆。

## 解析：为什么"项目概况"最容易空

公示正文没有统一结构，**不要指望 `项目概况：` 这种小标题**（多数文件根本没有）。按文体分三类处理：

1. **表格型**（评标结果公示/中标候选人公示）：字段在 `<tr><td>` 里（项目及标段名称、建设单位、招标人、中标候选人、投标报价、合同价格）。
   做法：解析表格行 → 定位含「中标候选人/中标人/合同价格」的行 → 取同行的公司名/金额，比正文正则可靠。
2. **叙述型**（招标公告/资格预审）：工程内容写在段首，抽「建设规模/招标范围」段落 + 里程正则（`全长\s*([\d.]+)\s*(公里|km|千米)`）。
3. **纯公告型**（中标结果公告，常见仅几百字）：只有招标编号、中标人、中标金额、公告日期——**写不出"几座隧道几公里"那层**，如实留简，不要编。

必做人工兜底：
- 标题/正文关键词的自动分类会错（实证：贵广客专隧道出口棚洞被归成"公路"，应是铁路）——类别列必须人工过一遍。
- 口径区分：隧道洞口棚洞/防护 ≠ 新建隧道开挖，统计"隧道座数、里程"时不能计入。

## 交付：填表 + 标黄

出 Excel 只是中间物，最终常要填进 Word 统计表（列：序号/区域/城市/类别/项目名称/施工单位/中标额/项目概况/公示日期/评级/指派业务员/督办人）。
- 自动可填：前 9 列（城市、评级、指派、督办人 常空——公示无城市就留空，内部管理列不编）。
- 填表做法：`copy.deepcopy` 现有行 XML 再 `addnext` 保留边框格式；**合并单元格行只能写 cells[0]，随后再遍历 cells[1:] 清空会把同一格擦掉**（踩过）。
- 新增行用 `run.font.highlight_color = WD_COLOR_INDEX.YELLOW` 标黄；改前备份，改后重开验证行数/黄色行/内容（详见 docx-annotation-review 技能）。
