## When to Use / 何时用
使用者说“公式记不住”“泰勒展开背不下来”“非齐次方程那个特解符号总错”“帮我背公式”“做个记忆卡片”。
配合 `math-output-style` 使用：聊天里用汉字描述（不堆符号），做卡片用 docx（真正上下标）。

## 先纠正一个认知
背不住不是因为脑子不好，是因为在**当字符串背**。公式不是字符串，是**生成出来的**：记住几个母版和生成规则，剩下的当场推。所以本技能的核心不是“多背”，是“少背但背母版 + 会推”。

## 五条方法（按有效性排序）
1. **母版生成法**：只背少数母版，其余靠“换元/积分/取奇偶项”现场生成（泰勒那套全靠这个方法）。
2. **含义记忆法**：记“为什么长这样”，不记考号。泰勒分子是导数、分母是阶乘；特解里的 x 的 k 次方是“频率撞了几次车”；齐次解里的指数是特征根。
3. **对照表卡片**：把“右边长什么样 → 试解怎么设”做成问背两面卡，不要背定义。
4. **间隔重复**：当天 → 第 2 天 → 第 4 天 → 第 8 天各默写一次（只默写，不看书），用的时间远少于连读一小时。
5. **做题反查 + 一页纸**：连做 10 道泰勒题、10 道非齐次方程题，不许翻书；错的地方回卡片。考前一晚只看“一页纸总表”。

## 泰勒（麦克劳林）展开：只背两个母版 + 五条生成链
**母版 A（阶乘型）**：e 的 x 次方 = 1 + x + x 的二次方除以 2 阶乘 + x 的三次方除以 3 阶乘 + x 的四次方除以 4 阶乘 + ……
**母版 B（几何级数型）**：1 除以（1 减 x） = 1 + x + x 的二次方 + x 的三次方 + ……（等于母版 A 把分母的阶乘全去掉）

生成链（全部能从 A、B 两步内推出）：
- 正弦：从母版 A 只取**奇次项**、符号**正负交替** → x − x 的三次方除以 3 阶乘 + x 的五次方除以 5 阶乘 ……
- 余弦：从母版 A 只取**偶次项**、符号交替 → 1 − x 的二次方除以 2 阶乘 + x 的四次方除以 4 阶乘 ……
- 1 除以（1 加 x）：母版 B 把 x 换成“负 x” → 1 − x + x 的二次方 − x 的三次方 ……
- ln（1 加 x）：对“1 除以（1 加 x）”**逐项积分** → x − x 的二次方除以 2 + x 的三次方除以 3 − ……
- （1 加 x）的 a 次方：系数是组合数 → 1 + a x + a（a−1）除以 2 阶乘乘 x 的二次方 + ……
- arctan x：先把 1 除以（1 加 x 的二次方）用母版 B 展开（x 换成 x 二次方、再换负号），再**逐项积分** → x − x 的三次方除以 3 + x 的五次方除以 5 ……
- 还有：e 的负 x 次方 = 母版 A 把 x 换成负 x（常用）。

口诀：**“阶乘配指数三角，对数反三角靠积分，几何级数当母版”**。
一般泰勒式只需记住一句：把里面所有的 x 换成（x 减 x0），系数是函数在 x0 处的 k 阶导除以 k 阶乘——**分母永远是阶乘**。

## 非齐次常系数线性方程：结构与特解三步定式
**通解结构**：非齐次通解 = 齐次通解 + 一个特解。（比喻：先把右边挑到零、把齐次解出来，再随便找一个能把右边那项对上的解，两者相加就是全部解。）

齐次三种情况（先写特征方程：λ 的二次方 + p λ + q = 0）：
- 两个不同实根 r1、r2 → C1 乘 e 的 r1 x 次方，加 C2 乘 e 的 r2 x 次方
- 二重根 r → （C1 加 C2 x）乘 e 的 r x 次方（**重根必须补一个 x**）
- 共轭复根 α±βi → e 的 α x 次方，乘（C1 cos βx 加 C2 sin βx）

**三步定式（不要背符号，按三步走）**：
1. 看右边自由项，写成“多项式 × e 的 μx 次方 × 三角函数”的样子，认出手里有两个数：μ 和 ω。
2. 解特征根，看 μ（三角情形看 μ±ωi）**有没有撞上特征根**：不撞 → k = 0；撞一次 → k = 1（乘一个 x）；撞两次（是重根）→ k = 2（乘 x 的二次方）。
3. 设特解 = x 的 k 次方 × 与右边**同次的多项式** × e 的 μx 次方（含三角就再乘 a cos ωx 加 b sin ωx），代回原方程比系数。

右边的常见形式 → 试解（对照表）：
| 右边是什么 | 试解怎么设 |
|---|---|
| 多项式 P(x) | 同次多项式（k 看 0 是否为特征根） |
| e 的 μx 次方 | A 乘 x 的 k 次方乘 e 的 μx 次方 |
| P(x) 乘 e 的 μx 次方 | x 的 k 次方乘 Q(x) 乘 e 的 μx 次方（Q 与 P 同次） |
| A cos ωx + B sin ωx | x 的 k 次方乘（a cos ωx + b sin ωx） |
| e 的 μx 次方乘（A cos ωx + B sin ωx） | x 的 k 次方乘 e 的 μx 次方乘（a cos ωx + b sin ωx） |

**撞号的比喻**：右边带的“频率”（μ 或 ω）如果和齐次解里的频率撞车了，就乘一个 x 把它顶开；重根撞两次，乘 x 的二次方。**待定系数永远比右边多一个字母**（三角情形要用 a、b 两个字母同时配 cos 和 sin）。

## 卡片模板与生成方式
- 正面：“e 的 x 次方展开前三项” ／ 背面：完整前四项 + 生成链
- 正面：“右边是 x 乘 e 的 2x 次方，而 2 是单重特征根” ／ 背面：“试解 = x 乘（ax+b）乘 e 的 2x 次方”（k=1）
- 用 docx 出卡片（公式写成真正的上下标，或直接走 OMML 公式管线，见 `word-math-paper-docx` 技能）；排版一页一组，正面背完再看背面。
- 打卡表用 txt：日期、默写遍数、错项、下次复习日（默认按 1/3/7/15 天排）。

## 训练流程（照做就行，每天 15 分钟）
1. 第 1 天：手抄 8 条泰勒链三遍、特解三步定式两遍，每抄一条出声念一遍。
2. 第 2、4、8 天：白纸默写（不翻卡）→ 与卡片对账 → 错项单独再抄五遍。
3. 每天再加 3 道泰勒小题 + 3 道非齐次方程小题，不许翻书，错了回卡片。
4. 考前一晚：只看一页纸总表（泰勒 8 条 + 特解对照表 + 齐次三种情况）。

### 全章节公式大全（第二份交付物：`高数公式大全（含高频标记）.docx / .pdf`）
- 规模与范围：11 章 185 条，覆盖高数课本全部章节（极限与连续／导数与微分／一元积分／多元微分／重积分／曲线积分／曲面积分／级数／微分方程／空间解析几何／三角与代数预备）。
- 每条三列：**公式｜说明与记忆点｜频率**；按频率给公式本身着色 —— 红 `C00000`＝高频、蓝 `1F4E79`＝中频、灰 `808080`＝低频；重点条目在公式前加 ★ 并把该 run 设黄底（`WD_COLOR_INDEX.YELLOW`）。
- 频率不靠感觉：先用真题题库统计各章命中次数（2015—2025 十一年），≥28 次记高频、12—27 中频、<12 低频，并在图例里写明依据。
- 脚本分工：`build_formulas.py`（排版）＋ `formulas_1/2/3.py`（内容，结构 `(latex, note, freq, star)`）——改内容不动排版代码。
- **给 OMML 公式上色的方法**（python-docx 不直接支持）：遍历 `m:oMath` 中每个 `m:r`，没有 `w:rPr` 就新建并插在第一个 `m:t` 之前，再往里加 `w:color`（可再加 `w:b` 加粗）。子元素顺序必须是 `m:rPr` → `w:rPr` → `m:t`。

## Common Pitfalls（都是真正的高频错点）
1. 正弦余弦分母漏阶乘（写成除以 3、除以 5，应为 3 阶乘、5 阶乘）。
2. 符号交替只改了一半（正弦、余弦、ln、arctan 都要逐项变号）。
3. 二重根忘记补 x（写成 C1 e 的 rx 次方 加 C2 e 的 rx 次方，其实后面那项要带一个 x）。
4. 复根把 α、β 放反（α 在指数上，β 在三角函数里）。
5. 特解与齐次解“撞号”了却乘 x，导致代入后系数解不出来。
6. 非齐次通解漏掉齐次部分（只写特解就交卷）。
7. ln（1 加 x）展开把常数项写出来（应为 0，从 x 开始；带 ln 2 的那种是另一个母版）。
8. **说明文字里写 LaTeX 却用了非原始字符串**（如 `'\alpha'`、`'\varphi'`）→ `\a`、`\b`、`\v` 被 Python 当转义符生成控制字符（0x07／0x08／0x0B），写 docx 时 lxml 直接抛 `All strings must be XML compatible: ... no NULL bytes or control characters`。规则：**任何含 LaTeX 的字符串一律用 `r''` 原始字符串**；生成器里再加一层 `clean()` 过滤控制字符兜底。
9. 改这类转义问题**不要在 shell heredoc 里拼反斜杠**（MSYS 会吞掉一层，匹配不上），用 `write_file` 落一个 .py 再跑；反过来也别用文件里的原始控制字符去匹配——文件里存的是 `\v` 两个字符，得匹配整条字符串（`'前缀[^']*'`）再替换。
