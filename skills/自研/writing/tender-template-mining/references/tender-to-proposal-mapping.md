# 招标文件 → 施工组织设计：该翻哪几节、怎么对应

配套样本：某城际铁路（市域铁路）土建施工技术标，招标文件 448 页、施组正文 779 页。
下面每条都在真实样本上核对过（或由用户口述定下）；标注"待定"的还没拿到用户确认，别当结论用。

## 一、五处要精读（顺序就是用户的工作顺序）

| 位置 | 拿什么 |
|---|---|
| 第一章 招标公告 | 项目基本盘（见第二节提取清单）；公告本身是索引页，细则分别指向第三、七、八章 |
| 第二章 投标人须知（含前附表） | 要求工期/质量要求、招标控制价、保证金、是否暗标、组卷与格式要求（册数、装订、页数、电子文件份数与格式）、分包、澄清与补遗时间、备选方案、是否偏离、评标办法类型；附件里还有主要人员资历要求表 |
| 第三章 评标办法 | 形式/资格/响应性评审表、否决投标（废标）情形、分值构成、三张评分表（商务 / 技术 / 报价）、评标基准价与扣分规则 |
| 第七章 技术标准和要求 | 工程重难点表、通用/专用技术要求（施组的重难点分析要逐条接住这张表）；节点工期常指向这里 |
| 第八章 投标文件格式 | 技术部分应包含的条目（骨架原话）、附表格式（机械表、试验/测量/质检仪器表、管线保护与改移表、交通导改表、临水引入表、临时用地及拆迁表、临电需求表、大型机械情况说明） |

合同条款与工程量清单属商务口径；但合同条款值得扫一眼——里面常点名"必须长驻工地、不得兼职"的主要领导
（项目负责人、技术负责人、安全总监、生产副经理）并附违约罚则，写人员配置时这几个是硬岗。

## 二、先看招标公告：要提取的信息（14 项）

1 项目名称/标段名称、2 建设地点、3 建设规模（线路长度、车站数、地下与高架各几座、站名、起讫点）、
4 合同估算价、5 工期（总日历天 + 计划开工/竣工日期）、6 招标范围、7 工区划分及概况（几站几区间）、
8 招标人/招标代理/联系方式、9 资金来源/出资比例/批文号/项目业主、10 投标人资格要求（资质、业绩门槛、联合体）、
11 招标文件获取时间与方式、图纸押金、12 投标截止时间、13 资格审查方式（后审/预审）、14 评标方法。

- 资金来源 = 项目投入资金从哪来：投标方知道就行，不考虑，也不写进投标文件。
- 工区：地铁/铁路标通常标大了才分好几个工区（一般一个项目在 10 亿上下，房建市政按实际情况）；
  工区划分由招标人定、**承包商不允许调整**（文件常带注：招标人可按管理需求增减，承包商无条件执行、
  不提费用或索赔），第七章 "工区划分及概况" 逐工区写明含哪些车站与区间、起讫里程、周边环境与控制因素。
  它是组织与管理口径（工区项目部、人员机械、施工平面布置按工区配），**不是工期口径**——工期节点按车站/区间给。
- 落点：建设地点 → 开头工程位置图；规模与工区划分 → 工程概况、工程特点，以及后面所有要分组的地方
  （组织机构、劳动力、平面布置图统统按工区来分）；工期 → 第一章工期目标 + 进度计划倒排；
  合同估算价 → 技术标里不能出现报价数额（招标文件常写明"用款计划不得出现投标报价的数额"）；
  资格与业绩 → 商务册的事，不进施组。

## 三、投标人须知（含前附表）再补这几项

是否允许分包；要求澄清的截止日期与澄清文件发布日期；是否允许递交备选投标方案（口语叫"副标"）；
其他编制要求（正副本份数、册数划分、装订方式、页数限制、是否暗标）；投标保证金金额与形式、投标有效期；
是否允许偏离；节点工期（常写"详见技术标准和要求"，要去第七章挖出来、落进进度计划章）；
递交投标文件地点、开标时间与地点、投标截止时间——这几项决定编制节奏：从截止时间往回倒，
留出集体校核、印刷封装、现场送达（或平台上传解密）的时间；纸质递交还是远程开标，决定最后一天要不要派人跑现场。

以上都是"本次怎么写就怎么办"，不预设。

## 四、评审用表当自查清单（不是施组内容）

形式评审表 / 资格评审表 / 响应性评审表是评委逐项打勾的核查表：投标人名称、投标函签字盖章、报价唯一、暗标、
联合体协议书与牵头人、授权委托书、投标内容、工期、工程质量、投标有效期、保证金、已标价工程量清单、安全承诺书。
它们不写进施组，但要抄下来当成"这些做了没有"的自查清单，出标前逐条问一遍。
跟施组对应的只有两处：形式评审里的"暗标"项；响应性评审里的"工期、工程质量"必须与投标函一致（别写成两套数）。

## 五、骨架三方对齐 + 章节数量怎么定

招标文件第八章的技术部分条目 = 评标办法施组评分表条目 = 施组正文章节，三者通常一一对应、措辞相近。
样本核对：14 条 = 14 个评分项 = 14 章；外加附表 8 张 + 附图若干。

**章节数量的定法（用户口径）**：常规是按技术评分表逐项设章节；招标文件后面给了格式要求 / 内容清单时，
**按格式要求划章节**，这时评分表降为参照依据，用来对一遍查漏；两者不一致以格式要求为准。
招标文件通常还有一句兜底："评标办法没有规定的评审因素和标准，不作为评标依据"。

## 六、评分表怎么用（把力气分配到分值上）

三张评分表通常都在第三章评标办法的附表里（样本：商务、施工组织设计、投标报价，另有市场信用评价）。
施组评分表的分值分布（样本技术部分共 32 分）：

| 项 | 分 |
|---|---|
| 前期实施方案及主要施工方案 | 6（最高，也最厚） |
| 工程总体目标及重难点分析、总承包部及工区组织架构职责及管理方案 | 各 3 |
| 进度、质量、安全、风险、文明施工环保消防保卫健康、智慧工地与标准化工地、劳材机配置、合同管理与分包、合理化建议 | 各 2 |
| 用款计划、协调配合措施及接口管理 | 各 1 |

- 每项都分高低两档（如 `1≤m≤2` / `0≤m<1`；用款计划低档直接 0 分）：每一章都要有，空着就掉低档；篇幅与打磨程度按分值排。
- 高分档的措辞就是写作标准：内容完整、针对性强、措施有力、认识深刻、可靠实用。写完拿这几个词自查。
- 技术标通常只占三成上下（样本另有投标报价 62 分、信用 3 分、商务 3 分），别把全部力气砸在技术标。

**算分思路（用户讲的）**：看分值构成 → 把能确定的先算出来（市场信用分自企业数据库提取、联合体取牵头人；
商务分按岗位配齐基本能拿满，样本商务 3 分 = 总承包部组织架构及人员配置 1 分 + 工区项目部 2 分，按缺岗与人员资格条件扣）
→ 开标时各家报价公布后按评标基准价规则代入（样本：基准价 = A×Q1 + B×Q2，Q1=Q2=50%；A 为有效评标价算术平均，
家数多时去掉最高/最低；B 为最高投标限价；报价等于基准价得满分，每高 1% 减 1 分、每低 1% 减 0.5 分，不足 1% 用插入法）
→ 剩下的技术分是唯一变量，反推自己施组要拿到多少分。

## 七、废标（无效标）条款：有就遵循，没有就不适用

样本里叠了三层：评标入围条件（保证金未足额、投标函工期超过招标期限、质量标准不响应、报价高于控制价）→
初步评审（形式/资格/响应性，一项不符即无效标）→ 无效标情形清单（弄虚作假、资格不符、技术方案明显错误或不符合暗标要求、
关键内容模糊无法辨认、承诺的机械到场时间不满足工期等）。
跟施组直接相关的是"技术方案明显错误 / 不符合暗标要求"和"机械到场时间不满足工期"两条。

**不是每份招标文件都有这类条款**——有的没有，没有就不适用；不要把它讲成通用规则。

样本的暗标要求（**仅当本次招标文件采用暗标时成立**）：正文不得出现投标单位名称、人员姓名及可识别身份的
字符/徽标/图案/照片/标识；第一册封面封底侧封为空白白纸；不盖章不签字；不设内封面/扉页/夹页/尾页/隔页/空白页；
电子件里的技术部分 PDF 也可能被要求"不带章"。

## 八、术语对照（招标文件用语 ↔ 项目上叫法）

| 招标文件 | 项目上 |
|---|---|
| 项目负责人 | 项目经理 |
| 技术负责人 | 总工 |
| 工区负责人 | 工区经理 |
| 安全质量管理负责人（资历表·总承包部）/ 安全副经理（资历表·工区）/ 安全总监（合同条款）/ 项目安全负责人（技术要求章） | 安全总监 |
| 大里程端 / 小里程端（按里程标号分） | 里程从起点往终点递增：**起点端＝小里程端，终点端＝大里程端**；不是"大站 / 小站"，也别跟大/小盾构（机型、直径）混 |

同一角色在招标文件里常有多处不同叫法；被问"某某是什么"时，先全文搜一遍再答。

## 九、组织架构怎么搭（样本核对过）

附件"主要人员资历要求表"就是组织架构的说明书，能反推三层：
上级领导指挥部（公司/联合体层级，独立于项目、不得兼任）→ 项目总承包部（经理层 + 职能部门）→ 工区项目部（班子 + 部门）。

- 搭法：项目经理（第一责任人）→ 领导班子成员各分管一条线（技术、安全、生产、商务、前期、书记；
  有盾构这类专业再加专业副经理）→ 职能部门（工程管理、安全环保、物资设备、计划合同、前期、财务、综合办、试验室）→ 作业层。
- 占比与人数：资历表备注里给人数下限（样本：总承包部不少于 30 人、正线工区不少于 40 人、停车场工区不少于 25 人），
  施组直接照写这几个数，不能低于；这个数是**管理人员**数，与"劳动力配置计划"章写的作业层劳动力是两码事。
- 岗位只许多、不许少：商务分按缺岗扣（样本：总承包部每缺一岗 0.1 分、工区 0.2 分），且不只查岗位齐不齐，
  还查每个人的资格条件对不对得上资历要求表。
- 工区按类型配岗位：只有盾构工区设盾构副经理与机电部，别一套模板套所有工区。
- 职责要写到部门级（评分点原话是"部门级岗位设置齐全、职责分工明确"）；管理方案章每项都要"流程 + 重难点 + 措施"。

## 十、人员与机械的数字

整数（不能半个人、半台）；拆出小数时总额能加就向上取整（2.5 → 3），总量定死就在工区间按工作量调剂（小的 2、大的 3）。
招标文件要求自有工人占比之类的，照它的口径答（哪怕实际队伍是外包的）；施组里的人数与商务册人员表要一致。

## 十一、概念对应样板（第 1 条评分项：工程总体目标及重难点分析）

| 招标文件的概念 | 施组里的落点 |
|---|---|
| 目标种类（安全/质量/进度/环境保护含水土/文明施工/内业管理/内外关系/信息化管理/科技研发与应用） | 逐项写目标 + 对应保证措施，一项不落；漏一项就是"目标不完整" |
| "技术标准和要求中所列重点、难点" | 第七章重难点表逐条覆盖 |
| "承包商提出"（包括不限于……） | 自己再提炼一批，这是"认识深刻"的来源 |
| 招标表的"施工要求"列 | 转成自己的对策，按安全/质量/进度/维稳/协调分组写 |
| 招标表的"设计控制措施"列 | 消化进对策，别原样当施工对策抄（那是设计口径） |

样本里这条写成：1.1 工程简况（含地质水文，再往下四级）→ 1.2.1 十项目标 + 1.2.2 十项对应措施 →
1.3.1 自提工程特点 → 1.3.2 重难点汇总表（前半段自提、后半段照招标表的车站/区间逐条接住）。

## 十二、地方性要求

安全、环保、消防保卫健康、智慧工地这些章要落到工程所在地的法规与文件（样本点了省级安全生产条例、
市安全监督管理办法、危大工程管理实施细则、有限空间作业规范、渣土运输管理规定等），只写国标会被认为不响应。

## 十三、内容取舍

见 `references/content-grading.md`。口径：评分表列了只说明它是评分项；什么算"必须有"由用户明确给出。

## 十四、待用户拍板（别当结论）

- 页数：招标文件写"技术部分页数不宜超过 600 页"，样本实际 779 页——有意超还是没在意，用户定。
- 附表 8 张的数据来源：厂家资料 / 公司台账 / 项目数据。
- 位置图与现场平面布置图用什么软件画。
- 风险管理体系算不算"必须有"（待用户给判断，别自己认定）。

## 十五、落点

这些最终要并进用户自己的 bid-technical-proposal 技能（桌面\我的小项目\Hermes社区技能\）。
那个技能是用户所有，改动必须等他明确说"改技能"；他没发话就只出草稿等他定。

## 十六、逐条核出来的细则（读一份招标文件时一遍扫完）

### 1. 同一要求常写好几遍 —— 取并集；不一致就都写上

典型三处：合同条款（通用/专用）、第七章技术标准和要求、第八章投标文件格式里的内容清单。
已核过的例子：甲供材料在合同条款与第七章"工作内容"各写一遍、又在"材料供应方式要求"里带规格再写一遍；
安全/质量目标在通用条款、专用条款、第七章"工程目标"、第八章投标人填的响应表里各写一遍，措辞有出入。

- 做法：定关键词（甲供、乙供、安全目标、质量目标、工期目标、文明施工、环保……）全文搜一遍，
  把每处出现的位置与原话列出来比对 —— 一致的照写一遍；**不一致就都写上**（取大值，一处不丢）。
- 同一件东西前后用词不同（"预埋套管"与"预埋套筒"）不算冲突，按并集处理；但**仍要在问题报告里点出来**，
  让编标人员关注这个地方，别自己闷头判一个口径。对外发问走第二章澄清程序，注意澄清截止日期。
- 抓兜底语：文件常写"除下表的外，其余均为乙供"这类封闭式定义，边界按它划。
- 材料那节的两层做法：甲供只写接收/进场验收/检验复验/报验/保管/预埋安装及验收（采购供货不是承包商的活，不写、
  写了就是答非所问）；乙供才写采购、进场检验、报审、标识、保管整套，且品种规格等级照招标文件写、不另立一套。
  有的文件把乙供再分档（I 类 / II 类）：采购方案的报批层级与供货单位的资格业绩要求不同，按它的分档写。

### 2. 第七章要整章读完，不是只看前面几节

文件结构：1 总则 → 2 工程简况（概况/范围/工区划分及概况/重难点/工作内容/接口管理/材料供应方式/工程目标）
→ 3 技术规范标准 → 4 通用技术要求（图纸管理、前期专项工作管理要求、施工现场管理要求与条件、验收与移交、勘察等）
→ 5 专用技术要求（总承包及工区管理、防水、盾构法、内置固定构件+槽道、桥梁、停车场、人防、精细化施工、
安全智慧管控系统、资产管理、施工材料管理、创优、创新及科研）→ 附件：危险性较大工程。
这一整章都是要满足的要求（可上百页）；专用技术要求的条文可以在质量（检查）章里引用写明"按本次文件相应条款执行"。
其中"接口管理"节：接口＝工程空间上的衔接（跟施工缝一样）——两个单位/专业/工序在空间上接头的那条缝，
是缝就容易出问题，所以接口管理写清谁干、什么时候办交接、交完谁管；工程接口（其他承包商）与管理接口
（建设管理单位/监理/地方政府）分开写。
小细节里全是硬指标（例：现场工程调度与安全监控场所不少于一定面积、各工区为招标人/设计/测量/监测/监理代表配几间
办公室与值班室、每工区会议室不小于多少平米，且面积"以工程量清单相应约定为准"要回清单核）——别当背景材料跳过。

### 3. 两张表是"上面写多少、我们写多少"

- **工程重难点表**：按车站/区间/车辆基地逐个列"自身风险 / 环境风险 / 前期拆改难点"，另带"设计控制措施"
  与"施工要求"两列。写重难点就按自身风险、环境风险分类逐条描述 + 对应措施（一条风险对一个措施）；
  设计控制措施是设计口径，别原样当自己的对策。
- **危大工程清单表**（附件）：列＝单位工程名称/分部工程名称/危大工程名称/是否为超过一定规模的危大工程/措施。
  一项对一项落，照它标注超规模项（写明组织专家论证），依据摆住建部 37 号令与地方实施细则；
  表前"进场后在此基础上补充完善"那句，在施组里照此承诺。

### 4. 第八章格式要求：技术部分条目 + 附表，照搬不改

- 技术部分条目常是 14 条（总目标及重难点、总承包部及工区组织架构职责及管理方案、前期实施方案及主要施工方案、
  进度计划及措施、质量/安全/风险体系及措施、文明施工环保消防保卫健康、智慧工地与标准化工地、劳材机配置计划、
  用款计划、合同管理与分包、协调配合及接口管理、降低造价与合理化建议）+ 附表若干（主要施工机械、
  试验/测量/质检仪器设备、建（构）筑物保护/管线保护拆除改移、交通导改、临水引入、临时用地及地上物拆迁、
  临电需求、拟投入大型机械情况说明）。拿一份成熟施组的章节跟这 14 条并排对一遍，能一一对上说明章节没搭错。
- 格式照搬的边界：**只有表格里的行数可按自己情况增减，其余一律不改** —— 列、列名、表头分格（跨几列 × 跨几行）、
  行高列宽、单位与大小写（文件写 Kw/m3 就照写，别改成 kW/m³）、表格外左上或右上角那行小字、
  表后跟着的注/说明/备注及其位置与缩进（实测一例是首行缩进两字符：注那行 x0 比表左边缘多出约 2 个字宽）。
- 这些附表是"本次文件给什么就照什么"，不是固定套路；同时接住格式章里顺带的硬话（不得出现投标单位名称/人名/
  识别性字符徽标、用款计划不得出现报价数额、总页码不宜过多）。

### 5. 大型设备台数是硬要求，要人去核实

地下隧道这类会逐区间写明盾构机台数；把它列进提醒清单，让编标人员跟机械部门或设备厂家确认台数、机型直径、
进场与到达时间、自有还是租赁（承诺的机械到场时间不满足工期，有的文件直接算无效标）。
盾构机明细表这类表的份数看**类型**不看台数：**同类型的合并到一张表**，类型不同才各做一张（既不是一台一张，
也不是一个工区一张）——先看表后注写明的适用工区，再数设备有几种类型。注里还可能写"可根据所选盾构机具体情况
适当调整表格内容"。

### 6. 工期目标夹在中间，但全文都要照应

工期常给两层：全线里程碑节点计划表（倒排）+ 按车站/区间逐项的节点表（前期专项开始、土建开始、主体完成、
附属完成、装修安装完成、移交铺轨）。节点是按工程对象给的，不是按工区给一个总工期 —— 进度别按工区粗排；
各章方案的工序与工期跟节点对齐，人员机械投入按节点倒推。怎么排是方法论，倒排正排都行，满足要求即可。

### 7. 正文里被 `**` / `***` 打码的参数：去工程量清单 PDF 找实数

公开版正文常把关键参数打成 `**` / `***`（管片外径、管片厚度、管片宽度、混凝土强度等级、桩径等）。
第五章末尾一般写着"工程量清单详见招标文件的其他材料部分"——那不是"文件没写"，是同套文件里的另一册。

- 去处：同目录的工程量清单 PDF（几百到上千页），搜关键字（管片外径 / 盾构掘进 / 直径…）读"项目特征描述"列，
  实数写在那里（样本读到：管片外径 7900mm、管片厚度 400mm、管片宽度 1600mm；隧道盾构掘进那条的"直径"就是
  管片外径，盾构形式＝复合式土压平衡）。图纸文件夹里更全；两处都没有就把这一项列进问题报告。
- 读到的数顺推校对一下再报：隧道内径 ＝ 管片外径 − 2 × 管片厚度（样本 7900 − 800 ＝ 7100mm），
  与断面常识对得上说明读对了；盾构机刀盘与盾壳外径要大于管片外径，选型时向厂家核。
