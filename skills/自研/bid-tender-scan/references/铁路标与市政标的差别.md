# 铁路标 与 市政标（地铁标）的差别

> **声明：下面的一切都是从两份具体文件里读出来的**（一份铁路标、一份地铁标），是举例不是规则。
> 手上这份文件属于哪类、要什么，一律以本次招标文件原文为准。

**用途说明：本文只是拿两个实际标做对比、说明铁路标与市政（地铁）标两类的差别。**
**技能的主例是市政 / 地铁标那一套；铁路标那份（雄忻）只作对比用，不是要照它写。**

## 怎么一眼分辨

| 看什么 | 铁路标 | 市政 / 地铁标 |
|---|---|---|
| 有没有"指导性施组" | **常有**（招标时随文件发）→ 章节照它搭，评分也拿它对标 | 一般没有 |
| 施组章节从哪来 | 指导性施组的章 + 招标文件"施工组织设计编制要求"的要点清单 | 招标文件"投标文件格式 → 技术部分格式"给的内容清单 |
| 专业怎么分 | 铁路专业：路基、桥涵、隧道、轨道、站房 / 枢纽配套，再带市政配套（道路、管廊、给排水、热力、燃气、水系） | 按工法与工区：明挖（盖挖）、盾构、高架区间、高架车站、桥梁拆复建、停车场、前期专项 |
| 计量与承包 | 常见"单价承包"（清单按子目、有招标人指导单价） | 常见总价 / 综合单价，看地区交易中心规则 |
| 工期怎么给 | 附件给"各标段总工期及分阶段工期要求"；指导性施组里有主要阶段工期与关键线路 | 第七章"工程目标"里给全线里程碑节点表 + 逐车站 / 逐区间节点 |
| 招标人体系 | 铁路建设管理系统（国铁集团 / 铁路建设管理公司），用"标段"、里程 DK | 地铁公司 / 城投 + 地方交易中心，用"工区"、车站名 |

## 章节骨架的差别（举例）

**铁路标（示例）**：编制依据、编制范围及设计概况 → 工程概况 → 建设项目所在地区特征（自然特征、
交通、水源电源、当地建材、卫生防疫）→ 施工组织安排（总体目标、组织机构与任务划分、总体施工安排与
主要阶段工期、施工准备和建设协调、关键线路、工程接口及配合、施工总平面）→ 大型临时工程和过渡工程 →
控制工程和重难点工程 → 施工方案（按铁路专业逐个：路基 / 桥涵 / 隧道 / 轨道 / 站房与枢纽配套，
再带市政配套各专业）→ 资源配置方案（材料设备采购供应、施工装备数量及进场、劳动力、资金使用）→
信息化（一体化管理平台、BIM、智慧工地、调度指挥中心）→ 管理措施（标准化、质量、安全、工期控制、
**投资控制**、环保、水保、职业健康、文物保护、文明施工、**节约用地**、冬 / 夏 / 雨季施工、
**沉降控制及观测**、预警与应急预案、信息化管理、技术创新、**农民工工资保障**）→ 施工组织图表

**市政 / 地铁标（示例）**：工程总体目标及重难点分析 → 总承包部及工区组织架构、职责及管理方案 →
前期实施方案及主要施工方案（前期专项 + 主要施工方案 + 施工现场总平面布置）→ 进度计划及措施 →
质量保证体系及措施 → 安全管理体系及措施 → 风险管理体系及措施 → 文明施工、环境保护、消防、保卫、
健康体系及措施 → 智慧工地建设、标准化工地建设目标和方案 → 劳动力、材料、机械设备配置计划及保障方案 →
用款计划 → 合同管理措施、分包计划和管理措施 → 协调配合措施及接口管理 → 降低造价、优化施工组织的
合理化建议 → 附表

## 铁路标特有的东西（市政标里很少见）

- **指导性施组**：章节依据，也是评分对标物（评分表里往往直接写"满足指导性施组要求"）
- **大型临时工程 + 过渡工程**单列成章（轨道板预制场、材料厂、集中拌和站、运输便道、填料拌合站、
  钢梁拼装场；过渡工程）
- **投资控制措施**、**节约用地措施**、**沉降控制及观测措施**、**农民工工资保障措施**、
  **技术创新计划**、**一体化管理平台 / BIM / 智慧工地 / 调度指挥中心**
- 评分里有"项目组织机构"这一档（含**自有产业工人数量**）
- 格式推荐常直接写在编制要求里（纸型、标题字体字号、每面行数字数、标题层级、总页数上限）

## 市政 / 地铁标特有的东西（铁路标里少见）

- **工区划分**（几个工区、每工区几站几区间），且注明承包商不得调整
- **危大工程清单表**（附件形式给出，逐项对照写）
- **甲供 / 乙供材料**清单（含"I 类乙供材料"的供货单位资格与业绩要求）
- **安全智慧管控系统 / 标准化星级工地**这类地方性要求
- **接口管理**单列（与机电装修、轨道、系统设备、市政交通接口）
- **合理化建议**一章（逐条点本标段的具体结构，必须结合本项目重写）
- 驻地与临建的硬指标（面积、间数）常写得非常细

## 两类都必须遵守的（不分铁路市政）

- 格式要求优先：招标文件给了内容清单或推荐格式，就照它来
- 评分表"评分标准"那一列逐条读 —— 它写的就是内容要求
- 招标文件里已经写明的东西（重难点、工作内容、接口、材料供应、目标、危大工程）逐条回应，一条不漏
- 措施跟着工法走；数字要经得起推；工期节点不得迟于；前后不一致进问题报告
