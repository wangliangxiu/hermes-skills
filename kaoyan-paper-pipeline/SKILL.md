## When to Use / 何时用
要出任何考研模拟卷（公共课或专业课）、要把一堆真题变成「命题地图」、要检查一套卷子是否超纲时加载。
把公式排进 Word 交给 `word-math-paper-docx`；只背公式用 `math-formula-memory`。

## 总览（一句话）
先用**考纲**划边界，再用**真题**抓套路，把两者压成一张**命题地图**，然后**照地图出题**；
出完**自己复算答案**、**逐题对大纲查超纲**、**逐页看图验收**。任何一步跳过，卷子都不算完成。

## 第 0 步｜先推出「到底考什么」（不背科目表，用三条规则推）
**核心规则：考什么由三个变量决定——学位类型 × 学科门类/专业代码 × 当年该校《招生专业目录》。**
不是由“科目名”决定，也不由“全日制/非全”决定。换专业、换学校、换年份，重跑下面的四问即可。

**四问推导链**（四问全部要回到当年官方文件，不能凭印象）：

**问 1：几个单元（几门课）？**——看教育部当年《全国硕士研究生招生工作管理规定》（每年 9 月发布）：
- **四单元（默认，总分 500）**：政治 100 ＋ 外语 100 ＋ 业务课一 150 ＋ 业务课二 150。
- **三单元（总分 500）**：教育学、历史学、医学 3 个门类的**学硕**，以及体育、应用心理、博物馆、
  临床医学、口腔医学、公共卫生、护理、药学、中药、中医、医学技术、针灸等 12 个**专硕**：
  政治 100 ＋ 外语 100 ＋ **专业基础综合 300**。
- **两单元（总分 300）**：管理类专硕（工商管理、公共管理、会计、审计、图书情报、旅游管理、工程管理等）：
  **199 管理类综合能力 200** ＋ 外语 100（政治不考初试，移到复试）。
- **单独考试**：初试科目设置与同专业全国统考**相同**（科目名多带“单独考试”字样，如 111 单独考试政治）。
- **非全日制不改变科目**：教育部原文“全日制和非全日制研究生考试招生依据国家统一要求，执行相同的政策和标准”。
  非全变的是招生计划、修业年限、学费、上课方式、复试线、定向就业——**不是考试科目**。

**问 2：考不考数学、考哪一档？**——看目录里第三单元的那串代码：
- **301 数学一**：工学中对数学要求较高的学科（机械、电子、计算机、土木、水利、化工、地质、矿业、航空、兵器、核、测绘等）。
- **302 数学二**：工学中对数学要求较低的学科（纺织、轻工、农业工程、林业工程、食品等）与部分院校专业。
- **303 数学三**：经济学、管理学门类（含管理类中对数学要求较高的学科，如农林经济管理）。
- **314 数学（农）/ 315 化学（农）**：农学门类。
- **601—609**：招生单位**自命题**的理学数学（部分数学/统计专业）。
- **不考数学**：哲学、法学、教育学、文学、历史、医学、艺术等门类，第三单元往往是自命题专业基础。
- ⚠ 同一专业不同学校可能挂不同数学（如建筑学既可能考数一也可能不考），**以目录为准**。

**问 3：外语考哪个？**——201 英语一（学硕为主）｜204 英语二（多数专硕）｜202 俄语｜203 日语｜240—289 为招生单位自命题外语。

**问 4：专业课（业务课二）是什么？**——**永远是招生单位自命题**，代码与名称只以**当年该校《招生专业目录》**为准，
命题依据是该校公开的《自命题考试大纲》＋指定参考书。目录每年 9—10 月更新，**换年份就必须重核**。

**科目代码规律（自己推，不用背清单）**
| 代码段 | 含义 | 命题方 |
|---|---|---|
| 1×× | 统考政治类：101 思想政治理论、111 单独考试政治、199 管理类综合能力 | 教育部 |
| 2×× | 统考外语：201 英一、202 俄、203 日、204 英二；240—289 为单位自命题外语 | 教育部/招生单位 |
| 3×× | 统考业务课一：301 数一、302 数二、303 数三、314 数学（农）、315 化学（农）、396 经济类联考、397/398 法硕、408 计算机学科专业基础 | 教育部 |
| 4××—5×× | 统考业务课二（如 497 法硕综合） | 教育部 |
| 6××/7×× | 招生单位自命题（601—609 专供自命题理学数学） | 招生单位 |
| 8××/9×× | 招生单位自命题专业课（最常见：849 材料力学、801 经济学） | 招生单位 |

**推出结果要写成一页《考试结构卡》**：单元数｜各单元科目与代码｜各自满分与时长｜命题方（统考/自命题）｜
该科目的考纲从哪拿｜该科目的真题能不能拿到。这张卡是后面六步的输入，**卡错了后面全白做**。
→ 展开规则与条款出处见 `references/exam-structure-rules.md`

## 第 1 步｜取考纲（划边界，不能靠印象）
- **公共课**（数学、英语、政治）：教育部考试大纲，公开 PDF 逐年版可抓；要求分「了解／理解／掌握／会」四档。
- **专业课**：学校官网《自命题考试大纲》＋《招生专业目录》（确认专业代码、学硕/专硕、专业课代码与名称）。
- **学硕与专硕科目常常不同，必须逐字核对**。实例：某校 081400 土木工程（学硕）=政治＋英语一＋数学一＋849 材料力学；
  085901 土木工程（专硕）=政治＋英语二＋数学二＋850 工程力学。用错就全盘作废。
- **抓取三个坑**：
  1. 附件要验证码 → cookiejar 建会话，抓 `createimage.jsp` 存图，**自己看图读出数字**，再带 `codeValue` 用同一会话请求；
     cookie 必须落盘（`MozillaCookieJar.save()`），分进程跑会丢会话。
  2. zip 里中文名乱码 → `zipfile.ZipFile(p, metadata_encoding='gbk')` 重新解压。
  3. 老版 `.doc` → Word COM 批量转换会卡死（无输出、进程不退），改用 **UTF-16LE 粗提取**：
     `raw.decode('utf-16-le','ignore')` → 正则保留中英文段落。
- **产出两份东西**：① 大纲全文 txt 存档；② 《考纲解析》——逐章写「考试内容／要求分层／本章重点难点／命题判断」，
  另加两节：「不考或只到概念层的部分」（省时间）与「真题可得性说明」（官网是否公开真题）。
→ 实操细节见 `references/subject-kaogang.md`

## 第 2 步｜取真题（套路来源）
- 优先找**带题面＋答案＋考点标注的结构化来源**，不要零散图片或来源不明的回忆版。
- **已实测可用**：
  - 数学：GitHub `PondFish-me/fish.888.moe` 的 `data/数学一/数学一_YYYY.json`（1987—2026，逐题含题面/选项/答案/考点/解析）。
  - 英语：GitHub `TsekaLuk/Kaoyan-English1-Papers`（papers、english1_from_github 有真 PDF；solutions/*.md 实为真题文本）；
    聚创考研网公开 PDF（历年“真题及答案”，URL 需搜索获取）。
  - 专业课：**多数不公开** → 改用「官方考纲＋指定教材典型题型」命题，不用回忆版充数。
- **三条硬规矩**：
  1. **交叉验证**：至少抽 1—2 题与独立公开出处逐字对过，再采信整个文件。
  2. **指纹核验年份**：给每一年备一组该年独有的“指纹词”，用命中数判断正文到底是哪一年。
     （实测抓到两份：文件名写 2021 的其实是 2015，写 2024 的其实是 2022。）
  3. **缺就写明缺**：拿不到的答案键或年份，在分析文件里如实标注，绝不拿不明来源顶上。
- **下载三个坑**：Git LFS 断链（1125 字节的 404 页冒充 PDF）、中文文件名要 `urllib.parse.quote(...)`、
  GitHub 直连超时就给单条命令挂代理（别 export 全局代理）。

## 第 3 步｜分析与总结（产出「命题地图」）
六个维度，**每个都要落到数字或清单，并写进 `真题分析\` 的文件里**：
1. **结构规格**：满分／时长／各题型题量与分值（逐年核对，特别注意改版年份，如数学 2021 年改版）。
2. **题号↔科目地图**：哪几题考哪科，改版后是否稳定（数学：选择=高4+线3+概3；填空 11–14 高、15 线、16 概；解答 17–20 高、21 线、22 概）。
3. **题型配比**：数学按“入口类型”统计（放缩/估计、秩与子式、特征值相似、对称性、换元、泰勒、洛必达…）；
   英语按题干类型（细节、推断、态度、主旨、词义、因果）。
4. **考点频率**：各章被命中的次数 → 直接用于给公式册/复习材料分「高频/中频/低频」上色。
5. **套路清单**：每类题的“命题人怎么设计入口”（如数学：补线/补面→格林或高斯或斯托克斯→化成面积或常数）。
6. **答案分布**：正确选项 A/B/C/D 的分布（英语实测：完形各年基本各 25%，阅读 C 略多 B 略少）。

## 第 4 步｜出题（照地图动手）
**铁律**：
1. 只出**模拟卷**，卷头必须标「模拟卷，非历年真题」；不写“押题、命中”这类字眼。
2. **考纲是硬约束**；考纲没公布的题型结构只能推断，且**必须标注“推断，非官方公布”**。
3. **不瞎编**：每道题自己先会做，答案经验证才写进卷子；不会的题型宁可不出。
4. **先列分布表**（题号→知识点→分值）给人过一眼，再动手排版，避免做完返工。
5. 选项/答案分布要**均衡且不规整**：别出现“某选项 9 个、另一选项 0 个”，也别写成 ABCD 循环。
6. **难度体现在“入口需要识别或变形”**，不是加大计算量。

**工程做法**：内容与排版分离（内容模块 `名词题.py` + `build.py`），公式用 `$...$` 包着；
出第二套时用“导入旧模块 + 覆盖个别题 + 重排题号”，不要重写整套。

## 第 5 步｜核验（不许口算）
- 数值题**先写 `calc.py` 把所有答案算出来打印**，再写 `build.py` 排版，两边数字必须对上。
- **两种方法互验**：曲线积分用“直接积分 vs 补线+格林”；矩阵用 `eigenvals()` 与 `P⁻¹AP` 是否真对角；
  概率无偏性用大样本模拟（如 30 万次抽样验证修正后的估计量）。
- **改了参数要连算式里的分子分母一起改**——实战教训：答案值改成了新数，算式还写着旧数，属“答案对、过程错”。
- 核验脚本落盘留证，可随时重跑复核。→ 配方见 `references/answer_verify_recipes.py`

## 第 6 步｜超纲检查（出完必做，不能凭印象）
- **正向**：把每道题的题面对到大纲章节关键词上，找“对不上任何章节”的题。
- **反向**：把大纲之外的概念做成**黑名单**扫源码；**出题候选清单也要过一遍黑名单**。
  数学一黑名单（实测）：一致收敛、单侧置信限、正交轨线/包络、雅可比换元、留数、拉普拉斯变换、
  若尔当标准形、奇异值/广义逆、含参量积分、随机过程。
- **真题先例可救“大纲没明写”的边缘题**：如梯形公式误差证明、最大次序统计量＋均方误差最小，
  大纲没单列，但 2024 数一真题第 20、22 题同型 → 不算超纲，报告里写明真题出处。
- **技术坑**：docx 里公式是 OMML，`paragraph.text` 读不到数学内容，抽题面必须遍历 `w:t` 与 `m:t`；
  切题要从「一、选择题」那一段开始切，否则会被卷头「注意事项」里的 1．2．3．把题号带乱。
- **产出《超纲检查报告》**：检查方法、逐章结果、边缘项及其依据、需删项、结论。

## 第 7 步｜排版与交付
- **docx ＋ PDF 两份**（要打印）；公式用 `word-math-paper-docx` 的 LaTeX→OMML 管线，公式要是 Word 原生可编辑格式。
- **逐页看图验收**：公式渲染、单位、上下标、下划线、截断、乱码都靠这一步发现（公式转 OMML 偶有静默失败）。
- **目录规范**：`桌面\考研\` 下按科目分（考研数学／考研英语／考研土木…），
  每科统一四件套：`模拟卷\`、`真题数据\`、`真题分析\`、`记忆材料\`（专业课另加 `考纲\`）。
- 交付前自己完整跑一遍，不让主人替我双击测试。

## Common Pitfalls（全流程，都是实战踩过的）
1. **没对大纲就交卷**——超纲检查是必做步骤，不是加分项。
2. **把模拟卷说成真题**——误导，绝对不做。
3. **学硕/专硕科目搞混**（数学一 vs 二、849 vs 850）。
4. **选项分布不均衡或过度规律**——一眼看穿，重排选项时要同步改解析里的“选 X”。
5. **改了参数只改结果、不改算式**——最隐蔽的错误。
6. **抽题面漏掉公式** → 检查结果全是“未匹配”，误判为超纲。
7. **深信文件名**——英语真题两份文件名与内容不符，必须先指纹核验。
8. **用不明来源的“回忆版真题”**——把不确定性写进卷子。
9. **只交 docx 不给 PDF**、交付前不逐页看图。
10. **拿不到的资料假装拿到**——缺什么就写“缺、待补”，下次接着弄。

## 改了技能之后的回归流程（硬规矩）
技能（含配套的 word-math-paper-docx / math-formula-memory）一旦改动，必须把下面三件事按顺序做完才算改完：
1. **回归已交付的产物**：受影响的卷子与报告全部重新生成（内容模块 → build → 公式计数 → 逐页看图 → 超纲检查 → 字体体检）。不能只改技能不重出卷子。
2. **重新打包分发件**：如 `桌面\考研\技能包\考研出卷技能包_<日期>.zip`，里面的技能目录与样例卷必须是新版（样例 PDF 重出，别拿旧文件充数）；旧包删掉，只留最新版。
3. **重新上传 GitHub 覆盖旧版**：技能推到 `wangliangxiu/hermes-brain` 的 `skills/自研/…`（本地技能目录 → 仓库对应子目录 → commit → push），不允许仓库里留着旧版技能。

一句话口令：**技能改了 → 产物重出 → 重新打包 → 仓库覆盖**。

## 批量出卷的编排与交付（一次出六套的实战教训）
1. **不要把“整套卷子”外包给一个子代理**：实测两套英语卷各派了一个子代理，**两个都撞了 600 秒上限**
   （一个死在排版前，一个死在自检中）。正确拆法：子代理只负责**最容易丢上下文的“写内容模块”**
   （英文文章/题干/选项/答案/解析），**排版与核验自己来**；或者干脆自己从头写。验收子代理的产物时，
   **不要信它自己的校验脚本**（那个报了一堆“不一致”，其实是它正则漏了格式空格造成的假警），自己重写一个。
2. **Windows 下给 python 脚本传路径必须用原生写法**（`C:/Users/...`），不能把 bash 的 `"$HOME/..."`
   直接当参数传——MSYS 已禁用路径转换，`/c/Users/...` 会被当成当前盘根下的目录，文件静默落到 `C:\c\Users\...`
   下，白跑一次（渲染分页图时真踩过）。
3. **命令里不要出现 `rm -rf` / `rm -r`**：会触发安全拦截并让整条命令卡死等确认（等不到就超时）。
   要删就在 python 里 `shutil.rmtree()`，或逐个列文件名删。
4. **交付前必须清点，不靠记忆报数**：写一个 `final_check.py` 一次列出全部卷子的页数、docx/PDF 大小、
   公式段数（直接数 docx 里 `<m:oMath`），六套一起对，避免“说错了页数”。
5. **Word 导 PDF 会残留 WINWORD.EXE 占住文件**：再导同一路径会报 `SaveAs` COMException。
   做法：改导到另一个文件名 → 看图验证 → `cp -f` 覆盖旧文件；**不得擅自 `taskkill winword`**（用户可能开着别的文档未存）。
6. **每科建一个出卷脚本目录**，子目录（如 `_e2/` `_e3/`）隔离同科不同套的内容与图表，避免互相覆盖。
