# 工期怎么排

> **声明：本文里的数字、面积、间数、天数、表名、章节号、项目名都是举例**（取自某一份招标文件），
> 不是通用要求。写的时候一律按**本次招标文件**的原文来 —— 它怎么写就怎么办，没有就不用管。

## 工期怎么排（招标文件的要求是红线）

- **工期计划照着招标文件那两张表编**（不是自己另设一套节点）：把它的里程碑节点、
  车站 / 区间节点当骨架，再往中间填工序、工作面、流水节拍。
- **红线是招标文件上的工期要求**：有要求（总工期、里程碑节点、车站 / 区间的节点工期）就照它走，
  不得迟于、不能超过；没有明确要求时，才自己按总工期合理排。
- 怎么排是方法论问题，不是必须的：倒排、正排都可以，**满足要求即可**。
  倒排＝从总时长倒着推（先定总工期 → 理清工序 → 结合实际工作时间、工作面、流水节拍回推）；
  正排＝从开工往下推。两条路都行，只要落到纸上的每个节点都满足招标文件的要求。
- 留压缩余量：绝不能超过招标文件给定的施工期限
- 节点工期（招标文件有时会给）要单独排出来，落到"关键节点工期计划 / 里程碑节点计划"里
- 招标文件里的工期常是两层：**全线里程碑节点计划表（倒排）** + **按车站 / 区间逐项的工期节点表**
  （前期专项工作开始日期、土建施工开始日期、主体结构完成日期、附属结构完成日期、
  车站装修安装完成日期、移交铺轨日期）。这两张表常"夹"在"工程目标"那一段里，看着像顺手一提，
  其实是**全文的约束 —— 写施组时全篇都要照应它**：进度计划按它排，各章施工方案的工序与工期安排
  跟节点对齐（例：某区间移交铺轨 2025-06，那它的主体结构完成、附属完成、验收、移交都得排在这之前），
  平面布置与人员机械投入也按节点倒推。
- 注意节点是**按工程对象**给的（车站一个一个、区间一个一个，各带一串节点日期），
  **不是按工区给一个工期** —— 写进度计划就照这个粒度落，别做成"某工区几个月"的粗排。
  工区是组织与管理口径（工区项目部、人员机械、场地），工期是工程对象口径，两个别混着用。
- 表下的注照着办：承包商应按上述工期编制投标文件、节点可自行优化但不得迟于；
  建设管理单位有权调整工期节点、承包商服从；所有工期优化不能索赔；
  节点时间均为当月月末、以验收合格之日为准
