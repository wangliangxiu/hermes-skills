# Narrative Script Example: Jiaozuo Railway "一列火车看百年"

**Context.** Validated with a user who is a local of Jiaozuo, Henan province.
**Format.** Image-first, text-light. ~600 words across 17 panels (12 main + 4 transitions + 1 ending).
**File delivery.** Always save to Desktop as `.txt` (NOT .md).

## Structure template

```
[Opening page]     — 1 panel: hook line
  ↓
[Section 1: Era A] — 3 panels: establishing, detail, wide
[Transition A→B]   — 1 panel: no text, gradient + directional element
  ↓
[Section 2: Era B] — 3 panels: establishing, detail, wide
[Transition B→C]   — 1 panel
  ↓
[Section 3: Era C] — 3 panels
[Transition C→D]   — 1 panel
  ↓
[Section 4: Era D] — 3 panels
  ↓
[Closing page]     — 1 panel: summary + call to action
```

## Transit system (validated)

- **1902 → 1970 transition**: 运煤敞车的对开门打开，门框短暂充满画面，穿过后变成1970绿皮车
- **1970 → 2000 transition**: 绿皮车窗下拉窗，玻璃泛起光晕，穿过后变成2000空调车
- **2000 → 高铁 transition**: 列车尾部风挡缝隙，穿过后变成白色流线型

Fade colors between sections guide the transition (warm sepia → cool blue-white).

## Content ground rules validated with user

1. **DO NOT fabricate domain details** — Train carriage types, door styles, window mechanisms were all user-corrected. See `chinese-train-carriage-facts.md` in this references directory.
2. **DO NOT include Yueshan Station (月山站) in images** — it's outside the city in mountains, doesn't fit urban-narrative framing. OK in text captions only.
3. **NO specific building names** (Wanda, postal center, etc.) unless user explicitly provided.
4. **NO text in AI-generated image prompts** — text is added manually later
5. **NO人物 in images** — use objects that imply human presence instead (luggage, coal, items on platform)
6. **铁路是主角，城市是背景** — railway device is the protagonist, city atmosphere is background

## Example: 一列火车看百年 (complete narrative script)

```
【开篇页】
一座小城，四条铁轨。从1902到2026，一列火车看百年。

【SECTION 1 · 1902 · 蒸汽时代】
图1: 第一声汽笛划破豫北平原的清晨。1902年，道清铁路通车。
图2: 乌黑的煤从敞车顶部堆成小山。那时候，每一块煤都烧出一个时代的温度。
图3: 一列接着一列，从矿场驶向远方。本地的第一张名片，是黑色的。

【过渡 · 1902 → 1970】
煤烧完了，火车没有停下。车轮碾过铁轨，碾过半个世纪的烟尘。

【SECTION 2 · 1970 · 绿皮时代】
图4: 70年代，绿皮车开进了本地人的日常。墨绿色的车厢，装着出差、探亲、和第一次出远门的心跳。
图5: 车窗拉下一半，风灌进来。那根铁棍挡得住小偷，挡不住窗外的好奇心。
图6: 月台上的人，等着下一趟车把自己带到未知的地方。那个年代，远方是绿皮车给的。

【过渡 · 1970 → 2000】
绿皮车越来越旧，铁轨越修越新。时代走得比火车快。

【SECTION 3 · 2000 · 空调列车时代】
图7: 2000年，火车换了新衣裳。白色车身、蓝色条纹、茶色玻璃——跑得更快了，也更安静了。
图8: 车窗再也打不开了，风被挡在外面。从没想过有一天，会怀念那根铁棍和漏风的窗。
图9: 城市在膨胀，铁轨在延伸。本地从矿区变成了城市，火车也变了模样。

【过渡 · 2000 → 高铁】
快一点，再快一点。直到快得让人忘记了等车的日子。

【SECTION 4 · 高铁时代】
图10: 白色闪电划过豫北平原。300公里的时速，把百年路程缩成一小时。
图11: 车窗关得更严了，窗外的世界却看得更远。本地，已经不再是那个只有煤的地方。
图12: 铁轨还是那条铁轨，火车早不是那列火车。

【结尾页】
从1902到2026。一列火车，拉走了一百年的煤，拉来了一座城的明天。

【车票 · 扉页】
下一站，更好的本地。
```
