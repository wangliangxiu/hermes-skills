## 技术说明

- **字号2** 适合 170x320 分辨率，大字清晰
- **字号1** 适合在颜文字下方显示补充文字
- 所有颜文字用 `tft.getTextBounds()` 计算宽度后居中显示
- 编码使用 UTF-8，确保 Arduino IDE 文件保存为 UTF-8 编码
