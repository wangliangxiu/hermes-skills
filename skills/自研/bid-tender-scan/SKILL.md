# 检查招标文件（先把该写什么扫清楚）

> **数字与例子声明：文中出现的数字、面积、间数、台数、天数、时限、表名、章节号、项目名都是举例**，
> 一律以**本次招标文件**的原文为准。凡是牵扯到数据的地方（工期天数、节点日期、面积、间数、人数、
> 机械台数、材料规格与等级、报审时限、各类比例）都要回本次文件原文逐个核 ——
> 不能把别处抄来的数、或这里举例的数，当成本次的要求写进去；文件没写的就不写，拿不准的进问题报告。

## 什么时候用它

- 刚拿到招标文件，要先扫清楚"这份文件要求我写什么、写到什么程度"
- 用户说：看招标文件、这个标怎么要求、帮我捋一遍招标文件、招标文件里要抓什么

不适用：动手编投标文件（用 bid-document-writing）；施组正文怎么写（用 bid-technical-proposal）。

## 这一步产什么（产不出这三样，就别说扫完了）

1. **"要逐条回应"的清单** —— 文件里已经写明的东西，一条不落地列出来（重难点、工作内容、接口、
   材料供应、工程目标、危大工程清单、格式要求的内容清单……）
2. **问题报告** —— 前后不一致、两处说法不同、拿不准的地方，指清是哪两处、各写的是什么
3. **核实提醒** —— 要跟公司内部或外部核实的（大型设备台数与到场时间、供货单位资格），提醒编标人员去办

**每一样东西都知道上哪儿找**：正文八章各管什么、图纸册与勘察报告 / 补遗答疑 / 指导性施组 / 清单造价
这几处要另外找 —— 见 `references/信息来源对照表.md`，扫标时按它逐行落实。

## 第 0 步 先分流：这个标属于哪一类（不判断就别动手）

铁路标和市政（地铁）标是两条路：**铁路标常有"指导性施组"，章节照它搭、评分也拿它对标；
市政标没有，章节照招标文件"投标文件格式"那份内容清单搭**。两类各自特有 / 共有的东西，
见 `references/铁路标与市政标的差别.md`（开头那一段先看）。

- 是不是铁路标、有没有附"指导性施组" → 有就照它的章节搭
- 有没有格式要求（招标文件给了内容清单那种）→ 有就按格式要求定章节，评分表降为参照
- 明标还是暗标 → 暗标才要抹身份信息
- 给多长时间 → 决定哪些整段沿用、哪些必须精写
- 有没有废标（无效标）条款 → 有就必须逐条遵守，没有就不适用

## 第 1 步 标基本盘：先看招标公告，再看投标人须知

招标公告里标出这些（公告是整份文件的索引页，细则都指向后面几章）：

- 项目名称与标段名称、建设地点
- 建设规模：线路长度、车站数量、地下站与高架站各几座、站名、起讫点
- 合同估算价、工期要求（总日历天 + 计划开工与竣工日期）
- 招标范围、工区划分（分几个工区、每个工区几站几区间）—— 标大了会分好几个工区：
  地铁、铁路标一般一个项目在 10 亿上下，房建、市政标按实际情况。
  "技术标准和要求"那一章里有"工区划分及概况"，逐个工区写明包含哪些车站、哪些区间、起讫里程、
  周边环境与控制因素，写施组时按工区对着看（组织架构、人员机械、施工平面布置按工区配；
  进度不要按工区排，要按车站、区间的节点排 —— 详见 bid-technical-proposal 技能的 references/工期怎么排.md）。
  工区划分由招标人定，承包商不允许调整（文件里常带注：招标人可按管理需求增减工区，
  承包商无条件执行，不提费用要求与索赔）
- 招标人 / 招标代理机构 / 联系方式
- 资金来源（知道就行，不写进投标文件）
- 投标人资格要求（资质、业绩、联合体规定）—— 用来判断能不能投
- 招标文件获取时间与方式、图纸押金
- 投标截止时间、资格审查方式、评标方法

投标人须知（含前附表）里补这些：

- 是否允许分包
- 要求澄清的截止日期 与 澄清文件发布日期
- 是否允许递交备选投标方案（副标）
- 其他编制要求：正副本份数、册数划分、装订方式、页数限制、是否暗标
- 投标保证金金额与形式、投标有效期、是否允许偏离
- 节点工期（有的话去"技术标准和要求"那一章挖）
- 递交投标文件地点、开标时间和地点、投标截止时间

顺手看两张表：

- 主要人员资历要求表 —— 反推组织架构；表下备注常给人数下限（编排人员不能低于它）
- 形式评审表 / 资格评审表 / 响应性评审表 —— 当"这些做了没有"的自查清单，不写进施组

## 扫招标文件对照清单（按章往下过）

拿到招标文件就从第一章顺着扫到最后一章，边扫边记。各章抓什么：

- 第一章 招标公告：项目与标段名称、地点、建设规模（线路长度、车站数与工法）、合同估算价、工期
  （总日历天 + 计划开竣工日期）、招标范围、**工区划分**、资格要求、文件获取方式、
  投标截止时间、资格审查方式、评标方法
- 第二章 投标人须知（含前附表）：是否允许分包、澄清截止日期与澄清文件发布日期、是否允许备选方案（副标）、
  正副本份数与册数划分 / 装订方式 / 页数限制 / 是否暗标、投标保证金与投标有效期、是否允许偏离、
  节点工期、递交投标文件地点与开标时间
  · 顺手两张表：主要人员资历要求表（反推组织架构，表下备注常给人数下限）；形式 / 资格 / 响应性评审表
    （当"这些做了没有"的自查清单，不写进施组）
- 第三章 评标办法：各评分表的分值构成、算分思路、**"评分标准"那一列逐条读**（它就是内容要求）、
  废标（无效标）条款（有就必须逐条遵守，没有就不适用）
- 第四章 合同条款及格式：通用 + 专用条款里的工期、质量等级、材料、文明施工、环保、奖罚，
  以及合同附件（组织机构、廉政责任书、安全责任保证书、履约保函、违约及奖励标准、保修书、联合体协议）——
  跟第七章对照着看，说法不一致按下面第 2 条办
- 第五章 工程量清单：编制说明、报价要求，以及末尾那份《工程量清单项目及计算规则》附表
  （按工法分节，节内一级项目＝施工顺序）；清单看"开项"不看数量，总价措施那类不用管
- 第六章 图纸：工程位置、控制因素、风险源、尺寸；**图纸册里往往另附一份岩土工程初步勘察报告**
  （按工点分册，主报告 + CK 系列附件）—— 施组里"工程地质与水文地质"、不良地质与特殊性岩土、
  液化判别、承压水与降水、盾构选型、监测与沉降控制、风险源，都从它取（见 `references/图纸册与勘察报告怎么用.md`）
- 第七章 技术标准和要求（正文最长的一段，一直写到后面那份附表为止）：总则 → 工程简况
  （概况、范围、工区划分及概况、工程重难点、工作内容、接口管理、材料供应方式、工程目标）→
  技术规范标准 → 通用技术要求（图纸管理、前期专项工作管理、施工现场管理要求与条件、验收与移交、勘察等）→
  专用技术要求（总承包及工区管理、防水、盾构、槽道、桥梁、停车场、人防、精细化施工、安全智慧管控、
  资产管理、施工材料管理、创优、创新及科研）→ 附件：危险性较大工程清单表。
  **整章都是要满足的要求**，逐节抓，别只看前面几节
- 第八章 投标文件格式：技术部分格式（施组编制要求的内容清单 + 附表 1~8）、经济部分格式、
  商务部分格式（投标函、各类承诺书、人员与业绩表、组织机构框图、拟分包工程表、商务合同条款响应表、
  **技术部分响应偏离表**、盾构机情况表等）

扫的过程中同时做三件事：

1. 文件里已经写明的东西（重难点、工作内容、接口、材料供应、工程目标、危大工程……）→
   记成"施组要逐条回应"的清单
2. 前后不一致 / 两处说法不同 / 拿不准的 → 写进问题报告，指清是哪两处，提醒标书制作人员
3. 要跟公司内部或外部核实的（大型设备台数与到场时间、机械来源、供货单位）→
   提醒编标人员及时跟机械部门、设备厂家沟通

## 第 2 步 看评标办法

- 找评分表（商务、施工组织设计、报价，可能还有市场信用），把分值构成记下来
- 算分思路：能确定的先算（信用分、商务分这类）→ 开标拿到各家报价后，按评标基准价规则算出报价分
  → 剩下的技术（施组）分是唯一变量，反推自己要拿多少
- **评分表的"评分标准"那一列要逐条读** —— 它写的就是招标人对投标文件内容的要求，
  等于告诉你这份投标文件应该具有哪些东西。把高档、低档描述里的名词和形容词拆出来，
  就是这一章"要写什么、写到什么程度"。
  例：某评分项写"体系完整，措施有力，风险评估全面准确，事故应急处理预案全面、有针对性" →
  这一章就必须有体系、措施、风险评估、应急预案四块，而且要做到全面、准确、有针对性。
- 每一档的措辞就是写作标准，写完拿它对一遍

## 术语对照（招标文件 ↔ 项目上叫法）

- 大里程端 / 小里程端 = 按**里程标号**（DK / 里程值）分：里程从**起点往终点递增** ——
  起点那一端是小里程端（标号小），终点那一端是大里程端（标号大）。
  文件里说某站"小里程端为盾构始发、大里程端为盾构接收"（或反过来说），指的就是这个站的两头，
  别理解成"大站 / 小站"
- 项目负责人 = 项目经理；技术负责人 = 总工
- 工区负责人 = 工区经理；安全负责人 = 安全总监

## 常见坑

- 不先分流就开写：铁路标、有格式要求的标、明标暗标、时间长短，走的路不一样
- 只看前几章就动手：第七章（技术标准和要求）整章都是要求，第八章（投标文件格式）也是要求，都得扫到底
- 扫完不落三件事：既没出"要逐条回应的清单"，也没出问题报告，也没提醒该去核实的人
- 提醒类漏掉：大型设备的台数与到场时间、供货单位资格这些该跟机械部门 / 设备厂家核的，没提给编标人员
- 把文件里的举例当成本次要求（数字、表名、章节号、项目名）—— 一律以本次文件原文为准
- 前后不一致的地方自己拿主意定了（哪怕判断成"同一件东西的两种叫法"，也要报一声）

## 扫完的产出检查清单

- [ ] 第一章到第八章逐章扫过，没有跳章（第七章、第八章尤其要扫到底）
- [ ] "要逐条回应"的清单出来了：重难点、工作内容、接口、材料供应、工程目标、危大工程清单、格式要求的内容清单
- [ ] 工区划分、材料甲供乙供范围、工期节点（含车站 / 区间逐项节点）都记下来了
- [ ] 问题报告出来了：前后不一致、两处说法不同、拿不准的地方，都指清了是哪两处
- [ ] 核实提醒提给编标人员了：大型设备台数与到场时间等要找机械部门 / 设备厂家
- [ ] 涉及数据的表述都写了"以本次文件原文为准"

## 下一步交给谁
