# Window Perspective Narrative Technique

A creative framing for timeline/city-evolution narratives: **a single window that changes across eras**.

## Concept

Each image shows the same "seat behind a window" perspective. The **window frame itself evolves** across the sequence, signaling the time period without needing text. The view outside the window shows the changing world.

This was validated with a Jiaozuo railway history project (1902→2026+), where it received positive feedback.

## Window Frame Evolution

| Era | Frame Material | Interior Details |
|-----|----------------|-----------------|
| 1902s steam | Thick dark wood, brass handles | Wooden bench, rough texture |
| 1970s green train | Green painted metal, half-open | Green vinyl seat, white floral curtain |
| 1990s-2000s express | Silver curved metal, fully sealed | White seat cover, clean plastic trim |
| 2020s+ high-speed | Wide panoramic silver frame | White leather seat, fold-down tray |

## Scene Composition (3 layers per image)

Each image must have three depth layers:

1. **近景 Foreground** — the window frame + interior detail (seat corner, curtain, tray table). This is the POV anchor.
2. **中景 Midground** — the main subject: station platform, tracks, city street, factory. Contains human-scale detail.
3. **远景 Background** — sky, mountains, distant city silhouette. Provides atmospheric tone and era-appropriate color palette.

## Color Arc

The color palette should also evolve across the image sequence to reinforce the timeshift:

```
暖黄/棕褐 (蒸汽时代) → 军绿/灰黄 (绿皮时代) → 暖橙/晚霞 (变革时代) → 蓝白/阳光 (现代)
```

## Usage Guidelines

- Best for "city/region + railway" or "then and now" storytelling
- Each image = one time period, one window, one POV
- Between images, use transitional elements (see `transition-page-design.md`)

## Common Mistakes

- ❌ Having the window frame change randomly — it must evolve in a clear chronological sequence
- ❌ Neglecting the interior detail — the seat/curtain/tray is what makes the "same seat" framing convincing
- ❌ Making the foreground too detailed — the window frame should frame the view, not compete with it
