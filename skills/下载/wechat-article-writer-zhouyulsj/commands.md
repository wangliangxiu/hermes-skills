# 微信公众号写作 Skill — 命令速查手册

## 完整命令列表

### `topic` — 选题分析

```
topic [主题描述或关键词]
```

**作用**：分析主题的传播潜力，给出5个选题方向，并推荐优先方向。

**示例**：
```
topic 孩子的专注力发展与大脑发育
topic 气候变化对农业的影响
```

**输出内容**：
- 主题解读（受众痛点、传播价值）
- 5个选题方向（含预估传播量）
- 推荐优先选题及理由

---

### `title` — 爆款标题生成

```
title [主题] [可选：风格偏好]
```

**作用**：生成10个多风格备选标题，含分析说明。

**风格类型**：
| 风格 | 示例 |
|:-----|:-----|
| 数字型 | `这3个关于记忆的真相，99%的人不知道` |
| 反差型 | `你以为你懂量子力学？科学家说你根本没理解` |
| 悬念型 | `一个被刻意隐藏的实验，改变了整个物理学史` |
| 实用型 | `科学验证有效的专注力方法，99%的人都做错了` |
| 情感型 | `我花了10年才明白：学习从来不需要天赋` |
| 权威型 | `MIT研究证明：你的记忆方式可能是错的` |
| 故事型 | `一个睡眠研究的故事，让科学家沉默了20年` |
| 趋势型 | `2026年教育界最值得关注的变化，来了` |

**示例**：
```
title 睡眠与学习效率的关系
title 量子纠缠 偏向悬念和权威风格
```

---

### `outline` — 文章大纲

```
outline [主题] [可选：目标字数] [可选：受众]
```

**作用**：生成完整文章大纲，含各节字数建议和素材分配建议。

**公众号结构规范**：
- 🎣 钩子段（150~200字）：制造好奇心，前3行抓住读者
- 📖 背景铺垫（250~350字）：建立认知冲突
- 🔬 核心内容（2~4小节，每节500~800字）
- 💡 实用总结（150~200字）：给读者带走什么
- 💬 互动结尾（30~50字）

**示例**：
```
outline 大脑的记忆机制 目标字数2000字 面向高中生
outline 为什么孩子越来越难专注 3000字
```

---

### `write` — 撰写正文

```
write [主题/大纲/素材说明]
```

**作用**：根据大纲或素材撰写完整正文，适配公众号阅读风格。

**重要：执行 write 命令前，系统会先询问文案类型！**

**4种文案类型选择**：
| 类型 | 风格参考 | 适用场景 |
|:-----|:---------|:---------|
| 1. 科普类 | "丁香医生" | 健康科普、宠物护理、生活常识 |
| 2. 历史叙事类 | "卢克文工作室" | 技术发展史、产业变迁、国家叙事 |
| 3. 学校宣传类 | 党政办宣传干事 | 学校活动报道、教育成果展示 |
| 4. 论文速递类 | 学术科普大V | 顶级期刊论文解读、科研成果传播 |

**写作时会自动（根据选择的类型应用对应规范）**：
- 每段控制在120字以内（移动端友好）
- 用类比解释专业术语
- 长短句交替，关键短句单独成段
- 在素材图片应插入位置标注 `【配图：XXX】`

**示例**：
```
write 根据上面的大纲撰写正文
→ 系统会先询问：请选择文案类型（1/2/3/4）...
write 主题：量子纠缠如何影响信息传输，面向大学生，约2500字
→ 系统会先询问：请选择文案类型（1/2/3/4）...
```

### `polish` — 润色优化

```
polish [粘贴你的文稿]
```

**作用**：优化已有文稿，改善表达、节奏、情绪调动。

**润色关注点**：
1. 前100字是否足够抓眼球
2. 段落是否有过长需要拆分
3. 节与节之间过渡是否自然
4. 是否有书面用语需要口语化
5. 情绪曲线是否有起伏

**输出格式**：先给修改建议清单，再输出完整润色后文稿。

---

### `format` — 排版格式化

```
format [粘贴你的文稿]
```

**作用**：将文稿转换为公众号标准排版，可直接复制到编辑器。

**排版规范执行项**：
- 统一标题层级（不超过3级）
- 标题前后加空行
- 段落超长自动提示并尝试拆分
- 加粗超过2处自动提示
- 文末添加互动引导语（如无）
- 输出排版报告（字数、图片占位符数量）

---

### `load` — 加载素材目录

```
load [素材目录路径]
```

**作用**：扫描指定目录，识别文字素材、图片素材、模板文件、大纲文件，生成素材摘要报告。

**识别规则**：
| 文件类型 | 识别方式 | 处理方式 |
|:---------|:---------|:---------|
| 模板文件 | 文件名含"template"/"模板" | 写作时严格遵循结构 |
| 大纲文件 | 文件名含"outline"/"大纲"/"提纲" | 作为写作骨架 |
| 文字素材 | .md / .txt / .docx | 提取关键内容要点 |
| 图片素材 | .jpg / .png / .webp 等 | 分析描述，标注配图位置 |
| 参考文献 | 文件名含"ref"/"参考"/"文献" | 支撑数据和结论 |

**示例**：
```
load C:\我的素材\量子纠缠科普
load D:\文章素材\专注力研究
```

---

### `start` — 快速全流程

```
start [主题] [可选：素材路径]
```

**作用**：自动执行 topic → title → outline → write → format 完整流程，输出可直接发布的文章。

**重要：执行 start 命令前，系统会先询问文案类型！**

**示例**：
```
start 为什么现代人越来越难专注？
→ 系统会先询问：请选择文案类型（1/2/3/4）...
start 大脑记忆机制 C:\我的素材\记忆研究
→ 系统会先询问：请选择文案类型（1/2/3/4）...
```

## 工作流组合示例

### 场景一：从零开始

```
1. start 为什么孩子越来越不喜欢阅读
```
（一步完成全流程）

### 场景二：有素材，有想法

```
1. load C:\我的素材\睡眠研究
2. topic 根据素材，探讨青少年睡眠不足的影响
3. title （确认选题后）
4. outline 目标2500字，面向家长群体
5. write
6. format
```

### 场景三：已有草稿，需要优化

```
1. polish [粘贴草稿]
2. format [粘贴润色后的稿件]
```

### 场景四：只需要标题灵感

```
1. title 气候变化与日常生活的关系
```

## 注意事项

1. **素材图片**：在最终文稿中，图片用 `【配图：描述】` 标记位置，发布时替换为实际图片
2. **数据真实性**：Skill 不会捏造数据，如无法确认的数据会标注"（数据来源待核实）"
3. **模板优先**：一旦在素材目录中检测到模板文件，写作结构将严格遵循模板
4. **字数统计**：每次输出后会标注实际字数，帮你控制篇幅
5. **文案类型**：使用 `write` 或 `start` 命令前，系统会先询问选择文案类型（1/2/3/4），请根据需求选择
