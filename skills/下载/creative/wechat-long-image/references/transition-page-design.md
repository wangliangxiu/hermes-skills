# Transition Page Design for Multi-Image Narratives

Multi-image narratives (especially WeChat long-images) need **transition pages** between sections to avoid jarring visual jumps.

## Core Concept

Each section has a dominant **color tone**. Between sections, insert a half-height transition page whose background **gradients** from the previous tone to the next.

## Transition Element Catalog

| From → To | Element | Works for |
|-----------|---------|-----------|
| Cover → 1902s | Steam locomotive wheel turning | Railway history, industrial |
| 1902s → 1970s | Railroad ties / sleepers flashing past | Railway/transit evolution |
| 1970s → 2000s | Curtain blowing in wind | Modernization, generational |
| 2000s → Present | Outside scenery blurring into speed lines | Acceleration, high-speed |
| Ending → CTA | A ticket/floating paper drifting down | Reflection, interactive |

## Design Rules

1. **Half height** — transition pages are 50% the height of main content images
2. **Gradient background** — background color transitions from the previous section's dominant tone to the next section's
3. **Single directional element** — one simple illustration that suggests movement through time
4. **No text** — text lives only on the main content images
5. **Consistent framing** — if the main images use a "window" framing, transition pages should use a different perspective (e.g. looking down at tracks, or an abstract close-up)

## Example: Railway History Long-Image

```
封面 (暖黄) → 车轮 → 1902 (棕褐) → 枕木 → 1970 (军绿) → 窗帘 → 2000 (暖橙) → 速度线 → 高铁 (蓝白) → 车票 → 互动 (暖黄)
```

This creates a cohesive story spine — the color arc itself tells the story of change over time.

## Why This Works

- **Visual breathing room** — prevents "slideshow" feeling where one image abruptly ends and another begins
- **Color signaling** — the gradient subconsciously primes the reader for the next section's emotional tone
- **Rhythm** — alternating full-image + half-transition creates a natural reading cadence
