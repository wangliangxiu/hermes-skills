# 水印坐标定位指南

图片与视频的 `x,y,宽,高` 使用普通像素坐标，**左上角为原点 (0,0)**。视频以单帧画面为基准，与截图坐标一致。

## 一、坐标获取方式（按易用度排序）

### 方式 1 · 用户直接给出
用户能报出准确坐标（例如「x=820, y=40, 宽180, 高60」）时直接使用。

### 方式 2 · 角标预设（图片）
不知道精确坐标时，可用 `--corner` 预设 + `--size` 猜测宽高：

| 参数值 | 位置 |
|--------|------|
| `tl` | 左上角 |
| `tr` | 右上角 |
| `bl` | 左下角 |
| `br` | 右下角 |

```bash
python3 scripts/remove_image_watermark.py photo.jpg --corner tr --size 260,80
```
跑完让用户确认效果，一次不准再调 `--size` 或改用精确 `--box`。

### 方式 3 · 截图量取（推荐，最准）
1. 图片：直接用系统看图工具打开放大，记下水印覆盖的像素范围。
2. 视频：先截取一帧画面（`ffmpeg -i video.mp4 -ss 00:00:10 -frames:v 1 frame.png`），再按图片方式量取。
3. 量取时框住水印**外边缘**，可略大 2~5 像素，防止边缘残留。

### 方式 4 · 全自动盲猜（慎用）
无任何坐标信息时，用 `--corner` 逐角尝试。**必须告知用户这是猜测结果**，让用户确认后再做正式处理。

## 二、常见水印形态与建议参数

| 水印形态 | 推荐模式 | 说明 |
|----------|----------|------|
| 角落台标（半透明 Logo） | delogo 插值 | 框稍大一圈，插值效果最自然 |
| 顶部/底部滚动字幕条 | 视频 crop 裁剪 | 水印占画面边缘一条，直接裁掉 |
| 画面中部文字水印 | 视频 blur 模糊 | delogo 在中部大区域可能留下纹理痕迹 |
| 半透明全屏水印 | 告知效果有限 | 与背景融合，插值后仍可能有残影 |

## 三、常见视频分辨率参考坐标

以下为常见水印位置粗略值，**仅供参考**，正式处理前建议截图确认：

| 分辨率 | 右下角台标（建议框） |
|--------|----------------------|
| 1080x1920（竖屏） | x=1560, y=1760, w=260, h=100 |
| 1920x1080（横屏） | x=1680, y=920, w=220, h=100 |
| 1280x720 | x=1080, y=600, w=180, h=80 |
| 720x1280（竖屏） | x=1040, y=1180, w=160, h=70 |

> 这些值基于「台标距右/下边缘约 40~60px」的常见排版习惯，**不同视频差别很大，必须截图验证**。

## 四、delogo 坐标调试技巧

- delogo 对坐标敏感：框小了留残边，框大了会吃掉部分画面内容。
- **宁可框大 5~10 像素**，delogo 的插值会平滑过渡，多框一点通常比漏框效果好。
- 先用 `--show` 跑一帧确认遮罩位置：
  ```bash
  python3 scripts/remove_video_watermark.py video.mp4 --box x,y,w,h --show -o debug.mp4
  ```
  输出的视频中水印区域会用色块高亮，确认位置后再去掉 `--show` 正式处理。

## 五、常见错误坐标特征

| 现象 | 原因 |
|------|------|
| 水印没被处理，画面其他区域被破坏 | 坐标与实际水印位置偏离 |
| 只处理了半个水印 | 宽/高数值不够，多框一点 |
| 报错「区域超出画面」 | x+w 或 y+h 超过画面尺寸，脚本已自动截断 |
