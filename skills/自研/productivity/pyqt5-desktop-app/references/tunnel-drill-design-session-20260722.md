# 2026-07-22 隧道智能炮孔设计系统 开发日志

## 背景
使用者（AI数据处理）和小伙伴（BIM建模）要开发一套全电脑凿岩台车的配套软件，参赛+落地。
小伙伴在国企机械设备厂（生产凿岩台车），两人均全职。

## 项目方向
智能炮孔设计系统 — 参数化布孔 + AI分析反馈优化
- 导入CAD炮孔图 → 自动识别炮孔参数
- 可视化布孔设计（根据围岩等级自动调整）
- 导出炮孔数据给台车控制系统
- 打完出3D竣工图 → AI分析偏差 → 优化下一轮参数

## 框架结构（v0.6最终版）

```
drill_design_v06.py
├── EXCAVATION_MODES        # 开挖方式常量
├── HOLE_COLORS / LABELS    # 炮孔颜色与标签
├── Sim3DView(QWidget)      # 3D模拟视图（俯视图+侧视图）
│   ├── _draw_top()         # 隧道左壁/右壁/掌子面/台车/钻臂/炮孔投影
│   └── _draw_side()        # 隧道拱形/台车高度/基座/钻臂
├── RigPanel(QWidget)       # 台车参数面板（尺寸+定位）
└── DrillPanel(QWidget)     # 炮孔设计面板（围岩/跨度/开挖方式/布孔参数）
```
