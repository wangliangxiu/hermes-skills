# 竞品格局与项目定位

什么时候看这份：写 BP/路演/答辩材料、被问"你们跟市面方案有什么不同"、使用者质疑项目
"落后了"要查证、或考虑下一阶段技术方向时。

## 两轮查证的事实底稿

### 一轮：整机厂侧（国外）
- **Sandvik AutoMine Concept Underground Drill**：无驾驶室、电池驱动、全自主双臂掘进
  台车，可完成从行走到就位、按炮孔图钻完、自行返回充电的**全流程无人作业**。
- **Epiroc Deep Automation**：已将自动化组合扩展到井下钻孔与锚杆作业。
结论：**整机层面的全自动化在国外已产品化**，不是概念。

### 一轮：整机厂侧（国内头部）
- **铁建重工 ZYS113/G 产品页原话**："通过采用定位与扫描一体化装置，实现凿岩台车在
  隧道内的精确定位"；"爆破设计图导入电脑，**无需掌子面描点即可实现自动钻孔**"。
- **五新隧装**（北交所 920174，专精特新小巨人）凿岩台车宣传词：集成"自动钻孔、
  防卡钎、**掌子面围岩判别、炮孔图生成**、数据自动采集与追溯"。
- 行业对"全电脑凿岩台车"的通行定义已包含：三维扫描、自动布孔、一键钻孔、数据记录
  与远程传输。

**关键读法**：厂家写的是"爆破设计图**导入**电脑"——**图是人先设计好再导入的**，
布孔设计仍是设计院/技术员手工完成。"导入"vs"生成"的差别就是这个项目的立足点。

### 二轮：通用 3D 能力侧（GPT-6 Astra 之后）
- GPT-6 Astra（2026-09-03）原生支持 3D 建模：Codex 接 Blender MCP，一条照片/参考图
  即可生成照片级、分部件、可编辑模型（有案例输出数千个独立可编辑物体）。
- 开源侧已有可本地跑的 3DGS 方案（高德 ABot-World 系列开源，原生输出 3DGS）。
- 行业判断：**通用 Agent 把"单点 3D 生成"从独立产品入口压成了可随时调用的一层能力**。

**这就是"画面不能当卖点"的根据**：通用模型会持续把单点生成能力变成免费基础能力。

### 二轮：掌子面三维重建（与本项目直接相关）
- 2026-05 MDPI 闭环框架：多视角三维重建 → 提取岩体结构面（ISODATA 聚类）、迹线
  （最小代价路径）、掌子面平整度（曲率分析）→ **反算优化爆破参数**（增加掏槽孔、
  调整辅助孔间距）。处于学术前沿向产品化过渡的窗口期。
- 传统 SfM 掌子面重建的痛点：**慢**。实测 169 张照片重建 22 小时、206 张 25 小时，
  仅 13 张也需约 14 分钟——匹配不上隧道循环节奏。这个"慢"就是产品化入口。
- 3DGS 在岩体表征上精度优于传统网格摄影测量（Postshot 实测，与人工测量相关性更高、
  RMSE 更低）。
- 采集环境硬约束：粉尘、光照不均 → 需图像增强（直方图均衡+双边滤波）；岩面纹理
  重复导致特征匹配失败 → 需增强匹配策略（BBF 优化 KD 树 + RANSAC），或双目/深度
  相机（两张图即可重建、快，但精度鲁棒性有限）。

### 侵权/合规侧（谈"能不能搬别人内容"时用）
- 未经许可搬运 = 侵犯信息网络传播权，按条数判赔；有判例为搬运 107 条短视频判赔
  8 万元 + 律师费 1 万 + 公证费 5190 元。
- 平台自身也可能因算法推荐侵权内容承担帮助侵权责任。
- 免责空间只有"合理使用"那一小块：引用极小部分、目的在阐述自身观点与评论。

## 定位结论

1. **不在自动化上正面比**。厂家做"执行"，本项目做"设计"。
2. **不换设备的软件层是空白**：厂家智能功能绑自家整机销售，存量在用台车不获升级。
3. **能力分两层**：工程语义层（护城河，写进材料）／通用视觉层（会贬值，不写）。
4. **"没实测"的口径**："算法已实现并通过仿真验证，待现场数据标定。"

## 待办（按性价比）

1. 做通"掌子面照片 → 真实感三维 → 结构面识别 → 自动布孔"链路（**不需真机**，
   一部手机 + 一台笔记本即可；这是"没测试"这个软肋的解药，也是最大的差异化演示）。
2. 向设备所索取**爆破后断面扫描点云 + 往期钻孔日志**——对接时已确认对方有，
   但一直没落地取用，这是数据闭环的燃料。
3. 重写对外卖点与定位口径（旧口径按上文第 3 条处理）。
4. 把点云分析 Tab 的"模拟点云"换成真实掌子面重建模型做一次演示（观感立刻从
   示意级跳到照片级，且证明它是工程数据驱动的）。

## 技术路线的现实约束（写方案时必须带上）

- 隧道现场**无网** → 重建只能在设计端/驻地做，现场只负责按规范采集照片。
- 照片重建得到的是**相对尺度**，工程使用必须标定绝对尺度：拍时在掌子面放已知长度
  的标尺，或用已知断面设计尺寸/台车已知外形尺寸做锚点。
- 重建模型要与隧道全局坐标系对齐，才能与设计轮廓比较——可复用系统已有的掌子面系/
  台车系坐标变换骨架，但需补"模型系→掌子面系"的配准步骤。
- 本机显卡（集显/低端独显）跑不动大场景 3DGS，需要时租云显卡或走云端服务。
