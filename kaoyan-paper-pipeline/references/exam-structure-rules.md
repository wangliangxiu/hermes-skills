# 考试结构推导规则（跨科目，任何人、任何年份都适用）

## 一句话
考什么，由 **学位类型 × 学科门类/专业代码 × 当年该校招生专业目录** 决定；
不由科目名决定，**也不由“全日制/非全日制”决定**。

---

## 一、单元数（几门课）——教育部《全国硕士研究生招生工作管理规定》
（每年 9 月发新版，条款号可能微调，内容稳定）
- **第三十二条（四单元，默认）**：初试一般设置四个单元——思想政治理论、外国语、业务课（一）、业务课（二），
  满分分别为 100、100、150、150，**总分 500**。
- **第三十三条（三单元）**：以下专业初试设三个单元——政治 100 ＋ 外语 100 ＋ **专业基础综合 300**（总分 500）：
  - 学硕：教育学、历史学、医学 3 个门类；
  - 专硕：体育、应用心理、博物馆、临床医学、口腔医学、公共卫生、护理、药学、中药、中医、医学技术、针灸。
- **管理类专硕（两单元，总分 300）**：199 管理类综合能力（200）＋ 外国语（100）；
  思想政治理论在**复试**中考核。适用：工商管理（MBA）、公共管理（MPA）、会计（MPAcc）、审计（MAud）、
  图书情报（MLIS）、旅游管理（MTA）、工程管理（MEM）等。
- **单独考试**：初试科目设置与同专业全国统考**相同**（科目名多带“单独考试”，如 111 单独考试思想政治理论）。

## 二、非全日制（最常见的误解）
- 教育部原文：**“全日制和非全日制研究生考试招生依据国家统一要求，执行相同的政策和标准。”**
- 所以非全 **不改变考试科目、不改变试卷、不改变大纲**；改变的是：招生计划与名额、修业年限、学费、
  上课方式（非脱产）、复试线（部分专业分开划线）、就业方式（多为定向就业）。
- 结论：**“换非全”不用重做命题地图；“换专业类别”才要重做。**

## 三、要不要考数学、考哪一档
| 代码 | 科目 | 适用范围（经验规则，最终以目录为准） |
|---|---|---|
| 301 | 数学一 | 工学中对数学要求较高的学科：机械、电子、计算机、土木、水利、化工、地质、矿业、航空、兵器、核、测绘等 |
| 302 | 数学二 | 工学中对数学要求较低的学科：纺织、轻工、农业工程、林业工程、食品等；部分院校个别专业 |
| 303 | 数学三 | 经济学、管理学门类（含管理类中对数学要求较高的学科，如农林经济管理） |
| 314 | 数学（农） | 农学门类（有些专业考 315 化学（农）） |
| 601—609 | 自命题理学数学 | 招生单位自命题，用于部分数学/统计类 |
| —— | 不考数学 | 哲学、法学、教育学、文学、历史、医学、艺术等门类；第三单元改为自命题专业基础综合 |
⚠ 同一专业**不同学校可能挂不同数学**（例：建筑学有的考数一、有的不考；管理类有的考数三、有的改 396），必须看目录。

## 四、外语
- 201 英语（一）：学硕为主；部分专硕也要求英语一。
- 204 英语（二）：多数专硕。
- 202 俄语 / 203 日语 / 其他语种；240—289 为招生单位自命题外语（小语种方向）。

## 五、业务课（专业课）——永远是自命题
- 代码与名称由**招生单位自定并在当年《招生专业目录》里公布**；常见第四单元用 8××/9××（如 849 材料力学、801 经济学），
  第三单元自命题常用 6××/7××（601—609 留给自命题理学数学）。
- 命题依据：该校公开的**《自命题考试大纲》**（有的还公布参考书目）＋指定教材。
- **目录与大纲在每年 9—10 月更新**，所以：换年份 = 重核考纲 = 重做命题地图（真题地图不动，考纲地图要动）。
- 专业课真题多数**不公开**；市售“回忆版”来源不可核验 → 不成篇引用，改用考纲＋教材典型题型命题。

## 六、输出物：一页《考试结构卡》（后面所有步骤的输入）
```
报考：<学校> <专业代码> <专业名>（学硕/专硕，全日制/非全）
年份：<20XX>（依据：<20XX>年招生专业目录）
单元数：<四/三/两>，总分 <500/300>
①  <代码> <科目名>  <满分>分/<时长>
②  <代码> <科目名>  <满分>分/<时长>
③  <代码> <科目名>  <满分>分/<时长>
④  <代码> <科目名>  <满分>分/<时长>   ← 自命题：命题方=该校
考纲来源：公共课=<教育部大纲>；自命题=<学院网站自命题考试大纲 + 参考书>
真题可得性：公共课=可得；自命题=<公开/不公开>
备注：<题型结构是否公布；学硕/专硕差异；同一专业不同方向的科目差异>
```
**这张卡必须先给使用者过一眼**，卡错了后面六步全白做。

## 七、查证顺序（防错）
1. 教育部当年《招生工作管理规定》→ 定单元数与各单元满分。
2. 研招网专业库 / 招生单位研究生院官网 → 拿当年《招生专业目录》PDF。
3. 招生学院官网 → 拿《自命题考试大纲》与参考书。
4. 三样都存档（目录 PDF ＋ 大纲原文 ＋ 结构卡），写明年份与链接，下次复用可直接比对差异。
