# 老年人操作指南编写 Skill

## Overview

当用户要求你为长辈（爸妈/叔叔阿姨/老人家）写一份操作指南时使用。
核心原则：**把读者当成完全没接触过这个软件的人，从打开手机/电脑开始讲。**

## When to Use

- 用户说"给我爸写个教程"、"给叔叔写个说明书"、"老人家看不懂"
- 用户说"写得详细一些，什么按钮在哪里按"
- 用户说"跟说明书似的，一步一步"
- 用户说"每一步写清楚按哪个按钮"
- 涉及长辈/老年人自己动手操作的任务

## 编写规范

### 1. 结构模板

```
给XX的[任务名称]操作指南

================================================================================
第X步：XXX（一句话概括）
================================================================================

操作：
1. 打开手机/电脑 → 找到XXApp
2. 点哪个按钮（说清楚位置：顶部/底部/左边/右边）
3. 输入什么内容（如果是复制粘贴的，直接给文字让长辈复制）
4. 点哪个按钮确认
5. 等多久能看到结果

[小窍门]
- 如果做错了怎么办
- 常用的提示词直接写好，让长辈复制

如果遇到问题：
问题1：... → 解决办法
问题2：... → 解决办法
```

### 2. 语言风格

- 用"您"称呼，语气尊重亲切
- 每个步骤只做一件事
- 按钮位置说清楚：**"页面顶部右边的'导出'按钮"** 而不是 **"点导出"**
- 如果涉及输入文字，把文字写出来让长辈直接复制，不要让他们自己打字
  - ✅ "在输入框粘贴这段文字：帮我润色这段文字..."
  - ❌ "输入提示词"

### 3. 必须包含的内容

- **软件从哪里下载/打开**（应用名称+图标特征）
- **每一步的按钮位置**（左上角/右上角/底部中间）
- **需要输入的文案**（直接写好让复制）
- **可能遇到的问题及解决方法**（常见错误+怎么处理）
- **最后的检查方法**（怎么知道做对了）
- **总结流程图** — 在文末用箭头简图总结整个流程，方便长辈回顾

### 4. 文件格式

- 优先输出 `.txt` 文件（最大兼容，任何电脑都能打开）
- 放在桌面方便长辈查看
- 文件名用中文，清楚标明用途：`给叔叔的自传转视频操作指南.txt`
- 如果用户要 Word 文档则用 python-docx 生成

### 5. 更新原则

- **每次更新就替换旧文件，不留多个版本**
- 更新前先删除旧文件（`rm -f 旧文件路径`）
- 桌面上始终保持最新版，不要出现"方案""方案2""最终版""最终版2"这种多个版本

## 典型场景

### 场景一：AI工具使用指南
用户给长辈写豆包/剪映等工具的使用说明。
- 从"打开应用商店下载"开始写
- 每步说明按钮位置
- 提示词直接写好让复制

### 场景二：自传/回忆录转视频指南
用户想帮长辈把自传文字做成视频。
典型工作流：
1. 语音转文字（微信语音→转文字）
2. AI润色（豆包App，提示词直接写好）
3. 分段整理（童年/求学/工作/成家/退休等）
4. 导入剪映"图文成片"功能
5. 调整画面/配音/背景音乐
6. 导出视频
7. 多段拼接成完整视频

每一步都要拆解到"按哪个按钮"。详见 `references/self-to-video-guide-example.txt`

### 场景三：微信/手机基础操作
- 语音转文字、复制粘贴、发送文件等

## Common Pitfalls

1. **假设读者有基础** — 不要以为"打开App"这种话谁都懂，要说"在手机桌面上找到红色的'剪映'图标，点一下打开"
2. **用专业术语** — 不要说"input函数"，要说"输入框"
3. **让读者自己打字** — 提示词和关键词直接写好让复制
4. **不写错误处理** — 老年人遇到报错会慌，一定要写"如果出现XX问题，就XX做"
5. **保留旧版本** — 每次更新必须删旧版文件，桌面上只留最新版
