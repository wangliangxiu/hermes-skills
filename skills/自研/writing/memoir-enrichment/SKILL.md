# 自传/回忆录整理扩写（出书感）

## 适用
用户提供长辈/本人的自传或回忆录文字，要求"更充实 / 出书的感觉 / 整篇均匀加厚 / 某部分重点加厚"。这是散文整理扩写，**不是**剧本也不是视频提示词（那是 prose-to-video-prompts 的活）。

## 工作流
1. read_file 读原文（支持 docx），先在心里列事实点清单
2. 问清方向：整篇均匀加厚？哪几章重点加厚？（例：军旅重点加厚 = 军旅各章拆小节按时间线展开）
3. 按作者语气扩写：平实真诚老派文气，不改成花哨抒情腔——"他一看就说这不是我写的"是失败标准
4. 生成 docx 出书版：封面(书名/作者/整理充实版) → 整理说明 → 目录 → 正文(首行缩进24pt/1.5倍行距/两端对齐) → 结语 → 后记(可用原文落款)
5. 原稿另存不动；新文件命名"XX_出书版.docx"；交付时报告：改了什么笔误、加厚分布，请用户确认

## 铁律（用户强约束）
- 人名/地名/时间/数字/番号/职务照原文，一个不编
- 不虚构对话；扩写只加：环境铺垫/画面细节/心理感受/段落过渡/时代氛围
- 保持第一人称与作者口吻
- 修正明显笔误必须写进"整理说明"逐条列出，读者能看见改了什么；意思不确定的问用户，别自作主张

## 笔误修正实例（2026-08，均写入整理说明后交付）
- "南方长大的少年" → "中原长大的少年"（作者家乡在黄河以北，事实矛盾）
- "终身记不了" → "终身忘不了"（河南话/笔误，语境是怀念）
- "下雨天无法向想" → "无法想象"
原则：改前先判断是否明显笔误；拿不准就问，绝不静默改。

## 加厚技巧
- 均匀加厚：每章补开篇环境铺垫 + 过渡段 + 收尾句
- 重点加厚：按时间线拆小节（例：离家→列车→到站→营房→训练→授奖），每节补画面，仍不加新事实
- 时代细节只用原文有据物（搪瓷盆/绿皮火车/驴吉普/全武装部一台电脑/单指敲键盘）
- 出书框架：章回标题统一、结语收拢人生心得、后记放作者自述与落款

## 交付
- docx；与原稿并排，不覆盖
- 交付时明确列出修正的笔误（用户需转告原作者确认）
