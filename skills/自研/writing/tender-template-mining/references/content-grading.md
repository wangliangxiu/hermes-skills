# 技术标内容分级（必须有 / 做得出彩 / 可有可无 / 绝不能做）

用途：给投标技术标做内容取舍。每条都挂在条件上——招标文件给定章节、评标办法与得分项、
项目类型、明标还是暗标、给的时间余量；没有一条是死的。这就是"要有选择性，不能一条直线流程"。

本分级是用户提出并要求整理的骨架，仍是草稿；落进社区技能（bid-technical-proposal）前等用户定稿。

## 一、必须有的（缺了不完整，或被评分标准点名）

工程概况（必配工程位置图）、主要施工方案与各分项工法、进度计划及措施（横道图 + 网络图）、
质量保证体系及措施、安全保证体系及措施、文明施工与环境保护（消防、保卫、健康通常并成一章）、
劳动力/材料/机械设备配置计划、附表附图（招标文件给的格式表一套齐全）。

待用户拍板：风险管理体系算不算必须有——样本把它单列成章，但若评标办法没点名、图纸又直接给了风险源，能否简化。
口径：评分表列了什么只说明"它是评分项"，不等于用户认定的"必须有"；什么样的内容一定要有，由他明确给出。

## 二、做得出彩的（不必须有，做好了明显拉开差距）

工程位置图 + 按施工阶段分多张的现场平面布置图、工期与进度计划（倒排、关键线路说明、里程碑、
工期计算过程）、重难点分析及对策（必须贴本标段具体结构写）、合理化建议（逐条针对本标段具体结构，
最容易显专业）、智慧工地与标准化工地、协调配合与接口管理、前期专项方案
（交通疏解、管线迁改、桥梁拆复建、道路改移、建构筑物保护）。

## 三、可有可无的（看招标文件、看时间余量）

用款计划、合同管理与分包措施、质量通病治理 / 成品保护 / 保修管理这类通用小节、
防疫等时点性内容、组织架构章里的专家顾问组 / 指挥部设置。

待用户拍板：这几项里哪些在实际做标时从来不写。

## 四、绝不能做的

- 触犯招标文件里的否决投标（废标）条款——**这类条款有才成立，不是每份招标文件都有**；有的话它比"拿分"更硬
- 暗标里出现公司名、人名、非本投标标段的项目名称（前提：本次采用暗标）
- 措施套错工程类型（这次是盾构，质量/安全措施还留着地上或桥梁那一套）——答非所问
- 超过招标文件给定的施工期限（工期是硬上限，宁可压缩）
- 招标文件"其他要求"里点名的内容没写（文物保护措施、明标暗标要求、Word 格式细则）
- 违反强制格式（标题层级数、字体字号、样式、页边距、页数限制、装订方式）
- 把商务内容写进技术标（报价、资质、业绩承诺）

待用户拍板：还有哪些"写了就出事"的，要带场面（哪个项目、因为什么、结果怎样）；用户不讲的不要编。

---

## 五、这套分级怎么用（工作口径）

出现的位置是"圈必须重写清单"那一步：先按招标文件的条目与评分表定"必须有的"，再把力气按分值排到"做得出彩"的章上，
"可有可无"的按时间余量决定写多细，"绝不能做"的当成出标前逐条自查的红线。
用户强调过：这套分级不是死的，每条都挂在条件上（招标文件给定章节、评标办法与得分项、项目类型、暗标与否、时间余量）。
