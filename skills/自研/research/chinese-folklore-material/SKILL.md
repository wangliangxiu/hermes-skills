# 中国民俗/神话素材：考证 → 映射 → 红线

给产品、文案、玩法找中国民俗素材（财神、节气、年俗、神兽、吉祥物）时按这个顺序走。核心是使用者那条铁律：**不许瞎编，查不到就说查不到**；民俗题材最容易“听起来像真的”，所以出处要分层写清。

## 一、出处分等级（每条素材都必须标）

写下来的每条都要标清是**典籍有载**还是**民间说法/后世演绎**，两者绝不能混着当同一档写。

可信度排序，只能从前往后引用：

1. 古籍原文（wikisource）
2. 博物馆／非遗／官媒（故宫博物院词条、中国非物质文化遗产网、新华社、人民网科普、中国天气网）
3. 学术文章／正规报刊
4. 维基词条
5. 商业站、算命命理号、自媒体——**只能当线索**，必须回溯到 1~4 档才准写进材料

典型陷阱——后世伪典：貔貅“是龙第九子、没肛门只进不出”典籍里没有（《尚书·牧誓》《史记·五帝本纪》《礼记·曲礼》里貔貅只是猛兽名），只进不出是民间说法。这种必须标成民间说法，不能当典故引。

## 二、怎么查（可复制的命令）

维基系 API 比 web_search 稳，且能直接拿原文。境内直连不通，走本地代理 `-x http://127.0.0.1:17890`。

古籍原文（wikisource）：

```
curl -s -x http://127.0.0.1:17890 -G "https://zh.wikisource.org/w/api.php" \
  --data-urlencode action=query --data-urlencode prop=extracts \
  --data-urlencode explaintext=1 --data-urlencode format=json \
  --data-urlencode redirects=1 --data-urlencode "titles=送窮文 (韓愈)"
```

词条释义（wikipedia）：把域名换成 `https://zh.wikipedia.org/w/api.php`，参数同上一模一样。

要点：

- **标题要用繁体**才容易命中；不确定就先 `list=search` 搜一遍拿到准确标题，再取 extract。
- 一篇长文只需要其中一段时：先取全文，再用 python 找关键词（`青蚨`、`智窮`）切片打印，别整篇读进上下文。
- `web_extract` 对维基词条时好时坏（CRAWL_NOT_FOUND、空返回、Unrecognized response shape）——**别据此判断页面不存在**，换上面的 API 再来。
- 搜不到的词条名先别写“查不到”，换繁体/别名再搜一轮。

## 三、数字名单类问题：先问有没有“公认版本”

“五路财神”“九路财神”“四大XX”这类，先确认有没有公认版本：

- 有公认版本就写公认的，并补一句“民间另有说法”。例：五路财神＝中路赵公明＋东路招宝天尊萧升、西路纳珍天尊曹宝、南路招财使者陈九公、北路利市仙官姚少司（《封神演义》体系），另有“东比干、西关羽、南柴荣、北赵公明”一说。
- 没有公认版本的（如“九路财神”，只有民间拼法：东比干、西关公、南柴荣、北赵公明、西南端木赐、东北李诡祖、东南范蠡、西北刘海蟾、中王亥）——**直说没有统一说法、这是某一版的拼法**，把选择权交回使用者，不要自己拼一个当标准答案。

## 四、使用者会追问“这是啥、我怎么没听过”

不要只证明“有出处”，要正面回答**他为什么没听过**：多是地域或叫法差异。例：“赶五穷”（正月初五破五赶穷气，五穷＝智穷、学穷、文穷、命穷、交穷，出自韩愈《送穷文》“凡此五鬼，为吾五患”）是年俗正式表述和部分北方地区在用，很多地方那天只叫“破五”。

接着给用法建议：外面写大众熟悉的叫法，生僻名当细节彩蛋。他家乡（本地）具体怎么叫**不要替他定**——直说“我不敢替你定，你比我清楚”，他是本地人，地域细节他会纠正。

## 五、素材 → 机制（素材库的写法）

每个元素三行：讲的是什么／有据的出处／能变成什么玩法。做完再给两份清单：按性价比排序的“建议做”和“不要碰”，让他挑，别替他定。

可用的映射套路：

- 神话里的**分工**→ 功能模块（四个部将＝四个入口/四种获取方式）
- 神话里的**动作**→ 交互（推车进宝＝入账动画；摇树落钱＝定时产出；锁财＝锁定仓位）
- 神话里的**性质**→ 规则口径（“无心则公”对应可复算的公平；“忠义守信”对应信用机制）
- 神话里的**时间**→ 定时任务（迎财神/接路头对应开坛、长明灯对应连续签到）

## 六、不要碰的（写进产出文件）

- 涉宗教本尊修法的（藏传五姓财神/黄财神赞巴拉）：最多在材料里提一句源流，**不做成玩法**。
- 历史上被写成邪神的（江南五通神，南宋《夷坚志》里半是邪神，后来才改称五路神）：别用。
- 带墓葬/陪葬意涵的（摇钱树本义是东汉六朝明器、含升仙意涵）：只取民间“摇落金钱”的意象，别往陪葬方向渲染。
- 赌性玩法（押注、下注、翻倍）：红线；顺势用“偏财不取、只认正财”做正面口径。
- 文案口径：**可以说吉，不能说凶**（使用者明确要求）。不顺的那面一律翻成“宜怎么做、避开什么”，不落吉凶判词。

## 七、交付习惯

- 素材落 **txt** 放项目文件夹（使用者要 txt，不要 md），聊天里只回要点和最值得做的几条，别把整份文件念一遍。
- 文件末尾加“出处”节，逐条对应到具体书/站点。
- 条目里区分“典籍有载/民间说法”，别让下游写材料的人自己猜。
