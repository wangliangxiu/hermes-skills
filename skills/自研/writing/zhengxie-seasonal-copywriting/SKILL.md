# 政协节气公众号文案创作

## 触发条件
当用户说"政协节气XX"、"写一个节气文案"、"节气宣传"且提到政协时加载此skill。

## 模板结构

每篇节气文案按以下**9段结构**顺序展开，段落之间用空行分隔。

### 1. 标题
`YYYYMMDD 政协节气[节气名]`

### 2. 在本地
```
在本地
[节气名]
是[本地景点A]的[特色描述]
是[本地景点B]的[特色描述]
是[本地景点C]的[特色描述]
```

### 3. 一如政协工作
```
一如政协工作
[四字短句]，[四字短句]
[结合节气特点的哲理句]
[政协相关比喻句]，[四字短句]
```
每段独立一行，连续排列。

### 4. [节气名]有三候
```
[节气名]有三候
一候[候名]
[候的描述]
在[本地地点]
[具体场景描写]

二候[候名]
...
三候[候名]
...
```
每个候写4行：候名、特性描述、本地地点、场景细节。

### 5. 本地[节气名]习俗
```
本地[节气名]习俗
[习俗1]
[习俗2]
[习俗3]
[习俗4]
```
4行连续排列，每行一个习俗。

### 6. 本地人的[节气名]
```
本地人的[节气名]
是[具体生活场景]
[细节描述]
[升华句1]
[升华句2]
```

### 7. [节气名]政协事
```
[节气名]政协事
[节气前后/时间]
[政协调研工作1]
[政协调研工作2]

[哲理句]
[哲理句]
政协人的[节气名]
[四字短句]，[四字短句]
在[地点]
[行动句]
```

### 8. 在本地遇见醉美节气[节气名]
```
在本地遇见醉美节气[节气名]
政协人对这片土地的热爱
如[节气特色比喻]
[形容词]
爱[本地地点A]的[特色]
爱[本地地点B]的[特色]
爱[本地地点C]的[特色]
这份热爱
[节气]为证，历久弥新
```
结尾三句"爱……"必须用本地市区真实地点。

### 9. 结尾
```
[节气名]已至
愿[结合节气特色]
[呼应句]

愿政协的[节气名]之约
[升华句]

愿你我在这[节气特色]里
在怀川大地上
[四字短句]
[四字短句]
```

## ⚠️ 核心红线

### 地点真实性（绝对红线）
- **不确定的地名绝对不能写。** 宁可少写、换已知地点，绝不编造。
- 所有本地地点必须100%真实存在。
- 已踩过的坑：
  - ❌ "龙佰山" — 不存在，编的
  - ❌ "缝山针夜市" — 缝山针是公园，夜市不确定存在
- 如果对某个地点存疑，必须问用户确认。

### 市区优先原则
- 优先使用本地市区地点
- 减少使用县里地点（修武、博爱、沁阳、孟州、温县等）
- 只有用户明确允许时才使用县里地点

### 已确认可用的本地市区地点（按水域/荷花主题）
- **龙源湖** ✅ 经典，有荷花，常用来做排比开头
- **天河公园** ✅ 南水北调沿线，有绿荫步道
- **大沙河** ✅ 湿地公园，水景丰富
- **人民公园** ✅ 老公园，有荷花池（2026年大暑确认）
- **月季公园** ✅ 有湖面水域（2026年大暑确认）
- **雕塑公园** ✅ 有水景（2026年大暑确认）

⚠️ **关键教训：地点替换的尺度把握**
使用者说"把地点换掉"时，不等同于"把所有出现的地点全部替换"。
- 如果使用者说"把XX换掉/替换一下"，先问清楚：是全部替换还是部分替换？还是保留一部分、新增一部分？
- 推荐做法：**保留开头排比句中的主要地点（龙源湖/天河公园/大沙河），把三候和结尾处的部分地点换成新地点**，这样六个地点都能出现，丰富不单调。
- 大暑文案最终版示例：开头排比保留龙源湖/天河公园/大沙河；一候→人民公园；二候→月季公园；结尾第三个爱→雕塑公园。
- **始终用 `in` 检查段落文本**（而非 `==`），python-docx 可能有不可见字符导致精确匹配失败。
- 不要对 docx 文件分两次修改（先还原再改），**一次性确定目标分布，一把改完**。

### 地点替换的灵活性
使用者可能会要求替换地点。此时**不要全量替换**，而是：

**正确做法（已验证通过）：**
1. 先问清楚：是全部替换还是部分替换？还是保留一部分、新增一部分？
2. 如果使用者说"换掉一些，别全换，留一些再加一些"：
   - 推荐分布：**开头排比（3个地点）保留主要地点不变**
   - 三候部分：选1-2个候换成新地点
   - 结尾"爱……"排比：选1个换成新地点
   - 这样6个地点都能出现，丰富不单调
3. 大暑文案最终定稿版分布参考：
   - 开头排比：龙源湖 / 天河公园 / 大沙河（保留）
   - 一候腐草为萤 → 人民公园
   - 二候土润溽暑 → 月季公园
   - 结尾爱……的第三个 → 雕塑公园
   - 政协事部分 → 防汛相关，与地点无关
4. **一次性写完替换脚本**，不要先还原再修改——直接在所有段落上做关键词匹配替换
5. **务必用 `in` 而非 `==`** 检查段落文本：`if '龙源湖' in p.text` 而不是 `if p.text.strip() == '是龙源湖荷塘的映日荷花'`
6. 替换后**逐个验证**每个出现过的旧地名是否都已替换干净

**python-docx 操作注意事项：**
- 修改段落文本后，需要**删除原文件再 save**（PermissionError: `os.remove()` then `doc.save()`）
- `doc.save()` 在同一文件上会报 `PermissionError`，因为原文件被已加载的 doc 对象锁住
- 循环中 `p.text = new_text` 后不能立即验证，需要 save 后重新 `Document()` 加载

## 写作风格
- 亲民、有温度，不堆砌排比句
- 每个节气结合本地本地特色
- 用修辞手法（比喻、排比）但细节要真实
- 结尾三段"愿……"拉近距离

## 风格避坑（经验教训）

### 政协事段落——避免句式重复
政协事段落中，调研/督导/巡查相关的两行描述**不能写成对称句式**（如"XX正忙/XX正勤""XX督导正紧/XX巡查正勤"）。用户对此敏感，要求每句话用不同的动词和结构。

✅ 正确的做法：
```
防汛督导踩着热浪走
河堤巡查追着水位跑
```
（动词不同："踩着"vs"追着"；句式不同）

❌ 错误的做法（会被批评重复/不好）：
```
市区的防汛备汛督导正紧
大沙河沿岸堤防巡查正勤
```
（"XX正紧/XX正勤"对称结构——勿用）

同样，"在河堤岸畔/把建言写在群众心坎上"这种前一句为地点状语、后一句为动宾结构的搭配也被认为不够好，推荐直接用"在一线现场/把呼声写进履职答卷里"这样动词有变化的写法。

## 交付习惯
- 最终交付文件用 `.txt` 格式（用户偏好）
- 同时生成 `.docx` 排版版（用python-docx生成，标题橙色18pt居中，小标题橙色加粗14号，正文微软雅黑12号居中）
- txt和docx都存桌面

## 生产流程

### 初稿编写
1. 严格按9段模板结构写文案
2. 所有本地地点先用【待确认】标记，如果没把握

### 地点确认流程
1. 写出初稿后，逐条检查每个地点是否真实存在
2. 有不确定的地点 → 明问用户"XXX是不是本地真实的地点/有这个说法吗？"
3. 用户确认的才保留，不确定的删掉换已知地点
4. 结尾三个"爱……"必须全部是用户确认过的市区地点

### 定稿前自检清单
- [ ] 每个本地地点都真实存在？（不是编的）
- [ ] 地点以市区为主？（少用修武/博爱/沁阳/孟州/温县等县里地名）
- [ ] 结尾的"爱……"三个地点都确认无误？
- [ ] 三候的地点没有编造？
- [ ] 政协事段落没有编造具体工作内容？
- [ ] 结构是否与之前节气文案完全对齐？
