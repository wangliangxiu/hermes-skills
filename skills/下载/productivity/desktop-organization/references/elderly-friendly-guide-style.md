# 给长辈写操作指南的文档风格

适用场景：用户让你"帮爸爸/叔叔/妈妈写一份操作指南"时使用。

## 核心原则

1. **从开机/打开App开始写** — 不要假设对方已经打开了软件
2. **每个按钮都说清楚位置和样子** — "底部红色的圆形按钮"而不是"点发布"
3. **用"→"表示步骤递进** — "打开微信 → 找到xxx → 点xxx"
4. **避免任何英文术语** — 写"下一步"不写"Next"，写"浏览"不写"Browse"
5. **每一页的操作都写出来** — "如果看到这个页面，就点xxx"

## 格式模板

### 适合的写法（说明书式）

```
第一步：打开微信
1. 在手机桌面上找到绿色的微信图标，点一下
2. 进入聊天列表后，找到"文件传输助手"
3. 点进去

第二步：把文字发给自己
1. 在底部输入框里，按住那个"按住说话"的按钮
2. 说出您想写的内容
3. 说完松手，会发送一条语音
4. 长按这条语音，点"转文字"
5. 文字出来后，长按文字，点"复制"
```

### 不适合的写法（太简略）

```
第一步：用微信录语音转文字
第二步：复制文字到豆包润色
```

## 提示词模板

当用户说"帮我写一份操作指南给爸爸"时，直接写出类似上面"适合的写法"那种详细程度的内容。不需要询问"要多详细"——默认就是最详细的那个版本。

## 配图说明

- 如果工具常用的按钮有图标特征，文字描述图标样子
- 例如："那个纸飞机图标（蓝色）就是发送按钮"
- 不要说"点右上角那个"——对方不知道哪个是右上角
