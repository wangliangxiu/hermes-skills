# 自传转视频操作指南（给叔叔的版本）

## 场景描述
使用者让帮他爸写一份从"自传文字"到"做成视频"的完整操作指南，要写成像说明书一样，每一步说清楚按哪个按钮。

## 关键要求
1. 从"打开手机"开始写，不要假设任何基础
2. 每个按钮位置说清楚（顶部/底部/左边/右边）
3. 提示词直接写出来让长辈复制
4. 包含"如果遇到问题"的常见错误处理
5. 用户第一版生成了"自传转视频方案.txt"，被要求重写为更详细的版本"自传转视频操作指南.txt"
6. 更新时要删除旧版本，只留最新版

## 内容结构参考

```
给叔叔的自传转视频操作指南

第X步：XXX（一句话概括）
================================================================================

操作：
1. 打开手机 → 找到XXApp
2. 点页面底部的"XX"按钮
3. 在输入框粘贴这段文字："[提示词]"
4. 点"生成"按钮
5. 等30秒

[小窍门]
- ...

如果遇到问题：
问题1：找不到"图文成片"按钮
  → 打开剪映后，首页上方有一排功能图标，手指左右滑动就能看到
```

## 推荐流程
1. 微信语音转文字（按住说话→转文字→复制）
2. 豆包润色（粘贴+提示词）
3. 剪映图文成片（粘贴文字→自动生成视频→手动调整画面配音）
4. 拼接完整视频
