# ST7789 170x320 Screen Configuration for ESP32-S3

## TFT_eSPI User_Setup.h Pins (合宙 ESP32-S3 N16R8)

```cpp
// === Driver ===
#define ST7789_DRIVER

// === Resolution ===
#define TFT_WIDTH  170
#define TFT_HEIGHT 320

// === SPI Pins (ESP32-S3) ===
#define TFT_MOSI 13
#define TFT_SCLK 14
#define TFT_CS   10
#define TFT_DC   11
#define TFT_RST  12
#define TFT_BL   15

// === SPI Speed ===
#define SPI_FREQUENCY  27000000
#define SPI_READ_FREQUENCY  20000000
```

## Wiring (ESP32-S3 → ST7789 Module)

| ST7789 Pin | ESP32-S3 GPIO | Notes |
|-----------|:-------------:|-------|
| VCC       | 3.3V          | 屏幕供电 |
| GND       | GND           | 共地 |
| CS        | GPIO10        | 片选 |
| DC/RS     | GPIO11        | 数据/命令选择 |
| RST       | GPIO12        | 复位 |
| MOSI/SDA  | GPIO13        | SPI 数据 |
| SCLK/SCL  | GPIO14        | SPI 时钟 |
| BL/LED    | GPIO15        | 背光控制（PWM optional） |

## 固件中的引脚定义（zhender_box.ino）

```cpp
// 屏幕 ST7789
#define TFT_CS    10
#define TFT_DC    11
#define TFT_RST   12
#define TFT_MOSI  13
#define TFT_SCLK  14
#define TFT_BL    15

// 麦克风 INMP441 - I2S
#define I2S_MIC_BCLK 4
#define I2S_MIC_LRC  5
#define I2S_MIC_DIN  6

// 功放 MAX98357 - I2S
#define I2S_AMP_BCLK 7
#define I2S_AMP_LRC  8
#define I2S_AMP_DOUT 9

// 按键
#define BTN_WAKE  1
#define BTN_MODE  2
#define BTN_CONFIRM 3
```

## 将固件代码与 User_Setup.h 同步

User_Setup.h 中的引脚必须与固件（.ino）里的引脚定义一致。
如果改了固件里的屏幕引脚，必须同步修改 User_Setup.h。
反之亦然。
