# 回答「怎么这么贵」的成套素材

使用者对价格极敏感，看到单价表或账单常直接质疑「怎么这么贵，怎么都几块几块的」。
按下面的顺序讲，一次讲清，别一句「每百万 token 几块钱」打发。

## 1. 先分列，别混着讲

价格表有三列，单价差三个数量级，混着说必吵架：

- **输入·缓存命中**：闲 0.05 / 峰 0.10 元每百万（flash）。「百万 token 才几分几毛」这个记忆指的就是这一列，
  而且这一列现在也还是这个价——先认可他的记忆是对的，再指出他说的是哪一列。
- **输入·缓存未命中**：闲 1.5 / 峰 3.0。
- **输出**：闲 4.5 / 峰 9.0 —— 最贵的一列，永远是最先撑爆账单的那项。

## 2. 历史锚点（用来解释「以前不是更便宜吗」）

他记的便宜价都是真的，但要落到具体哪一代/哪一列：

| 时间 | 价格（元/百万 tokens） | 说明 |
|---|---|---|
| 2024-08 | 输入 0.1 / 输出 2 | V3，他印象里「便宜」的根源 |
| 2025-02 | 输入 0.5 / 输出 8（R1 16） | 优惠期结束 |
| 2026-05 | 0.025 / 3 / 6 | V4 Pro 永久 2.5 折，全球最低价纪录 |
| 2026-08-17 起 | flash 闲 0.05/1.5/4.5、峰 0.10/3/9 | V4 全系列峰谷定价，基准价上调（最高涨幅 1100%，主要命中的是缓存命中输入那一列） |

**结论话术**：不是他记错，是官方 2026-08 确实上调过基准价，且「几分几毛」指的是缓存命中输入那一列。

## 3. 单次成本表（flash，元）

| 场景 | 高峰 | 闲时 |
|---|---|---|
| 简单问答 2k 入 + 0.5k 出 | 0.011 | 0.005 |
| 中等任务 20k 入 + 2k 出 | 0.078 | 0.039 |
| 长文档总结 100k 入 + 5k 出 | 0.345 | 0.173 |

Pro 同结构 ×3。拿来证明「问几句话真的只是一分钱」。

## 4. 「几块几块」出在哪：agent 型任务

agent 每跑一次工具调用都要重发整段上下文，成本随「轮数 × 上下文长度」涨，跟问题数量没关系：

| 80k 上下文、10 轮工具调用 | 成本 |
|---|---|
| 高峰、无缓存命中 | 2.74 元 |
| 闲时、无缓存命中 | 1.37 元 |
| 闲时、缓存命中 | 0.08 元 |

同一个活儿差 34 倍。**先给这张表再给建议**，他才知道省钱的着力点在哪。

## 5. 讲价顺序（按杠杆大小）

1. 错峰：避开工作日 9:00-12:00、14:00-18:00，价格直接减半（周末全天闲时）
2. 别频繁 `/new`：DeepSeek 自动缓存前缀，连续对话输入几乎白送；一 /new 全按未命中算，贵 30 倍
3. 输出精炼：输出单价是未命中输入的 3 倍，长文档分段出
4. 大活（写代码、跑测试、批量调研、多路 subagent）挪到闲时再开工

顺手报账时用真实数字，不估算；算不清就先跑一遍算术工具，别在对话里心算。
