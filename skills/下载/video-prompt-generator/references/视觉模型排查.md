# 视觉模型排查备忘录

当用户要求"看图"（vision_analyze 失败时），当前 deepseek-chat 不支持视觉，需要排查可用的视觉模型。

## 当前环境状态

- 主模型：deepseek-chat（DeepSeek API）
- deepseek-chat **不支持 vision_analyze**（API 返回 400: unknown variant `image_url`）
- 当前 config.yaml 中 vision 配置为 `provider: auto, model: ''`
- 没有配置独立的视觉模型 API key

## 排查顺序

### 1. 检查已配置的 API 提供商

查看 `hermes config show` 和 `.env` 文件，寻找可用的视觉模型提供商：

| 提供商 | 视觉模型 | 排查要点 |
|--------|---------|---------|
| OpenRouter | gpt-4o, claude-sonnet-4-vision | 需要 OPENROUTER_API_KEY |
| z.ai (GLM) | glm-4v-plus | 需要 GLM_API_KEY，端点 `https://api.z.ai/api/paas/v4` |
| Qwen Portal | qwen-vl-max | 需要 qwen oauth 登录（本地 token） |
| SiliconFlow | deepseek-vl2, qwen-vl | 需要 SILICONFLOW_API_KEY |

### 2. 尝试直接调用 API

```python
import base64, requests

img_path = '图片路径'
with open(img_path, 'rb') as f:
    b64 = base64.b64encode(f.read()).decode()

payload = {
    'model': '视觉模型名',
    'messages': [{
        'role': 'user',
        'content': [
            {'type': 'text', 'text': '描述图片'},
            {'type': 'image_url', 'image_url': {'url': f'data:image/png;base64,{b64}'}}
        ]
    }]
}

r = requests.post('API端点/v1/chat/completions', json=payload, timeout=60)
```

### 3. 常见失败原因

- **401 Unauthorized**：API key 未配置或错误
- **400 bad request**：模型不支持图片输入（如 deepseek-chat）
- **Connection timeout**：API 端点不可达（如 Docker 内部网络 172.17.0.1）
- **图片过大**：超过 20MB 会被截断

### 4. 临时方案

如果视觉模型不可用，可以：
1. 让用户描述画面内容
2. 根据描述写提示词（但必须跟用户确认关键细节，不瞎编）
