# 任务级交接包（跨机器 / 跨会话接着干）

使用者常在两台机器之间换着干（工作机 ↔ 家里台式机），说"把今天做的东西整理一下打成包放桌面，
我回家让台式机的 hermes 去完成后面的内容"。交的是**一个任务**，不是整台机器 —— 全量迁移见 SKILL.md 正文。

## 一、复原"本阶段做了什么"

1. 先 `session_search()` 不带参数 browse，找到当天的会话 id（长任务当天往往只有一条会话）。
2. 当天常是**超长会话**（几百条消息、十几万字）：**不要**整体读进上下文，也不要一条条 session_search。
   直接查会话库导出到 Temp 再分段 read_file：
   ```python
   con = sqlite3.connect("file:" + os.path.expanduser(r"~\AppData\Local\hermes\state.db") + "?mode=ro", uri=True)
   rows = con.execute(
       "SELECT id, role, content, tool_name, timestamp FROM messages WHERE session_id=? ORDER BY id",
       (sid,)).fetchall()
   ```
3. 分层导出，按需读：
   - `role='user'` = 使用者原话，一天通常只有一万多字 → 先导这一份，足够写交接说明与原话记录
   - `role='assistant'` = 自己的回话（含当时的结论与数字）→ 抠细节时再导
   - `role='tool'` = 工具输出，默认丢掉
4. 过滤噪音（**必须**，否则记录里一半是系统通知）：
   - `role='user'` 里夹着后台进程通知（正文含 `Background process`）、`Operation interrupted: ...` → 滤掉
   - `[OUT-OF-BAND USER MESSAGE ...]` 包着的是使用者当场追加的话 → 不是噪音，剥掉标记改写成「（当场追加）…」
   - 上下文压缩会让同一段回话在表里出现两次（并留下 `[CONTEXT COMPACTION ...]` 标记）→ 阅读略过，统计时按 (role, content) 去重
   - 会话很长时另看 `sessions` 表的 title / started_at / last_activity_at / message_count，确认哪条是当天主线
5. 导出 txt 的编码跟目录里已有 txt 保持一致（UTF-8；要 Windows 记事本好看就 newline="\r\n"）。

## 二、盘点产出物（别靠回忆）

按修改时间扫目录，一次列全，别凭对话回忆文件名：

```python
for root, dirs, files in os.walk(base):
    for f in files:
        st = os.stat(os.path.join(root, f))
        if st.st_mtime >= 当天0点: 记下 (时间, 大小, 相对路径)
```

- 工作副本目录**和**已装技能目录都要扫，两份对一遍（`diff -rq`）确认是同一版
- 顺手把"今天没有留下、需要知道的东西"也写进清单：临时脚本放哪了、被覆盖的旧版本备份在哪
- 清单按类别分组（技能 / 素材 / 资产 / 示意稿），每项一句话用途，不要只丢一串路径

## 三、打包与验证

- Python `zipfile`，`ZIP_DEFLATED`，arcname 用 `os.path.relpath(p, os.path.dirname(包目录))`
  —— 解压出来就是顶层一个同名文件夹，接手方不用再挪目录
- 验证三样：`len(z.namelist())` 文件数、`z.testzip()` 无损坏、关键文件（00 交接说明 / 进度索引 / 各技能 SKILL.md）确实在包里
- **复制阶段删过文件就重新对一遍清单**："先 cp 再 rm 清理"的写法容易把还没备份的源文件从包里删掉；核清单发现少了立刻从源目录补回
- 文件夹与同名 .zip 各留一份：文件夹方便当面看，zip 方便拷走

## 四、交接说明（00）的固定顺序

1. 这个包是什么、给谁、接手后要干到哪一步
2. 主线任务与终点（一句话说清"这是在干什么"）
3. 本阶段做了什么（分条，带出处与页码/路径）
4. 现在进度到哪儿（逐章/逐阶段标：已完 / 讲了大部分 / 下一步从这儿接），并写清收工原因
5. 接手步骤：装技能到哪个目录、先读哪份文件、接着干的启动语怎么写
6. 红线与口径：用户反复强调过的规矩，按原话抄进去
7. 包内文件地图：每个子目录一句话
8. 下一步与提醒：要插的外设、省钱的用法
