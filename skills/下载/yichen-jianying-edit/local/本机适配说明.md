安装日期：2026-09-29   宿主：C:\Users\使用者   核心项目：D:\hermes-skills\jianying-headless

  原生 macOS 路线（Apple Silicon + 剪映专业版 11.5.0 + 本机剪映引擎导出）在本机不可用，不要尝试。
  但 Windows FFmpeg 后端在本机【已实测跑通】：能给 MP4 成片，不做剪映草稿。
  计划 → 校验 → 导出 → 断言，全链路可用。

二、必须设置的环境变量
  JIANYING_HEADLESS_ROOT=D:/hermes-skills/jianying-headless
  （核心引擎是另一个公开仓库 mcncarl/jianying-headless，已放在上面这个目录，含 engine/ 与 skills/yichen-jianying-edit/）

三、实测通过的命令（三条，按顺序）
  S="D:/hermes-skills/jianying-headless/skills/yichen-jianying-edit/scripts/headless_draft.py"
  python "$S" doctor

  python "$S" export --backend windows-ffmpeg --build <同上目录> \

      → {"status":"encoded-and-decoded","full_decode_passed":true,"source_build_unchanged":true}

四、本机踩过的坑（照做即可）
  1. --out 必须是"项目 work 目录下的新目录"，且不能已存在，否则报
     "Output must be a new directory below the project work directory"。
     即：输出只能落在 D:/hermes-skills/jianying-headless/work/ 下面。
  2. 调 python 脚本时路径必须用原生 Windows 形式（D:/... 正斜杠可以），
     不要用 MSYS 形式 /d/...，否则 python 会把路径解析成 D:\d\... 而报找不到文件。
  3. 含文字的导出必须显式给 --font；本机用 C:/Windows/Fonts/msyh.ttc（微软雅黑），
     ttc/ttf/otf 均可。不给字体会在含 text 轨时失败。
  4. 素材格式按项目要求：H.264 + yuv420p。用 testsrc2 造的测试片完全可用。

五、实测证据（2026-09-29）

六、口播自动剪辑链路（本机怎么接）
  edit_plan.py compile 已实测通过：jianying-edit-plan/v1（原片秒数）→ compiled.json +
  subtitles.srt + transcript.md。它只做时间轴编译，不做转写。
  上游 ASR 执行器该项目不随包分发（默认找 ~/scripts/transcribe.py，可用 YICHEN_ASR_EXECUTOR 指定）。
  本机做法：用本地转写（video-transcript-local 技能 / faster-whisper）产出带时间点的逐句稿，
  再手写 jianying-edit-plan/v1 的 keeps + subtitles + decisions，然后 compile → build → export。
  实测：3.0 秒原片、保留 2 段（删掉 1.2–1.6 秒气口）→ 编译出 2.5 秒 / 75 帧 / 2 条字幕（已含 20ms 显示余量）。

七、不要做的事

  - 不要把 Windows 后端产物说成"可编辑剪映草稿"——它只出 MP4，native_editable_draft 恒为 false。
