# AI Video Shot Planner

## Overview

这个 skill 负责前期策划，包括三个阶段：**剧本解析**、**空间锁定**、**镜头拆分**。不负责写生图提示词或图生视频提示词。目标是把文案变成结构化的剧本要素、固定场景空间关系，再拆成清晰的镜头表，并提前分配每个镜头的 `visual_carrier` 与画面轨重点。

## When To Use

- 用户给出文案，想先拆分镜
- 用户还没开始生图，只需要镜头规划
- 用户需要判断主讲人、场景、解释图、数据对比等视觉承载比例

## Step 0：剧本解析

在拆镜头之前，先让模型「读懂」文案，输出结构化的剧本要素。这一步的目的是把用户的模糊需求转化为后续每一步都能直接使用的结构化输入。

### 输入

用户原始文案全文。

### 输出

至少包含以下字段：

```
剧本解析：

【角色】
- 角色A：年龄段、性别、职业气质、穿着、状态
- 角色B：（如有多个角色逐一列出）

【场景】
- 场景A：空间类型、光线条件、关键物品
- 场景B：（如有多个场景逐一列出）

【情绪线】
按文案节奏分段，例如：压抑（前1/3）→ 转折（中1/3）→ 振作（后1/3）

【色调线】
对应情绪线的色调变化，例如：冷蓝暗调（前段）→ 过渡（中段）→ 暖金逆光（后段）

【关键动作】
按时间顺序列出关键动作节点，每个动作对应文案的一个信息点

【道具/细节】
画面中需要出现的道具、文字、界面、品牌元素等
```

### 规则
- 角色描述要具体到能直接写进提示词的程度，不要只写「男生」
- 场景描述要包含光线条件和关键空间元素
- 情绪线和色调线必须对应，不要出现情绪是压抑但色调是暖色的矛盾（除非用户明确要求反差）
- 关键动作要和文案的语义节奏对齐，不要跳过转折句和金句
- 如果文案中出现大众熟知的品牌、logo、地标，必须在道具/细节里保留

## Step 0.5：空间锁定卡

剧本解析完成后，为每个场景生成一张空间锁定卡。这张卡和人物三视图互补：三视图管人物长相，空间锁定卡管场景布局。

### 输入

剧本解析中的【场景】信息。

### 输出

每个场景各一张卡：

```
空间锁定卡 — 场景A：[场景名称]

【环境锚点】（≥3个固定参照物）
1. [位置]：[物体描述]
2. [位置]：[物体描述]
3. [位置]：[物体描述]

【光线方向】
主光源：[来源]（[方向]，[色温]）
辅助光：[来源]（[方向]，[色温]）
整体：[明暗调性]，[饱和度]

【人物站位】
默认位置：[描述]
备选位置：[描述]（如有）

【轴线管理】
视线轴线：[人物] ↔ [参照物]
情绪轴线：[暗区位置] → [亮区位置]

【机位参考】
默认：[景别]，[距离]，[高度]
特写：[景别]，[距离]
全景：[景别]，[距离]，用于交代环境
```

### 规则
- 环境锚点至少 3 个，必须是场景中固定不动的参照物（墙壁、窗户、家具、设备等），不要写人物或临时道具
- 光线方向必须明确，因为后续每个镜头的光影都要和这张卡一致
- 人物站位写清楚默认位置和可选位置，后续镜头提示词里的人物位置不能超出这些范围
- 轴线管理是防止空间错乱的核心：人物不能突然跑到轴线另一边
- 机位参考给后续镜头拆分提供默认值，不是强制锁死
- 如果只有一个场景，只生成一张卡；如果有多个场景，每个场景各一张
- 如果场景信息不够具体（例如文案只写了「房间」），按合理推断补全，但标注「推断值」，让用户确认

## Step 1：镜头拆分

剧本解析和空间锁定卡完成后，再进入镜头拆分。

- 镜头密度默认是每分钟 `8～10` 个镜头
- 低密度按每分钟 `8` 个镜头
- 普通密度按每分钟 `9` 个镜头
- 高密度按每分钟 `10` 个镜头
- 默认先按普通密度处理
- 只有在信息点连续切换、转折频繁、品牌/事件/数字明显密集、几乎一句一镜时，才升级为高密度
- 时长优先使用用户给定时长；否则按文案估算
- 中文默认 `230` 字/分钟，英文默认 `150` 词/分钟
- 开头 3 秒优先给钩子镜头
- 一个镜头只表达一个主要信息点

## Required Output

### 剧本解析输出

完整的结构化剧本要素（格式见 Step 0）。

### 空间锁定卡输出

每个场景的空间锁定卡（格式见 Step 0.5）。

### 镜头表输出

每个镜头至少包含：

- `shot_id`
- `time_range`
- `narration_excerpt`
- `message_goal`
- `visual_carrier`，必须使用总控定义的 7 值规范名
- `scene`，对应空间锁定卡的场景名
- `reason`

新增的 `scene` 字段用于关联空间锁定卡，确保每个镜头都锚定到具体场景的空间关系上。

## Visual Carrier Allocation

如果用户没指定视觉承载策略，默认：

- 开头镜头优先考虑主讲人或强钩子画面建立信任感
- 中段复杂说明优先允许 B-roll 覆盖
- 结尾 CTA 优先回到主讲人、场景收束或明确行动画面
